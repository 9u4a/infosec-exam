**19·25회 반복 출제.** '이미 연결된 활성 세션을 가로채 사용자 신원으로 통신' → 세션 하이재킹.

**핵심 정답**
- **세션 하이재킹**: 인증이 끝난 **활성 세션**을 탈취해 공격자가 사용자 행세.
- **TCP 세션 하이재킹**: 시퀀스 번호를 예측·동기화해 끼어듦(스니핑 + 스푸핑, ACK 스톰 발생).
- **웹 세션 하이재킹**: 세션 ID(쿠키)를 XSS·스니핑·세션 고정으로 탈취.
- 대응: HTTPS, 로그인 성공 시 **세션 ID 재발급**(고정 방지), 유휴 타임아웃, HttpOnly/Secure 쿠키, IP·User-Agent 바인딩, TCP 시퀀스 랜덤화.

**함정**: 세션 고정(공격자가 만든 세션ID를 피해자가 쓰게 함)과 하이재킹(탈취) 구분.
