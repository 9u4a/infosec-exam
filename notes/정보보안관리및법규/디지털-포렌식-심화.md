## 포렌식 유형

| 유형 | 대상 | 도구 |
|---|---|---|
| **디스크(저장매체) 포렌식** | HDD/SSD/USB, 파일시스템, 삭제·슬랙 영역 | EnCase, FTK, **Autopsy/Sleuth Kit**, X-Ways |
| **메모리(라이브) 포렌식** | RAM — 실행 중 프로세스, 네트워크 연결, 복호화 키, 은닉 코드 | **Volatility**, Rekall, FTK Imager(덤프) |
| **네트워크 포렌식** | 패킷·플로우·방화벽/IDS 로그 | **Wireshark**, tcpdump, NetworkMiner, Zeek |
| **모바일 포렌식** | 스마트폰(앱 DB, 통화·메시지, 위치) | Cellebrite UFED, Oxygen, MSAB |
| **DB 포렌식** | 트랜잭션 로그, 삭제 레코드 | 로그 분석 도구 |
| **클라우드 포렌식** | API 로그, 스냅샷, 관할권 이슈 | CSP 로그(CloudTrail 등) |

## 포렌식 절차

```
사전 준비 → 증거 수집(현장 보존, 휘발성 우선) → 이송(봉인·기록)
 → 조사·분석(사본으로) → 보고서 작성 → 증거 제출(법정)
```

### 증거 수집 — 휘발성 순서 (RFC 3227)

레지스터·캐시 → **메모리(RAM)** → 네트워크 상태·프로세스 → 임시 파일 → **디스크** → 원격 로그 → 물리 백업·아카이브

### 이미징 (사본 생성)

- **쓰기 방지 장치(Write Blocker)** 를 거쳐 원본 연결.
- 비트 단위 복제(dd, EnCase E01). **원본·사본 해시(MD5+SHA-256) 동일** 확인·기록.
- 분석은 **반드시 사본**으로. 원본은 봉인 보관.

## 디지털 포렌식 5대 원칙 (재확인)

**정당성**(적법 절차) · **재현성**(같은 조건→같은 결과) · **신속성**(휘발성 소실 방지) · **연계보관성(Chain of Custody)**(수집~제출 전 과정 책임자·시각·방법 기록) · **무결성**(해시로 원본 동일 증명)

## 분석 산출물·개념

- **타임라인 분석**: MAC 타임(Modified/Accessed/Created/MFT Changed), 로그 시각 상관.
- **삭제 파일 복구**: 파일 카빙(시그니처 기반), 미할당·슬랙 영역, `$MFT`·저널.
- **레지스트리 분석**(Windows): 최근 실행(UserAssist·Prefetch), USB 연결 이력, 자동실행.
- **아티팩트**: 브라우저 히스토리·캐시, 이벤트로그, `.lnk`, `Amcache`, `SRUM`.

## 안티 포렌식 (Anti-Forensics)

| 기법 | 대응 |
|---|---|
| 데이터 완전 삭제(와이핑), 물리 파괴 | 슬랙·저널·백업·클라우드 사본 확인 |
| 암호화·스테가노그래피 | 메모리에서 키 추출, 패스프레이즈 크래킹 |
| 타임스탬프 변조(Timestomp) | `$MFT` STANDARD_INFO vs FILE_NAME 비교 |
| 로그 삭제·조작 | 원격 syslog, 백업, `chattr +a` 로그 |
| 스테가·은닉 파티션·가상머신 | 디스크 전체 카빙, 엔트로피 분석 |
| 루트킷·파일리스 | 메모리 포렌식(Volatility), 신뢰 매체 부팅 |

## 관련 표준

- **ISO/IEC 27037**(증거 식별·수집·보존), 27041/27042/27043, NIST SP 800-86.
- 국내: 대검찰청·경찰청 디지털 증거 처리 규정, 형사소송법상 위법수집증거 배제.
