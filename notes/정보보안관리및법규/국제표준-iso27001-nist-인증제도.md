> isms-p 노트의 국제 짝. 필기 단골.

## ISO/IEC 27000 시리즈

| 표준 | 내용 |
|---|---|
| **27000** | 용어·개요 |
| **27001** | ISMS **요구사항**(인증 기준). Annex A에 통제목록. PDCA → (2022판) 계획-실행-평가-개선 |
| **27002** | 정보보안 **통제 실무 지침**(구현 가이드). 2022판 = **93개 통제, 4개 테마**(조직/인적/물리/기술) + 5개 속성 태그 |
| **27003** | ISMS 구현 가이드 |
| **27004** | 보안 측정·지표 |
| **27005** | 정보보안 **위험관리** → 위험관리-절차 노트 |
| **27011** | 통신 사업자 |
| **27017** | **클라우드 서비스** 보안 통제 |
| **27018** | 클라우드 **개인정보(PII)** 보호 |
| **27701** | **개인정보보호 관리체계(PIMS)** — 27001/27002 확장, GDPR 대응 |
| **27031/27035/27037** | 사업연속성 / 침해사고 관리 / 디지털 증거 |

- 27001 인증: 인정기관(KAB 등) → 인증기관 → 조직. 유효 **3년**, 매년 사후심사.

## NIST 프레임워크

| 문서 | 내용 |
|---|---|
| **NIST CSF (Cybersecurity Framework)** | 5(→2.0은 6)개 기능: **거버넌스 · 식별(Identify) · 보호(Protect) · 탐지(Detect) · 대응(Respond) · 복구(Recover)**. 자율 프레임워크 |
| **NIST SP 800-53** | 연방 시스템 보안·프라이버시 통제 카탈로그 |
| **NIST SP 800-61** | 침해사고 대응 가이드(준비→탐지·분석→봉쇄·근절·복구→사후) |
| **NIST SP 800-37 (RMF)** | 위험관리 프레임워크 |
| **NIST SP 800-63** | 디지털 신원(인증) 지침 — AAL/IAL/FAL 등급 |

## 기타 국제 표준

- **ISO 22301**: 사업연속성 관리체계(BCMS).
- **ISO 31000**: 리스크 관리 일반 → 위험관리-절차 노트.
- **COBIT**: IT 거버넌스 프레임워크.
- **ITIL**: IT 서비스 관리.
- **PCI-DSS**: 카드 데이터 보안(12개 요구사항).
- **GDPR**: EU 개인정보보호 규정(과징금 전세계 매출 4% 또는 2천만 유로).

## 국내 인증제도 비교

| 인증 | 대상 | 주관 | 유효기간 |
|---|---|---|---|
| **ISMS-P** | 정보보호 및 개인정보보호 관리체계 | KISA/한국정보통신진흥협회, 개인정보위·과기정통부·방통위 | 3년(사후 연1회) |
| **CC 인증** | 정보보호 **제품**의 보안 기능 | IT보안인증사무국 / 국정원 | — |
| **CSAP** | 공공용 **클라우드 서비스** | KISA | 5년(사후 연1회) |
| **PIPL(우수 개인정보 처리자)** 등 | 상황별 | 개인정보위 | — |
| **정보보호 준비도 평가 / 정보보호 공시** | 기업 정보보호 투자·인력 현황 공개 | KISA | 연 단위 |

- **PIMS + ISMS → ISMS-P 로 통합(2018)**. PIMS 단독 인증은 폐지.

## 관리체계 공통 사이클 (PDCA)

**Plan**(정책·범위·위험평가·대책 수립) → **Do**(구현·운영) → **Check**(모니터링·내부감사·경영진 검토) → **Act**(시정·개선). 지속적 개선이 핵심.
