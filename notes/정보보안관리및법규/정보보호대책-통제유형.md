## 통제 시점(기능)에 따른 분류 (7-9)

| 유형 | 개념 | 예 |
|---|---|---|
| **예방 통제 (Preventive)** | 잠재적 문제를 **사전에 식별해 대처**하는 능동적 통제 | 접근통제, 암호화, 방화벽, 보안 교육, 직무 분리 |
| **탐지 통제 (Detective)** | 예방 통제를 **우회해 발생한 문제**를 찾아냄 | IDS, 로그 감사, CCTV, 침입 경보, 무결성 점검 |
| **교정(시정) 통제 (Corrective)** | 발견된 문제를 **복구·개선**하고 재발 방지 | 백업 복구, 패치, BCP/DRP, 사고 대응 절차 |

- 추가: **억제(Deterrent)** — 경고문·처벌 규정, **복구(Recovery)** — 교정의 세부.

## 통제 수단(구현 방식)에 따른 분류 (6-10, 25-5, 30-11)

| 유형 | 내용 |
|---|---|
| **관리적(행정적) 통제** | 정책·지침·절차, 인사 보안, 교육, 감사, 직무 분리 |
| **물리적 통제** | 관계자 외의 사람이 **시설·설비에 접근하지 못하게** 함 — 출입통제, 잠금장치, 경비, 소방·항온항습 |
| **기술적(논리적) 통제** | 승인받지 못한 사람이 **정보통신망을 통해 자산에 접근**하는 것을 차단 — 인증, 접근제어, 암호화, 방화벽/IPS |

- 30-11 빈칸: (A) 물리적 접근 통제 (B) 논리적(기술적) 접근 통제.
- 6-10: (A) 예방 통제 (B) 물리적 접근 통제 (C) 논리적 접근 통제.
- 25-5: 정보보호대책 3구분 = 예방(→물리적·논리적 접근통제로 세분)·탐지·교정으로 서술되기도 함(문항 지문 따라감).

## 외우는 법

- **시점**: 예방(막고) → 탐지(찾고) → 교정(고친다).
- **수단**: 관리적(사람·규정) / 물리적(문·벽·자물쇠) / 기술적(전자·논리).
- 한 대책이 여러 유형에 걸침: 예) 방화벽 = 예방 + 기술적, 백업 = 교정 + 기술적/관리적.
