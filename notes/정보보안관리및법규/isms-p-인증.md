## ISMS vs ISMS-P

- **ISMS**: 정보보호 관리체계 (보안 중심)
- **ISMS-P**: 정보보호 **및 개인정보보호** 관리체계 (ISMS + 개인정보 처리단계 요구사항)

## 인증기준 3개 영역 / 102개 항목

| 영역 | 항목 수 | 내용 |
|---|---|---|
| **1. 관리체계 수립 및 운영** | 16 | 기반 마련, 위험 관리, 운영, 점검·개선 (**PDCA**) |
| **2. 보호대책 요구사항** | 64 | 정책·조직·자산, 인적·물리·인증권한·접근통제·암호·개발·운영·사고대응·재해복구 (12개 분야) |
| **3. 개인정보 처리단계별 요구사항** | 22 | 수집 → 보유·이용 → 제공 → 파기 → 정보주체 권리 |

## 관리체계 라이프사이클 (PDCA)

**Plan**(정책·범위·위험평가·대책 수립) → **Do**(대책 구현·운영) → **Check**(모니터링·내부감사·점검) → **Act**(개선·시정조치)

## 관리적 요구사항 절차 (3회)

정책 수립·범위 설정 → 경영진 책임·조직 구성 → 위험관리 → 대책 구현 → 사후관리

## 인증체계 기관

| 기관 | 역할 |
|---|---|
| **정책기관** (과기정통부·행안부·**개인정보보호위원회**) | 법·제도, 인증기관·심사기관 지정 |
| **인증기관** (KISA, 한국정보통신진흥협회) | 인증서 발급, 심사원 양성·자격관리 |
| **심사기관** | 실제 인증심사 수행 |
| **인증위원회** | 심사결과 심의·의결 |

## 정보보호 정책 (문서 위계)

**정책**(최상위, 경영진 승인·공표) → **표준/지침**(준수 기준) → **절차**(수행 방법)

## 물리적 보안 대책 (2.4)

보호구역 지정(통제·제한구역) · 출입통제(이력 관리) · 정보시스템 보호(배치·케이블) · 보호설비 운영(UPS·항온항습·소방·누수) · 보호구역 내 작업 관리 · 반출입 기기 통제 · 업무환경 보안(클린데스크)
