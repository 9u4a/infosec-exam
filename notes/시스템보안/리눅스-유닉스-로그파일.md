## 핵심 로그 파일

| 파일 | 경로 | 내용 | 조회 명령 |
|---|---|---|---|
| **utmp** | `/var/run/utmp` | 현재 로그인한 사용자 | `who`, `w`, `users` |
| **wtmp** | `/var/log/wtmp` | 로그인/로그아웃, 재부팅 이력(누적) | `last` |
| **btmp** | `/var/log/btmp` | 로그인 **실패** 기록 (바이너리) | `lastb` |
| **lastlog** | `/var/log/lastlog` | 각 사용자의 **마지막** 로그인 시각·소스 | `lastlog` |
| **pacct / acct** | `/var/account/pacct` | 사용자가 실행한 **모든 명령어** | `lastcomm`, `acctcom` |
| **sulog** | `/var/adm/sulog` (Solaris) | `su` 명령 사용 내역 | `cat` |
| **loginlog** | `/var/adm/loginlog` (Solaris) | 연속 로그인 실패 (기본 5회) | `cat` |
| **xferlog** | `/var/log/xferlog` | FTP 전송 로그 | `cat` |
| **messages** | `/var/log/messages` | 시스템 전반 로그 (커널, 데몬) | `cat`, `dmesg` |
| **secure** | `/var/log/secure` | 인증 관련 (원격 접속, sudo) | `cat` |

## 자주 나오는 함정

- **wtmp vs lastlog**: wtmp는 *모든* 로그인 이력(누적), lastlog는 사용자별 *가장 최근* 1건.
- **btmp**는 바이너리라 `cat` 으로 못 보고 `lastb` 사용. Solaris에서는 `loginlog`(텍스트).
- **utmp/wtmp/btmp**는 바이너리. `pacct`도 바이너리 → 전용 명령 필요.
- 로그 삭제/조작은 침해사고의 흔적. `wtmp` 변조 시 `last` 출력에 공백/역순이 나타남.

## Solaris vs Linux 이름 대응

- 최근 로그인: Solaris `lastlog` = Linux `lastlog`
- 실패 로그인: Solaris `loginlog` ↔ Linux `btmp`
- su 로그: Solaris `sulog` (Linux는 `secure`/`auth.log` 에 통합)
