> 최신 정보보안기사 범위. 기출엔 스턱스넷 정도.

## IoT 보안 위협

- 취약한 **기본 자격증명**(admin/admin), 펌웨어 업데이트 부재, 평문 통신, 물리적 접근 용이.
- 대규모 봇넷화: **Mirai**(디폴트 계정 IoT 감염 → 대규모 DDoS).
- 프라이버시(카메라·마이크·위치), 안전(의료기기·차량).

### IoT 보안 원칙 (OWASP IoT / 국내 IoT 공통보안가이드)

- 안전한 **초기 설정**(기본 비밀번호 강제 변경, 불필요 포트 폐쇄)
- **보안 업데이트**(서명된 펌웨어, 자동 갱신), 안전한 부팅
- 전송·저장 **암호화**, 상호 인증(기기 인증서)
- 최소 기능·최소 권한, 물리적 변조 방지
- 로그·이상 탐지, 폐기 시 데이터 삭제
- 개발 단계 보안(Security by Design), SBOM

## 경량 암호

- 저전력·저메모리 기기용: **LEA, HIGHT**(국산), PRESENT, SPECK/SIMON, ChaCha20.
- 경량 해시·경량 인증(AEAD): ASCON(NIST 표준).

## ICS / SCADA (산업 제어 시스템)

발전·수도·가스·제조 등 물리 프로세스를 제어. **OT(운영기술)** 영역.

| 구성요소 | 역할 |
|---|---|
| **SCADA** | 감시 제어·데이터 수집 (중앙 HMI) |
| **DCS** | 분산 제어 시스템(플랜트 내부) |
| **PLC / RTU** | 현장 장치 제어(밸브·모터), 센서 입력 |
| **HMI** | 운영자 인터페이스 |
| **Historian** | 공정 데이터 이력 DB |

- 프로토콜: **Modbus, DNP3, PROFINET, EtherNet/IP, OPC** — 대부분 **인증·암호화 없음**(설계상).

### IT vs OT 보안 차이

| | IT | OT |
|---|---|---|
| 우선순위 | 기밀성 > 무결성 > 가용성 | **가용성·안전(Safety) > 무결성 > 기밀성** |
| 패치 | 수시 | 재가동 어려움 → 지연, 검증 필수 |
| 수명 | 3~5년 | 15~30년(레거시 다수) |
| 재부팅 | 자유 | 공정 중단 = 큰 손실·위험 |

### ICS 공격 사례

- **Stuxnet**(2010): 이란 원심분리기 표적. USB 전파 + 4개 제로데이 + PLC(지멘스 S7) 로직 변조 + HMI에 정상값 위장. 폐쇄망도 뚫림(공급망·USB).
- BlackEnergy/Industroyer(우크라이나 정전), TRITON(안전계장시스템 SIS 표적).

### ICS 보안 대책

- **망분리**: IT망 ↔ OT망 사이 **DMZ + 단방향 게이트웨이(데이터 다이오드)**.
- 자산 인벤토리, 화이트리스트 기반 통신, 제어망 전용 IDS(이상 트래픽·명령 탐지).
- USB·이동매체 통제, 원격 유지보수는 점프 서버 + MFA + 세션 기록.
- 표준: **IEC 62443**(ICS 보안), NIST SP 800-82, **정보통신기반보호법**(주요정보통신기반시설).
