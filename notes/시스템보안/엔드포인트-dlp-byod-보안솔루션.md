## EPP vs EDR

| | **EPP** (Endpoint Protection Platform) | **EDR** (Endpoint Detection & Response) |
|---|---|---|
| 목적 | **예방**(알려진 위협 차단) | **탐지·대응**(침입 후 행위 포착) |
| 방식 | 시그니처, 평판, 정적 휴리스틱 | 행위 분석, 이상 탐지, 이벤트 상관 |
| 대응 | 격리·삭제 | 원격 격리, 프로세스 중단, 롤백, 포렌식 |
| 한계 | 미지·파일리스·정상도구 악용 못 잡음 | 경보 많음, 분석 인력 필요 |

→ 실무는 EPP + EDR 통합. 확장: **XDR**(EP+NW+메일+클라우드 상관), **MDR**(관제 서비스 결합).

## EDR (Endpoint Detection & Response) — 16-5

엔드포인트(PC·서버)를 **지속 모니터링**하여 **행위 기반**으로 위협을 탐지·분석하고 대응(격리·차단·롤백).

- 시그니처 기반 백신(EPP)의 한계(알려진 악성코드만)를 보완 → 정상 프로세스를 악용하는 공격, 파일리스, APT 탐지.
- 핵심 기능: 행위 로깅, 이상행위 탐지, 위협 헌팅, 원격 격리, 타임라인 포렌식.
- 수집 데이터: 프로세스 생성 트리, 네트워크 연결, 파일·레지스트리 변경, DLL 로드, 스크립트 실행.

## DLP (Data Loss / Leakage Prevention) — 24-8, 29-4

내부 정보 유출 방지. **PC 에이전트 + 네트워크 센서**로 이동 경로를 감시·차단·기록.

- 감시 채널: 이동식 디스크(USB), 이메일 첨부, 메신저, **웹사이트 파일 업로드**, 출력(인쇄), 화면 캡처.
- **HTTPS 등 암호화 통신**도 에이전트/프록시에서 복호화 검사(내부 문서 이동 탐지).
- 콘텐츠 인식: 정규식(주민번호·카드번호), 지문(fingerprint), 키워드, 문서 분류 태그.
- 배치: **엔드포인트 DLP**(에이전트, 오프라인·USB·인쇄 통제), **네트워크 DLP**(게이트웨이, 메일·웹), **스토리지 DLP**(서버 저장 데이터 스캔).

## 데이터 보호 인접 솔루션

| 솔루션 | 역할 |
|---|---|
| **DRM** (Digital Rights Mgmt) | 문서 **자체를 암호화**하고 열람·편집·인쇄·기간 권한을 부여 → 외부로 나가도 무력화 |
| **CASB** (Cloud Access Security Broker) | 클라우드(SaaS) 사용 가시성·통제 — 섀도우 IT 탐지, 업로드 차단, 정책 적용 |
| **NAC** (Network Access Control) | 네트워크 접속 단말 **인증 + 무결성 점검**(백신·패치) → 미달 단말 격리/치료 |
| **워터마킹** | 출력물·화면에 사용자·시각 표시 → 유출 시 추적 |
| **문서 암호화(EFS/BitLocker)** | 디스크·파일 수준 암호화 (분실·도난 대비) |

## MDM / BYOD 모바일 보안 — 22-13, 30-14

| 기술 | 개념 |
|---|---|
| **MDM** (Mobile Device Management) | 기기 전체를 원격 관리 — 정책 적용, 앱 화이트리스트, 원격 잠금·**원격 삭제(wipe)**, 탈옥/루팅 탐지, 카메라·캡처 제어 |
| **MAM** (Mobile Application Management) | 업무용 **앱 단위** 관리·배포·삭제 (개인 영역은 미간섭) |
| **컨테이너화 (Containerization)** | 한 기기 안에 업무용/개인용 영역을 **논리적으로 분리**. 업무 데이터는 암호화 컨테이너에 저장, 상호 복사 차단 |
| **모바일 가상화 (Mobile Virtualization)** | 하나의 기기에 업무용·개인용 **OS(가상 머신)** 를 각각 구동해 완전 격리 |
| **MCM** (Mobile Content Management) | 업무 문서의 안전한 배포·열람(뷰어) 통제 |

- BYOD 3대 고민: 사생활 침해 vs 통제, 분실·도난, 비인가 앱. → 컨테이너화가 절충안.
- 통합 관리 플랫폼: **EMM**(MDM+MAM+MCM), 더 넓게 **UEM**(PC까지 통합).
