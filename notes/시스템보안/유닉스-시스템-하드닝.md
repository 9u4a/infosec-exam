## PAM (Pluggable Authentication Module) — 23-7, 29-1

인증을 모듈식으로 분리한 프레임워크. 설정: `/etc/pam.d/`, 모듈: `/lib/security/`.

| 관리 그룹 | 역할 |
|---|---|
| **auth** | 실제 인증 — 패스워드 확인, 토큰 검증 |
| **account** | 계정 유효성 — 사용 권한, 만료, 접속 시간·호스트 제한 |
| **password** | 패스워드 변경 정책 (복잡도, 재사용) |
| **session** | 세션 전후 처리 — 로그 기록, 홈디렉토리 마운트, 자원 제한 |

제어 플래그: `required`(실패해도 계속 진행 후 최종 실패) / `requisite`(즉시 실패) / `sufficient` / `optional`.

## 계정 잠금 (pam_tally / pam_faillock) — 14-11, 18-15

```
auth required /lib/security/pam_tally.so deny=5 unlock_time=120 no_magic_root reset
```
- `deny=5` : 인증 5회 실패 시 계정 잠금
- `unlock_time=120` : 마지막 실패로부터 120초 후 자동 잠금 해제
- `no_magic_root` : root는 잠금 예외
- `reset` : 로그인 성공 시 실패 카운터 0으로 초기화
- 설정 파일: `/etc/pam.d/system-auth` (RHEL) 또는 `/etc/pam.d/common-auth` (Debian)

## 패스워드 최소 길이 (OS별) — 24-17

| OS | 파일 | 설정값 |
|---|---|---|
| Solaris | `/etc/default/passwd` | `PASSLENGTH=8` |
| Linux | `/etc/login.defs` | `PASS_MIN_LEN 8` (+ `pam_pwquality`/`pam_cracklib` minlen) |
| AIX | `/etc/security/user` | `minlen=8` |
| HP-UX | `/etc/default/security` | `MIN_PASSWORD_LENGTH=8` |

## root 원격 접속 제한 — 6-6

| OS | 파일 | 방법 |
|---|---|---|
| Solaris | `/etc/default/login` | `CONSOLE=/dev/console` |
| AIX | `/etc/security/user` | `rlogin=false` (root 스탠자) |
| Linux | `/etc/securetty` | 허용 tty만 나열 (원격 pts 제외) |
| 공통(SSH) | `/etc/ssh/sshd_config` | `PermitRootLogin no` |

## r-command 대응 — 24-14, 32-14

`rsh`, `rlogin`, `rexec` 는 인증 없이 신뢰 기반 접속 → 가급적 사용 중지(SSH 대체).
불가피하게 쓸 때 `/etc/hosts.equiv`, `$HOME/.rhosts`:
- 소유자를 **root(또는 해당 계정)** 로: `chown root /etc/hosts.equiv`
- 권한을 **600 이하**: `chmod 600 ...`
- 파일 내용에서 **`+`** (모든 호스트/사용자 허용) 제거, 필요한 호스트만 명시

## Telnet 배너 노출 (28-18)

`telnet` 접속 시 OS·커널 버전이 노출되면 CVE 매핑·익스플로잇이 쉬워짐 + 평문 전송.
- 대응: Telnet 중지 → **SSH** 사용, 배너에서 버전 제거(`/etc/issue`, `/etc/issue.net`), root 직접 로그인 차단.

## ndd 커널 파라미터 (Solaris) — 9-13

| 명령 | 의미 | 대응 공격 |
|---|---|---|
| `ndd -set /dev/ip ip_forward_directed_broadcasts 0` | Directed Broadcast 포워딩 차단 | **Smurf** |
| `ndd -set /dev/tcp tcp_conn_req_max_q0 512` | SYN 대기 큐(backlog) 크기 확대 | **TCP SYN Flooding** |
| `ndd -set /dev/ip ip_forwarding 0` | IP 라우팅 비활성 | IP spoofing 경유 |

(Linux 대응: `/proc/sys/net/ipv4/...`, `sysctl` — `tcp_max_syn_backlog`, `tcp_syncookies=1`)

## 신규 보안장비 계정 관리 (12-12)

① 기본 관리자 **계정명 변경** ② 기본 패스워드를 복잡도 규칙 맞춰 변경 ③ 계정별 최소권한 부여(역할 분리)
④ 불필요·미사용 계정 삭제·잠금 ⑤ 세션 타임아웃·접속 IP 제한 ⑥ 로그인 실패 잠금·감사 로그 활성화.

## SW 패치 종류 (27-9)

- **핫픽스(Hot Fix)**: 즉시 교정이 필요한 주요 취약점용 긴급 패치. 서비스팩 이후 추가로 별도 배포.
- **업데이트(Update)**: 문제 예방·해결을 위해 정기적으로 배포되는 패치.
- **서비스팩(Service Pack)**: 그간의 패치·핫픽스를 누적해 묶은 대규모 패치.
- **패치 관리 시스템(PMS)**: 다수 시스템의 패치 배포·검증을 중앙 관리.
