## CC (Common Criteria, 공통평가기준 · ISO/IEC 15408)

정보보호 제품·시스템의 보안 기능을 **국가 간 상호인정**하기 위한 평가 기준.
> 시험 함정: "ISO-15504 인증"이라고 물어도 정답은 **CC 인증**(15408). 15504는 SPICE(SW 프로세스 성숙도)와 혼동을 노린 것.

### 3대 구성 요소 (자주 빈칸으로 출제)

| 약어 | 명칭 | 정의 |
|---|---|---|
| **PP** | 보호 프로파일 (Protection Profile) | 특정 제품군(소비자)의 요구에 맞춘 **구현 독립적** 보안 요구사항의 집합 |
| **ST** | 보안목표 명세서 (Security Target) | 식별된 **평가대상(TOE)** 평가의 근거가 되는 보안 요구사항 + 구현 명세 |
| **EAL** | 평가보증등급 (Evaluation Assurance Level) | 미리 정의된 보증 수준을 갖는 보증 컴포넌트 패키지. **EAL1 ~ EAL7** |

- 외우는 법: PP는 "사고 싶은 사람의 요구서"(구현 무관), ST는 "만든 제품의 답안지"(TOE 종속), EAL은 "점수".
- TOE(Target of Evaluation): 평가 대상이 되는 제품 또는 시스템.
- **SFR**(Security Functional Requirement, 보안기능요구사항) / **SAR**(Security Assurance Requirement, 보안보증요구사항)로 요구사항을 분류.
- ST는 PP를 만족(claim)할 수 있음. 개발자가 ST 작성 → 평가기관이 TOE를 ST 기준으로 평가.

### EAL 1~7 등급 의미

| 등급 | 수준 | 개념 |
|---|---|---|
| **EAL1** | 기능 시험 | 최소한의 신뢰, 문서 검토 위주 |
| **EAL2** | 구조 시험 | 개발자 시험 + 취약성 분석 |
| **EAL3** | 체계적 시험·점검 | 개발 환경 통제 확인 |
| **EAL4** | 체계적 설계·시험·검토 | **상용 제품이 경제적으로 도달 가능한 최고 수준**(국내 대부분 국정원 인증 제품이 여기) |
| **EAL5** | 준정형화된 설계·시험 | 준정형 명세 |
| **EAL6** | 준정형화된 검증 설계·시험 | 고위험 환경 |
| **EAL7** | 정형화된 검증 설계·시험 | **수학적 정형 명세·검증**, 극히 제한적 |

- EAL이 높다 = 보안기능이 강하다(X) → **평가·검증에 들인 보증 수준이 높다(O)**.

### CC 관련 체계

- **CCRA** (CC 상호인정협정): 회원국 간 EAL2까지(또는 cPP 기반) 인증서 상호 인정.
- 국내: **IT보안인증사무국(ITSCC)** 정책, KISA·한국시스템보증 등 평가기관, **국가정보원**이 국가·공공용 제품 검증(CCRA + 국내용 CC).
- **국내용 CC 평가·인증**: 국가·공공기관 도입 정보보호제품은 CC 인증 또는 보안기능 확인서 필요.

## CVSS (Common Vulnerability Scoring System)

취약점의 심각도를 **0.0 ~ 10.0** 으로 점수화하는 표준.

- **기본(Base) 그룹**: 공격 벡터·공격 복잡도·권한·사용자 상호작용 + CIA 영향도 → 변하지 않는 고유 심각도
- **시간성(Temporal) 그룹**: 익스플로잇 성숙도, 패치(대응) 가능성, 신뢰도 → 시간에 따라 변동
- **환경(Environmental) 그룹**: 자산 중요도·조직 환경 반영
- 등급: 0.0 없음 / 0.1~3.9 낮음 / 4.0~6.9 중간 / 7.0~8.9 높음 / 9.0~10.0 긴급
- 17회 5번 지문의 "코드베이스·시간성·악영향·환경적 요소"가 곧 CVSS 그룹 구성.
- 기본 메트릭 벡터 예: `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H` = 9.8(Critical).
  - AV(공격 벡터): N 네트워크 / A 인접 / L 로컬 / P 물리
  - AC(복잡도) L·H, PR(권한) N·L·H, UI(사용자 상호작용) N·R, S(범위) U·C

### 기타 취약점·위협 식별 체계

| 약어 | 의미 |
|---|---|
| **CVE** | 개별 취약점 식별번호 (`CVE-2021-44228`) — MITRE |
| **CWE** | 취약점의 **유형(원인) 분류** (`CWE-89` SQL Injection) |
| **CVSS** | 취약점 **심각도 점수**(0~10) |
| **CPE** | 제품·플랫폼 식별 표기 |
| **CCE** | 시스템 **보안 설정** 항목 식별 |
| **CAPEC** | 공격 패턴 분류 |
| **CVE·CWE·CVSS·CPE** 를 모아 제공 = **NVD**(미 NIST), 국내는 **KISA 취약점 정보포털** |
