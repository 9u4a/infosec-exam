## 해시함수 요구조건

| 성질 | 의미 |
|---|---|
| **압축성** | 임의 길이 입력 → 고정 길이 출력 |
| **효율성(계산 용이)** | h(x) 계산이 빠름 |
| **역상 저항성(일방향성)** | h(x)=y 일 때 y로부터 x 찾기 불가 (preimage) |
| **제2 역상 저항성(약한 충돌 저항성)** | x가 주어질 때 h(x)=h(x')인 x'≠x 찾기 불가 |
| **충돌 저항성(강한 충돌 저항성)** | h(x)=h(x')인 임의의 쌍 (x, x') 찾기 불가 |

## 생일 공격 (Birthday Attack)

- n비트 해시의 충돌을 찾는 데 약 **2^(n/2)** 번의 시도면 충분(생일 역설).
- 따라서 128비트 해시(MD5)의 충돌 저항성은 실질 **64비트** → 취약.
- 안전한 해시는 **256비트 이상**(SHA-256) 권장.

## 주요 해시 알고리즘

| 알고리즘 | 출력 | 상태 |
|---|---|---|
| MD5 | 128비트 | **충돌 발견(2004) — 사용 금지** |
| SHA-1 | 160비트 | **충돌 발견(2017, SHAttered) — 폐기** |
| SHA-2 (SHA-224/256/384/512) | 224~512 | 안전, 현재 표준 |
| SHA-3 (Keccak) | 224~512 | 스펀지 구조, SHA-2 대안 |
| **HAS-160** | 160비트 | 국산(KCDSA용) |
| RIPEMD-160 | 160비트 | 비트코인 주소 등 |

- 비밀번호 저장: 일반 해시 ✗ → **bcrypt / scrypt / Argon2 / PBKDF2** (솔트 + 의도적 반복).

## MAC (메시지 인증 코드)

메시지 + **비밀키**로 생성하는 인증 태그 → **무결성 + (송신자) 인증**. (부인방지 ✗ — 키를 둘 다 갖고 있음)

| 종류 | 방식 |
|---|---|
| **HMAC** | 해시 함수 기반 (`H(K⊕opad ‖ H(K⊕ipad ‖ M))`). 가장 널리 쓰임 |
| **CMAC / CBC-MAC** | 블록 암호(AES) 기반 |
| **GMAC** | 갈루아 필드 기반, GCM 모드의 인증부 |

- **AEAD**(인증 암호): 암호화 + 무결성을 한 번에. AES-GCM, ChaCha20-Poly1305.
- MAC vs 전자서명: MAC은 대칭키(빠름, 부인방지 ✗), 서명은 공개키(느림, 부인방지 ✓).
- 해시 vs MAC vs 서명: 해시(키 없음, 무결성만) < MAC(대칭키) < 서명(공개키, 부인방지).

## 키 관리 생명주기

**생성 → 분배(전달) → 저장 → 사용 → 갱신(교체) → 폐기(파기) → 복구/보관**

- **키 길이**: 대칭 128비트+, RSA 2048비트+, ECC 256비트+.
- **키 분리 원칙**: 용도별로 다른 키(암호화 키 ≠ 서명 키 ≠ KEK).
- **KEK (Key Encrypting Key)**: 데이터 암호화 키(DEK)를 다시 암호화해 보관.
- **키 위탁(Key Escrow)**: 키를 신뢰기관에 분할 보관 → 합법적 감청·복구. 프라이버시 논란.
- **HSM (Hardware Security Module)**: 키 생성·저장·연산을 전용 하드웨어에서 (변조 방지).

## 키 분배 프로토콜

| 프로토콜 | 특징 |
|---|---|
| **KDC (키 분배 센터)** 방식 | 중앙 서버가 세션키 분배. Kerberos의 기반. KDC가 SPOF |
| **Needham-Schroeder** | KDC 기반 세션키 분배 + 상호 인증. **재전송 공격 취약**(옛 세션키 재사용) |
| **Kerberos** | Needham-Schroeder + **타임스탬프**로 재전송 방지 (접근통제-모델 노트) |
| **Diffie-Hellman** | KDC 없이 두 당사자가 키 합의 (인증 필요) |
| **공개키 기반 분배** | 상대 공개키로 세션키 암호화 전송 |

## 난수 생성

- **PRNG(의사난수)**: 시드로부터 결정적 생성 → 시드 노출 시 예측 가능.
- **CSPRNG(암호학적 안전 PRNG)**: 다음 비트 예측 불가, 역추적 불가. `/dev/urandom`, CTR_DRBG.
- 약한 난수 = 키·IV·논스·세션 ID 예측 → 심각한 취약점.
