## 전자서명 개념

메시지의 **해시값을 서명자의 개인키로 암호화**한 것. 검증자는 서명자 공개키로 복호화해 해시 비교.

### 제공하는 보안 서비스

| 서비스 | 설명 |
|---|---|
| **무결성** | 서명 후 변조 시 해시 불일치 |
| **인증(사용자 인증)** | 개인키 보유자만 서명 가능 |
| **부인방지** | 서명자가 나중에 "안 했다" 부인 불가 |
| (기밀성 ✗) | 전자서명 자체는 기밀성 제공 안 함 → 별도 암호화 필요 |

### 전자서명 요구조건

- **위조 불가**, **서명자 인증**, **부인 방지**, **변경 불가**(서명 후 문서 수정 불가), **재사용 불가**(다른 문서에 전용 불가)

### RSA 서명 vs DSA/KCDSA

- **RSA 서명**: 서명 = 검증의 역연산, 서명·암호화 동시 가능
- **DSA**: 이산대수 기반, 서명 전용(암호화 불가), 서명 생성 빠름·검증 느림
- **KCDSA / EC-KCDSA**: 국산 전자서명 표준

## 특수 전자서명

| 종류 | 설명 |
|---|---|
| **은닉 서명 (Blind Signature)** | 서명자가 **내용을 모른 채** 서명 (전자화폐·전자투표의 익명성) |
| **이중 서명 (Dual Signature)** | **SET**에서 사용. 주문정보(OI)와 지불정보(PI)를 각각 해시 → 연결 해시에 서명 → 상점은 PI를, 은행은 OI를 못 봄 |
| **부인방지 서명** | 서명자 협조 없이는 검증 불가 (확인 프로토콜 필요) |
| **위임 서명 (Proxy Signature)** | 원 서명자가 대리인에게 서명 권한 위임 |
| **다중 서명** | 여러 명이 하나의 문서에 서명 |
| **수신자 지정 서명** | 지정된 검증자만 확인 가능 |
| **일회용 서명 (Lamport)** | 해시 기반, 1회만 사용 |

## PKI (공개키 기반구조)

공개키와 사용자 신원을 **인증서**로 묶어 신뢰를 제공하는 체계.

| 구성요소 | 역할 |
|---|---|
| **CA (인증기관)** | 인증서 발급·폐지·갱신, 최상위는 Root CA |
| **RA (등록기관)** | 신원 확인 대행 (CA 위임), 인증서 발급 신청 접수 |
| **저장소 (Repository, Directory)** | 인증서·CRL 공개 (LDAP, X.500) |
| **PKI 이용자** | 인증서 소유자, 검증자 |
| (국내) **최상위 인증기관** | 한국인터넷진흥원(KISA) |

### 신뢰 모델

- **계층(Hierarchical)**: Root CA → 중간 CA → 사용자. 단일 신뢰점.
- **네트워크/상호인증(Mesh)**: CA끼리 교차 인증.
- **웹 오브 트러스트**: PGP, 사용자 상호 서명 (CA 없음).
- **브리지 CA**: 서로 다른 PKI 도메인을 연결.

## X.509 인증서

주요 필드: **버전, 일련번호, 서명 알고리즘, 발급자(Issuer) DN, 유효기간, 주체(Subject) DN, 주체 공개키 정보, 확장 필드(Key Usage, SAN, CRL 배포점 등), CA의 전자서명**.

### 인증서 검증 절차

1. 인증서 **서명**을 상위 CA 공개키로 검증 (체인을 Root까지)
2. **유효기간** 확인
3. **폐지 여부** 확인 (CRL 또는 OCSP)
4. 용도(**Key Usage**)·이름(**SAN/CN**) 일치 확인
5. Root CA가 **신뢰 저장소**에 있는지 확인

### 인증서 폐지

| 방식 | 설명 |
|---|---|
| **CRL (인증서 폐지 목록)** | CA가 주기적으로 폐지된 인증서 일련번호 목록 발행. 크기 큼, 실시간성 낮음 |
| **Delta CRL** | 마지막 CRL 이후 변경분만 |
| **OCSP (온라인 인증서 상태 프로토콜)** | 검증자가 OCSP 응답자에게 실시간 질의(good/revoked/unknown). 응답자 부하·프라이버시 이슈 |
| **OCSP Stapling** | 서버가 미리 받은 OCSP 응답을 TLS 핸드셰이크에 첨부 → 클라이언트 질의 불필요 |

- 폐지 사유: 개인키 유출, 소속 변경, CA 손상, 정보 변경 등.

## 전자서명법 (국내)
