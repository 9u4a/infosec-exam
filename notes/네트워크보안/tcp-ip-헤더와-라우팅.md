## TCP 3-way / 4-way (8-6, 10-14)

```
연결:  C→S  SYN            SEQ=x
      S→C  SYN+ACK        SEQ=y   ACK=x+1
      C→S  ACK            SEQ=x+1 ACK=y+1
해제:  C→S  FIN+ACK
      S→C  ACK
      S→C  FIN+ACK
      C→S  ACK              (→ TIME_WAIT)
```
- 상대 SEQ에 **+1** 한 값이 ACK (SYN·FIN은 1바이트를 소비).
- 예) `S→C SYN+ACK(SEQ=2324, ACK=3479)` 였다면 앞서 `C→S SYN(SEQ=3478)`, 다음 `C→S ACK(SEQ=3479, ACK=2325)`.

## TCP 플래그 6비트 (23-14)

| 플래그 | 의미 |
|---|---|
| **URG** | 긴급 데이터 존재 (Urgent Pointer 유효), 우선 처리 |
| **ACK** | 확인 응답 번호 유효. 받은 SEQ+1 로 응답 |
| **PSH** | 버퍼링 말고 즉시 상위 애플리케이션으로 전달 |
| **RST** | 비정상 세션 강제 종료(리셋) |
| **SYN** | 연결 요청 + 순서번호 동기화 |
| **FIN** | 정상 연결 종료 요청 |

- 비트열 예: SYN=`000010`, SYN+ACK=`010010`, ACK=`010000`, FIN+ACK=`010001` (URG ACK PSH RST SYN FIN 순).

## IP 단편화 (9-5) — tcpdump `frag 95: 1480 @ 2920+`

| 값 | 의미 |
|---|---|
| `95` | **Fragment ID** — 같은 원본 패킷에서 나온 단편임을 식별 |
| `1480` | 이 단편의 **데이터 크기**(바이트) |
| `2920` | **Fragment Offset** — 원본에서 이 단편이 시작되는 위치(바이트) |
| `+` | **MF(More Fragments)=1** — 뒤에 단편이 더 있음 (마지막은 `+` 없음) |

- Offset은 헤더에 8바이트 단위로 저장(2920 = 365 × 8).
- 단편화 악용: Teardrop(offset 중첩), Tiny Fragment(헤더 분할로 필터 우회), Ping of Death(재조합 65535 초과).

## 서브넷 마스크 (25-8)

`255.255.255.192` → `11111111.11111111.11111111.11000000` (/26).
- 마지막 옥텟 192 = 128+64 = `11000000`. 호스트 6비트 → 서브넷당 64개(사용 62개), 4개 서브넷.
- 자주 나오는 값: 128=`10000000`(/25), 192=`11000000`(/26), 224(/27), 240(/28), 248(/29), 252(/30).

## 라우팅 테이블 조회 (6-4) — `netstat -rn`

목적지 IP에 대해 **가장 구체적인(prefix가 긴) 경로**를 선택.
1. 호스트 라우트(`/32`, Genmask 255.255.255.255) 우선
2. 없으면 네트워크 라우트(`/24` 등)
3. 그래도 없으면 **Default Gateway**(`0.0.0.0/0`)

## 내부 라우팅 프로토콜 (22-1)

| 프로토콜 | 알고리즘 | 특징 |
|---|---|---|
| **RIP** | 거리 벡터 (홉 수) | 가장 오래됨, 최대 15홉, 30초마다 전체 테이블 브로드캐스트 |
| **OSPF** | 링크 상태 (Dijkstra) | 변화 시에만 LSA 전파, 대규모망, Area 분할 |
| **EIGRP** | 하이브리드 (DUAL) | Cisco 전용, 빠른 수렴 |
| (외부) **BGP** | 경로 벡터 | AS 간 라우팅, 인터넷 백본 |

## RARP (27-2)

**MAC → IP** 를 얻는 프로토콜 (ARP의 반대). 디스크리스 워크스테이션·네트워크 부팅 장비가 자기 IP를 모를 때 사용. 현재는 BOOTP·DHCP로 대체.
