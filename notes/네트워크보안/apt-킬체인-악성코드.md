## APT (지능형 지속 위협)

특정 표적 + 다양한 기법(제로데이·스피어피싱·워터링홀) + **장기간 은밀** 침투 후 내부 이동·정보 수집·유출.
- 단발성 공격과 차이: **표적성 + 지속성 + 은밀성**

## 사이버 킬체인 (록히드마틴, 7단계)

정찰 → 무기화 → 전달(배달) → 취약점 공격(익스플로잇) → 설치 → **C2(명령·제어)** → 표적 행동

> 어느 한 단계만 확실히 끊어도 최종 목표 달성 차단

- **MITRE ATT&CK**: 각 단계의 구체적 전술(Tactic)·기술(Technique) 매트릭스 — 탐지 커버리지 평가·위협 헌팅
- **Unified Kill Chain**: 킬체인 확장 14단계

## 회피 · 지속 기법

| 기법 | 설명 |
|---|---|
| **DGA** (Domain Generation Algorithm) | 매일 수천 개 도메인 생성 → 하나로 C2 접속 → 블랙리스트 회피 |
| **Pass the Hash** | LSASS 메모리의 NTLM 해시를 그대로 제출해 원격 인증 (크래킹 불필요) |
| **Living off the Land** | PowerShell·WMI 등 정상 도구로 공격 (파일리스) |
| **자동실행 레지스트리** (Run 키) | 재부팅 후에도 지속 |

## 악성코드 유형

| 유형 | 설명 |
|---|---|
| **바이러스** | 숙주 파일에 기생, 사용자 실행으로 전파 |
| **웜** | 자가 복제, 네트워크로 자동 전파 |
| **트로이목마** | 정상 프로그램 위장, 자가 복제 없음 |
| **드롭퍼** | payload를 품고 있다가 시스템에 떨어뜨려 설치 |
| **인젝터** | 파일 없이 정상 프로세스 메모리에 코드 주입 |
| **다운로더** | payload를 원격에서 받아옴 |
| **루트킷** | 커널·명령어(ps/ls/netstat) 변조로 은닉 |
| **랜섬웨어** | 파일 암호화 후 금전 요구 |
| **백도어** | 정상 인증 우회 원격 접속 통로 |
| **봇/좀비** | C2 명령을 받는 감염 호스트 (봇넷) |

## 대응

다층 방어(Defense in Depth), EDR/샌드박스(행위 기반), 망분리, 최소권한, 이상행위 분석(UEBA), 패치·백업.
