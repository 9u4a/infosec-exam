> 무선랜-보안 노트가 Wi-Fi 전용이라 별도. 필기 단골.

## 블루투스 (Bluetooth)

- 2.4GHz ISM 대역, **주파수 호핑(FHSS)**, 클래스별 도달거리(1m~100m).
- 페어링: 레거시(PIN) → **SSP(Secure Simple Pairing)** — Numeric Comparison / Passkey / Just Works / OOB.
- BLE(저전력)는 IoT·웨어러블에 광범위.

### 블루투스 공격

| 공격 | 설명 |
|---|---|
| **블루재킹 (Bluejacking)** | 비인가 기기에 **스팸 메시지·명함** 푸시 (피해 경미) |
| **블루스나핑 (Bluesnarfing)** | 페어링 없이 연락처·문자·일정 등 **데이터 탈취** |
| **블루버깅 (Bluebugging)** | 기기를 **원격 제어**(통화·문자 발신, 도청) |
| **블루프린팅** | 기기 정보(제조사·모델) 수집(정찰) |
| **BlueBorne** | 페어링 없이 취약점으로 RCE (2017) |
| **KNOB** | 암호화 키 엔트로피를 1바이트로 강제 다운그레이드 |

- 대응: 비사용 시 **비활성**, 검색 불가(non-discoverable) 모드, "Just Works" 지양, 최신 패치, 알 수 없는 페어링 거부.

## RFID

- 태그(안테나+칩) ↔ 리더 무선 인식. 수동형(배터리 없음)/능동형.
- 주파수: LF(125kHz, 출입증) / HF(13.56MHz, 교통·NFC) / UHF(900MHz, 물류) / 마이크로파.

### RFID 보안 위협·대응

| 위협 | 대응 |
|---|---|
| 스키밍(무단 판독), 도청 | 암호화, 접근제어, 거리 제한 |
| 태그 복제·위조 | 상호 인증, 챌린지-응답, 디지털 서명 |
| 위치 추적(프라이버시) | **Kill 명령**(폐기 시 비활성), 블로커 태그, 패러데이 케이지 |
| 스푸핑·재전송 | 논스·타임스탬프 |

- 경량 암호(**HIGHT**, PRESENT)로 저전력 태그 보호.

## NFC (Near Field Communication)

- RFID HF(13.56MHz) 기반, **~4cm 초근거리**. 결제·태그·P2P.
- 모드: Reader/Writer, P2P, Card Emulation(모바일 결제 — Secure Element/HCE).
- 위협: 도청(근거리라 제한적), 데이터 변조·삽입, 릴레이 공격(중계로 거리 위장), 악성 태그(피싱 URL).
- 대응: 보안 채널(NFC-SEC), 결제는 SE에 격리, 태그 서명 검증.

## Zigbee / 저전력 메시

- IEEE 802.15.4 기반, **저전력·저대역·메시 네트워크**(스마트홈, 센서망).
- 보안: AES-128 CCM*, 네트워크 키·링크 키. 초기 키 배포·조인 과정이 약점(오픈 조인, 키 스니핑).
- 유사: **Z-Wave, Thread, LoRaWAN**(광역 저전력).

## 이동통신(LTE/5G) 보안 개요

- 상호 인증(USIM 기반 AKA), 무선 구간 암호화, 무결성 보호.
- 5G: **가입자 영구 식별자(SUPI) 암호화(SUCI)** 로 IMSI 캐처(스팅레이) 방어, 네트워크 슬라이싱 격리.
