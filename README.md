## 정보보안기사 실기 트랙

- **기출문제 1~32회 · 532문항** — 5개 출제영역(시스템/네트워크/애플리케이션/정보보안일반/관리및법규) 분류 + 전 문항 해설
- **학습 노트 70개** — 기출 문항과 상호 연결, 시험범위 보충 노트 포함
- **예상문제 186문항** — 기출·노트 기반 신규 집필(단답 123 / 서술 42 / 실무 21, 모의고사 10회분). ⚠ AI 작성 예측 문항으로 실제 출제·정답을 보장하지 않음
- **모의고사(`#/mock`)** — 예상문제에서 18문항(단답 12·서술 4·실무 2)을 영역·유형 균형으로 매번 새로 추출, 180분 타이머, 60점 합격 판정. 필답형이라 자가채점(2023 배점: 단답 3 / 서술 12 / 실무 16, 실무형은 2문제 중 1개만 채점)

### 기능

- **풀기**: 회차별 / 영역별 / 유형별 / 예상문제 / 오답만 / 애매함만 / 즐겨찾기만 / 푼 문항만 / 안 푼 문항만 / 랜덤 범위 선택 (`예상문제도 포함` 토글)
- 문제는 기본 **정답 숨김** → "정답 보기" 클릭 시 펼침 (설정에서 항상 펼침 가능)
- **자가채점 3단계**: ⭕ 맞음 / 🔺 애매함 / ❌ 틀림 → 세션 제출 시 요약(점수·영역별 성적·오답 바로가기)
- **이어풀기**: 진행 중 세션은 자동 저장, 홈의 "이어풀기" 카드로 재개 (모의고사는 타이머까지 복원)
- **지난 풀이 기록**(`#/history`): 제출한 세션·모의고사의 점수창을 언제든 그대로 다시 열람 (채점 스냅샷 고정)
- **통계**: 총 시도·진도·완주 회차, 문항별 오답 랭킹, 영역·유형·회차별 정답률, 최근 14일 학습량, 예상문제·모의고사 추이(기출 통계와 분리)
- **통합 검색**(`#/search`): 문제·정답·해설·보충지문·노트·예상문제 전체 AND 부분일치
- **문항 직링크**(`#/q/<id>`), **즐겨찾기(★)**, 문제별 메모
- 진행 데이터는 브라우저 localStorage. 더보기 > 내보내기/가져오기(JSON)로 기기 간 이동

## CPPG(개인정보관리사) 트랙

- **5과목 · 5지선다 800문제** (과목별 160/170/210/160/100) — 답 선택 즉시 자동채점, 해설·오답 근거 포함
- **학습 노트 75개** (참고자료 카테고리 10개 포함: 조문 인덱스·개정 타임라인·핵심 수치 치트시트·GDPR 대조표 등)
- **모의고사** — 과목별 출제비율(20/20/25/20/15%)로 100문항 배분 + 120분 타이머 + 총점 60점·과목별 40% 과락 판정
- **연습문제**: 과목 / 노트 / 태그 / 오답 / 안 푼 문제 / 랜덤 범위, 즉시 공개 토글
- **통계**: 과목별 정답률, 오답 랭킹, 모의고사 총점 추이
- ⚠ 개인정보보호법은 개정이 잦다. 노트·해설은 조문 번호 + 기준 시점 + 고시번호를 명시하며 **현행/종전 기준을 병기**한다. 최종 정답은 국가법령정보센터(law.go.kr) 현행 조문·시행처 자료로 교차 확인 필요 — 정답 보증 불가

## 구조

```
실기/N회(YYYY-MM-DD)/N.json   정보보안기사 원본 기출 (수정 금지)
meta/N.json                   기출 영역 분류 + 해설 (문항번호로 조인)
notes/<영역>/<슬러그>.md        기사 학습 노트
예상문제/<영역>.json            기사 모의고사용 신규 예상문제 (원본과 별개)
cppg/subjects.json            CPPG 과목·모의고사 배분·합격기준 (단일 출처)
cppg/notes/<과목>/<슬러그>.md   CPPG 학습 노트 (참고자료 카테고리 포함)
cppg/quiz/<과목id>.json        CPPG 5지선다 문제
cppg/자료/*.pdf                CPPG 법령 원문 PDF (1차 사료)
scripts/build.mjs             모든 소스 → docs/data/bundle.js · docs/data/cppg.js
docs/                         GitHub Pages 발행 루트
```

빌드 산출물 `docs/data/bundle.js`·`docs/data/cppg.js` 는 **커밋한다** (GitHub Pages는 빌드를 돌리지 않음).
자세한 규칙과 스키마는 [`CLAUDE.md`](CLAUDE.md) 참고.

## 로컬 실행

```bash
node scripts/build.mjs                        # 데이터 번들 재생성 (참조 오류 시 경고)
python -m http.server 8080 --directory docs   # http://localhost:8080  (file:// 은 불가)
```

같은 Wi-Fi의 폰에서 확인: `http://<PC-IP>:8080` (`ipconfig` 로 IPv4 확인)

## 배포

`main` 브랜치 push → GitHub Pages가 `/docs` 를 서빙. 데이터·노트·코드를 수정하면:

```bash
node scripts/build.mjs
git add -A && git commit -m "..." && git push
```

- 앱 셸(html/css/js)을 바꾸면 `docs/sw.js` 의 `CACHE` 버전을 올릴 것 (`bundle.js`·`cppg.js` 는 네트워크 우선이라 무관)

## 콘텐츠 추가

**기사 노트** — `notes/시스템보안/새노트.md`:

```markdown
---
title: 표시 제목
domain: 시스템보안
questions: [1-8, 27-5]   # "회차-문항번호" (역인덱싱해 각 문항에 노트 링크 자동 연결)
tags: [태그1, 태그2]
---
본문 마크다운...
```

**기사 예상문제** — `예상문제/<영역>.json` 의 `items[]` 에 추가:

```json
{ "id": "y-sys-001", "type": "단답형",
  "question": "...", "answer": "정답 : ...", "explanation": "...",
  "notes": ["시스템보안/리눅스-유닉스-로그파일"], "tags": ["로그"] }
```

**CPPG 문제** — `cppg/quiz/<과목id>.json` 의 `items[]` 에 추가 (문제→노트 연결은 문제의 `note` 필드).

수정 후 `node scripts/build.mjs` 를 실행하면 참조 오류·누락이 경고로 표시된다.
