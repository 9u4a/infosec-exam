## 위치별 분류

| | HIDS (호스트 기반) | NIDS (네트워크 기반) |
|---|---|---|
| 설치 | 서버 각각 | 세그먼트당 1대 (미러/TAP 포트) |
| 분석 | 시스템 콜, 파일 무결성, 로그, 레지스트리, 권한 탈취 | 패킷 페이로드 |
| 암호화 트래픽 | 내부에서 복호화 후 확인 가능 | **불가** (스위칭 환경도 한계) |
| 예 | Tripwire, OSSEC | Snort, Suricata |

## 탐지 방식

| 방식 | 원리 | 장점 | 단점 |
|---|---|---|---|
| **오용(Misuse) / 지식기반 / 시그니처** | 알려진 공격 패턴과 비교 | 오탐 낮음, 명확 | 미지·변형 공격 탐지 불가, 지속적 룰 업데이트 |
| **이상(Anomaly) / 행위기반 / 통계** | 정상 프로파일 학습 → 벗어나면 탐지 | 미지의 공격 탐지 가능 (제로데이) | 오탐 높음, 정상 기준 설정 어려움 |

## 오탐 vs 미탐

| | 정의 | 영향 |
|---|---|---|
| **오탐 (False Positive)** | 정상을 공격으로 판단 | 경보 피로, 운영 방해 |
| **미탐 (False Negative)** | 공격을 정상으로 판단 | **침해 방치 (더 위험)** |

시그니처 기반 → 미탐↑ / 이상탐지 기반 → 오탐↑. 룰 튜닝으로 균형.

## IDS vs IPS 배치 (13회)

- **IPS**: 실시간 **차단** 목적 → **인라인**(트래픽 경로), 외부·내부 접점에 배치. 내부망에 두면 오탐 시 정상 통신 장애 위험. 장애 시 SPOF
- **IDS**: **탐지·경보** 목적 → 포트 미러링(아웃오브밴드), 업무 흐름에 영향 없이 분석. 내부망 모니터링에 적합

## IDS 대응 행위 (25회)

경보(메일·SMS·콘솔) / 로깅(포렌식 자료) / 세션 강제 종료(RST) / 방화벽·라우터 연동 차단 / SIEM 상관분석

## NIDS 설치 위치 (네트워크 존별)

| 위치 | 목적 |
|---|---|
| **방화벽 바깥(인터넷 구간)** | 시도되는 모든 공격 관측(정찰·스캔 포함), 경보량 많음 |
| **방화벽 안쪽(내부망 진입점)** | 방화벽을 **통과한** 실제 위협만 → 경보 신뢰도↑, 가장 일반적 |
| **DMZ** | 공개 서버(웹·메일·DNS) 대상 공격 탐지 |
| **내부 세그먼트** | 내부자 위협·측면 이동(lateral movement) 탐지 |

- 스위치 환경 → **포트 미러링(SPAN)** 또는 **네트워크 TAP** 으로 트래픽 복제 수집.

## 탐지 이론 세부

- **오용 탐지 기법**: 시그니처(패턴 매칭), 전문가 시스템(규칙), 상태 전이 분석, 페트리넷
- **이상 탐지 기법**: 통계적 분석, 기계학습/신경망, 데이터 마이닝, 임계치(threshold) 기반
- **정탐(True Positive)** / **정탐거부(True Negative)** 포함 4분면. **정확도 = (TP+TN)/전체**.

## 허니팟 / 허니넷

- **허니팟(Honeypot)**: 의도적으로 취약하게 꾸민 미끼 시스템 → 공격자 유인, 수법·도구 수집, 실제 자산 시간 벌기.
- **저상호작용**(서비스 에뮬레이션, 안전) vs **고상호작용**(실제 OS, 정보 풍부하나 장악 위험).
- 허니넷: 허니팟 여러 대로 구성한 가짜 네트워크. **허니토큰**: 미끼 데이터·계정.

## 관련 솔루션

- **NAC**: 네트워크 진입 시 단말 인증 + 보안 상태 점검 (인라인 / 아웃오브밴드)
- **UTM**: 방화벽+IPS+안티바이러스+VPN+웹필터 통합(중소 규모, 성능 트레이드오프)
- **NGFW**: 애플리케이션 인식·사용자 인식·IPS 내장 차세대 방화벽
- **SIEM**: 이기종 로그 수집·상관분석 / **SOAR**: 대응 자동화 / **EDR**: 엔드포인트 행위 탐지
