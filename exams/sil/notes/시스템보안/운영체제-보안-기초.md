## 보호 링 (Protection Ring)

CPU가 제공하는 특권 수준. x86은 Ring 0~3.
- **Ring 0**: 커널 (모든 명령·메모리 접근)
- **Ring 3**: 사용자 애플리케이션
- Ring 1·2: 드라이버·서비스(대부분 OS는 0/3만 사용)
- 하이퍼바이저는 Ring -1(VMX root), SMM은 Ring -2 로 표현하기도.
- 사용자→커널 전환은 **시스템 콜(트랩)** 을 통해서만.

## 참조 모니터 (Reference Monitor)

주체가 객체에 접근할 때마다 **접근 규칙을 강제하는 추상 개념**.

| 요건 | 의미 |
|---|---|
| **격리성 (Isolation, 부정조작 방지)** | 변조·우회 불가 |
| **완전성 (Completeness, 항상 호출)** | 모든 접근이 반드시 참조 모니터를 거침 |
| **검증가능성 (Verifiability)** | 작고 단순해 정확성 분석·시험 가능 |

- 참조 모니터를 구현한 하드웨어·소프트웨어·펌웨어 = **보안 커널 (Security Kernel)**.

## TCB (Trusted Computing Base)

시스템의 보안 정책을 강제하는 **모든 보호 메커니즘의 집합**(HW+SW+펌웨어).
- TCB가 작고 검증될수록 신뢰도↑ → **최소화**가 원칙.
- 보안 경계(security perimeter)가 TCB와 비-TCB를 구분.

## TPM (Trusted Platform Module)

메인보드에 탑재된 **암호 연산·키 저장 전용 칩**(TCG 표준).
- 기능: 키 생성·봉인(sealing), 무결성 측정값 저장(**PCR**), 원격 증명(attestation), 난수 생성.
- **신뢰 부팅(Measured Boot)**: 부팅 각 단계(펌웨어→부트로더→커널)의 해시를 PCR에 누적 → 변조 탐지.
- **BitLocker·디스크 암호화 키**를 TPM에 봉인 → 디스크만 탈취해도 복호화 불가.
- Secure Boot(서명된 부트로더만 실행)와 함께 루트킷·부트킷 방어.

## 신뢰 컴퓨팅 관련 하드웨어

- **HSM**: 서버용 키 관리 전용 장비(FIPS 140-2/3 인증).
- **TEE (Trusted Execution Environment)**: ARM TrustZone, Intel SGX — 일반 OS와 격리된 보안 영역에서 코드·데이터 처리.
- **Secure Element**: 스마트카드·모바일의 변조 방지 칩.

## 보안 평가 기준의 역사

| 기준 | 지역/특징 |
|---|---|
| **TCSEC (Orange Book)** | 미국 국방부(1985). 기밀성 중심. **D < C1 < C2 < B1 < B2 < B3 < A1** (7등급). C2 = 임의적 접근통제 + 감사 |
| **ITSEC** | 유럽(1991). 기능(F)과 보증(E1~E6) 분리, 기밀성·무결성·가용성 |
| **CC (ISO 15408)** | 국제 통합(1999~). PP/ST/**EAL1~7** → cc-보안성평가 노트 |

- TCSEC B1부터 **강제적 접근통제(MAC)** + 보안 레이블 요구.
