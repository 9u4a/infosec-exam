**21·27회 반복 출제.** 미러 정의 / 장단점 각 2개 / RTO 가장 긴 방식.

**핵심 정답**
- **미러 사이트 정의**: 주센터와 동일 수준 시스템을 백업센터에 구축, **Active-Active로 실시간 동시 서비스**.
- **장점**: 신속한 업무 재개(RTO 즉시), 데이터 최신성 보장(RPO 0).
- **단점**: 초기 투자·유지보수 비용 높음, 데이터 갱신 많으면 동기화 과부하.
- **RTO 가장 긴 방식 = 콜드 사이트**: 데이터만 원격 보관하고 정보자원은 최소만 확보 → 재해 시 장비 조달·구성·복구에 오랜 시간(수주).

**함정**: 미러의 단점 = 비용 + 동기화 부하. → [🔗 재해복구센터(DRS) 유형 — 미러 · 핫 · 웜 · 콜드](#/note/%EB%B0%98%EB%B3%B5%EC%B6%9C%EC%A0%9C%2F%EC%9E%AC%ED%95%B4%EB%B3%B5%EA%B5%AC-%EC%82%AC%EC%9D%B4%ED%8A%B8-%EC%9C%A0%ED%98%95)
