## 한 줄 정의

**누가 접근하나(계정·SSO·OTP)** 를 다루는 인증 관리 + 시험에 자주 끼어드는 **단답형 용어 모음**이다. 앞부분은 *EAM/IAM · SSO 방식 · OTP* 의 구분을, 뒷부분은 *블록체인 · 전자서명법 · 생체정보 원칙 · 단답 용어* 를 묻는다. {{9-11}} {{16-10}} {{20-7}} {{25-2}} {{30-8}} {{30-13}} {{31-15}}

## EAM vs IAM

| 구분 | EAM (Extranet Access Mgmt) | IAM (Identity & Access Mgmt) |
|---|---|---|
| 초점 | **인증 · SSO · 권한(접근통제)** | 인증·권한 + **계정 생명주기(프로비저닝)** 전체 |
| 관리 대상 | 웹/애플리케이션 접근, 내부 시스템 계정 | 조직 전체 사용자·고객 계정 (신규 입사~퇴사) |
| 공통 기능 | 통합 인증(SSO) · 접근 권한 중앙 관리 · 감사 로그 | 〃 |
| 한계 / 개선 | EAM: 앱 중심으로 범위가 제한, 계정 등록·삭제 자동화 부족 | IAM: 자동 프로비저닝/디프로비저닝 · 워크플로 기반 권한 승인 · 전사 통합 |

상위 개념으로 **IGA**(Identity Governance & Administration), 특권계정은 **PAM/PIM**.

## SSO 방식 비교

| 방식 | 기반 | 주 용도 |
|---|---|---|
| **Kerberos** | 대칭키 티켓 (KDC = AS + TGS), 포트 88 | 사내망(Windows AD). KDC 가 SPOF, 시계 동기화 필수 (→ 접근통제-모델) |
| **SAML 2.0** | XML 어서션, IdP–SP | 기업 ↔ SaaS 웹 SSO |
| **OAuth 2.0** | 액세스 토큰 | **권한 위임** (제3자 앱의 자원 접근 허용) — **인증 아님** |
| **OIDC** | OAuth + ID 토큰(JWT) | OAuth 위에 **인증** 계층 |

> [!함정] OAuth 는 인증이 아니라 인가(위임)
> 인증이 필요하면 **OIDC** 를 쓴다. 또 SSO 는 세션·토큰 탈취가 곧 **전체 계정 탈취**이므로 MFA · 짧은 만료 · 재인증이 필요하다.

## OTP (일회용 비밀번호)

| 방식 | 원리 |
|---|---|
| **시간 동기 (TOTP)** | 서버·토큰이 공유 시드 + 현재 시각으로 값 생성 (30~60초). 시계 오차 허용창 필요 |
| **이벤트 동기 (HOTP)** | 버튼 누른 횟수(카운터) 기반. 카운터 동기화 이탈 주의 |
| **질의응답** (Challenge-Response) | 서버가 난수 챌린지 → 토큰이 응답값 계산. **동기화 불필요**, 입력 번거로움 |

## 블록체인 합의 알고리즘

| 알고리즘 | 원리 | 사용 |
|---|---|---|
| **PoW** (작업증명) | 해시 퍼즐을 먼저 푼 노드가 블록 생성 (채굴) | 비트코인 — 전력 소모 큼 |
| **PoS** (지분증명) | 보유 코인 지분에 비례해 검증자 선정 | 이더리움 2.0 |
| **PBFT** | 검증자 2/3 이상 합의 | 프라이빗 체인, 빠름 |
| **DPoS** | 대표 노드를 투표로 선출 | EOS 등 |

특성: 분산 원장 · 위·변조 곤란(해시 체인) · 투명성 · 스마트 컨트랙트. 단점: 처리 지연 · 저장 부담 · **51% 공격**.

## 법·원칙

### 전자서명법 — 인증서 효력 소멸 사유 {{9-11}}

구법 기준 4가지 (서술형 대비):

> [!암기] 유효기간 경과 · 인증기관 지정 취소 · 효력 정지 · 폐지

현재는 공인인증서 제도가 폐지(2020)되어 **"전자서명인증서"** 로 통칭하지만, 시험은 여전히 4가지 사유를 요구한다.

### 생체인식정보 보호 6원칙 {{31-15}}

> [!암기] 비례성 · 적법성 · 목적 제한 · 투명성 · 정보주체 통제 · 안전성 확보

- **비례성**: 침해 위험이 편익보다 크지 않을 때만 활용
- **목적 제한**: 동의받은 인증/식별 외 목적으로 사용 금지
- 원본 대신 **특징정보(템플릿)** 로 저장, 분리 보관·암호화

## 단답 빈출 용어

| 용어 | 핵심 |
|---|---|
| **DTLS** | UDP 기반에서 TLS 와 동등한 보안 제공 (Datagram TLS). WebRTC · VPN · IoT |
| **TEMPEST** | 전자기기의 **부수적 전자파 방사**를 통한 도청·정보 유출을 차단하는 표준/기술 (차폐) |
| **제로데이** (Zero-Day) | 공개되지 않은 취약점을 패치 배포 **이전**에 악용하는 공격 |
| **블록체인 / 채굴** | 비트코인(사토시 나카모토)의 분산 거래 저장소 = 블록체인, PoW 해시연산 보상 획득 = 채굴 |
| **크리덴셜 스터핑** | 유출된 ID/PW 목록을 다른 사이트에 자동 대입 (제로데이와 보기에서 함께 등장) |
