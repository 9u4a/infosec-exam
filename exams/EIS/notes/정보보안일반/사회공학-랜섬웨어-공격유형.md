## 한 줄 정의

**사회공학**은 기술 취약점 대신 **사람의 신뢰·실수·두려움**을 이용해 정보나 접근 권한을 얻는 공격이다. 대부분의 침해(랜섬웨어 포함)가 피싱 메일 한 통으로 시작된다.

## 피싱 변종

| 유형 | 수단·대상 | 핵심 |
|---|---|---|
| **피싱** (Phishing) | 불특정 다수 메일 | 가짜 로그인 페이지로 계정 탈취 |
| **스피어 피싱** | **특정 개인·조직** | 업무 맥락에 맞춘 맞춤형 메일 |
| **웨일링** (Whaling) | **CEO 등 고위 임원** | 스피어 피싱의 대어(고래) 버전 |
| **스미싱** (Smishing) | **SMS** 문자 | 택배·청첩장 링크 → 악성 앱 설치 |
| **비싱** (Vishing) | **음성 전화** | 보이스피싱, 기관 사칭 |
| **큐싱** (Qshing) | **QR 코드** | QR 로 피싱 URL 접속 (URL 이 안 보임) |
| **파밍** (Pharming) | **DNS·hosts 변조** | 정상 주소를 입력해도 가짜 사이트로 |
| **BEC** (기업 이메일 침해) | 거래처·임원 사칭 메일 | 계좌 변경 요청 → **송금 사기** |

> [!함정] 피싱 vs 파밍
> 피싱은 **가짜 링크를 누르게** 한다. 파밍은 PC 의 hosts·DNS 를 바꿔 **진짜 주소를 직접 입력해도** 가짜 사이트로 간다.

## 기타 사회공학 기법

| 기법 | 내용 |
|---|---|
| **워터링 홀** | 표적이 자주 가는 사이트를 감염시켜 기다림 (사자가 물웅덩이에서 기다리듯) |
| **프리텍스팅** | 그럴듯한 상황(헬프데스크·감사)을 꾸며 정보 요구 |
| **테일게이팅 / 피기백킹** | 출입 권한자를 따라 보안 구역 진입 |
| **숄더 서핑** | 어깨 너머로 비밀번호 엿보기 |
| **덤스터 다이빙** | 버린 문서·장비에서 정보 수집 |
| **타이포스쿼팅** | 오타 도메인(`gooogle.com`) 등록 |

- 대응: **보안 인식 교육·모의 훈련** · 메일 인증(SPF·DKIM·DMARC) · MFA · 송금 시 별도 채널 확인

## 랜섬웨어

파일을 **암호화하고 복호화 키를 대가로 금전**(주로 암호화폐)을 요구한다.

1. **초기 침투** — 피싱 메일 · 노출된 RDP/VPN 취약점 · 탈취 계정
2. **권한 상승·내부 확산** — 관리자 계정 획득, AD 장악
3. **백업 무력화** — 볼륨 섀도 복사본 삭제 (`vssadmin delete shadows`)
4. **데이터 유출** — 협박용으로 미리 빼냄
5. **암호화·협박** — 랜섬노트 남김

> [!팁] 하이브리드 암호화
> 파일은 빠른 **대칭키**(AES 등)로 암호화하고, 그 대칭키를 공격자의 **공개키**로 다시 암호화한다. 개인키가 없으면 복구 불가.

| 협박 단계 | 내용 |
|---|---|
| 단일 갈취 | 암호화 → 복호화 대가 |
| **이중 갈취** | + 유출 데이터 **공개 협박** |
| 삼중 갈취 | + DDoS · 고객·거래처에 직접 연락 |

- **RaaS**(Ransomware as a Service): 개발자가 랜섬웨어를 임대, 수익 분배

## 랜섬웨어 대응

| 구분 | 대책 |
|---|---|
| 예방 | 패치 · RDP 외부 노출 차단 · MFA · 매크로 차단 · EDR · 최소 권한 |
| **백업** | **3-2-1 규칙** + **오프라인·불변(immutable)** 백업, 복구 훈련 |
| 감염 시 | 네트워크 **즉시 분리** · 확산 차단 · 증거 보존 · KISA(118) 신고 |

> [!암기] 3-2-1 백업
> 사본 **3**개 · 서로 다른 매체 **2**종 · **1**개는 외부(오프사이트) 보관.

> [!함정] 온라인 백업만으로는 부족
> 네트워크에 붙은 백업 서버·NAS 도 함께 암호화된다. **분리 보관(오프라인)** 이 핵심이다.
