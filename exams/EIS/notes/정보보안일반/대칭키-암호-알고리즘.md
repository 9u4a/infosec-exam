## 한 줄 정의

대칭키 암호는 **같은 키로 암·복호**하며, **블록 암호**(고정 길이 단위)와 **스트림 암호**(비트 단위)로 나뉜다. 블록 암호는 구조가 **Feistel** 이냐 **SPN** 이냐로 알고리즘이 갈린다. 기출에 직접 나오진 않았지만 필기·실기 공통 범위이며 `암호학-기초` 의 확장이다.

## 1. 블록 암호 vs 스트림 암호

| | 블록 암호 | 스트림 암호 |
|---|---|---|
| 처리 단위 | 고정 길이 블록 (64/128비트) | 비트·바이트 |
| 방식 | 평문 블록 ↔ 암호문 블록 | 평문 ⊕ 키스트림 |
| 특징 | 확산·혼돈, 재사용 가능 | 빠름, 오류 전파 적음, 하드웨어 적합 |
| 예 | DES · AES · SEED · ARIA | RC4 · A5/1(GSM) · ChaCha20 · LFSR 기반 |

> [!암기] 혼돈과 확산
> **혼돈 (Confusion)** = 키와 암호문의 관계를 숨김 (**치환**) · **확산 (Diffusion)** = 평문 1비트 변화가 암호문 전체로 퍼짐 (**전치**)

## 2. 블록 암호의 2대 구조

| | **Feistel** | **SPN** |
|---|---|---|
| 방식 | 평문을 좌·우(L, R)로 나눠 라운드 함수 F 반복 | 전체 블록에 S-box(치환) + P-box(전치) + 키 XOR 을 라운드마다 |
| 식 | `L(i) = R(i−1)` · `R(i) = L(i−1) ⊕ F(R(i−1), K(i))` | — |
| 복호화 | **암호화와 구조 동일** (라운드 키만 역순) | 역연산 필요 (S-box·P-box 역함수) |
| 특징 | F 가 역함수일 필요 없음, 보통 16라운드 | 병렬 처리 가능 → **빠름** |
| 예 | **DES · 3DES · SEED** · Blowfish · RC5 · CAST | **AES · ARIA** · SHARK · IDEA(변형) |

## 3. DES / 3DES

| 항목 | DES | 3DES |
|---|---|---|
| 블록 | 64비트 | 64비트 |
| 키 | 56비트 (패리티 포함 64) | 112 또는 168비트 |
| 구조 | Feistel 16라운드 | DES 3회 (EDE: 암·복·암) |
| 상태 | **1998년 무차별 공격으로 파괴** | 과도기용, 느림 → AES 로 대체 |

- DES 약점: 짧은 키(56비트) · 약한 키(weak key) · 차분·선형 공격
- 3DES 모드: DES-EEE3 / DES-EDE3 (키 3개) / DES-EDE2 (키 2개, K1 = K3)

## 4. AES (Rijndael)

2001 NIST 표준이다. **블록 128비트 고정**, 키 **128 / 192 / 256비트**, 라운드 수 **10 / 12 / 14**.

> [!암기] 라운드 연산 4단계
> **SubBytes**(S-box 치환) → **ShiftRows**(행 이동) → **MixColumns**(열 혼합) → **AddRoundKey**(키 XOR). **마지막 라운드는 MixColumns 생략.**

갈루아체 GF(2⁸) 연산 기반이며 현재까지 실용적 공격이 없다.

## 5. 국산 블록 암호

| 알고리즘 | 개발 / 용도 | 블록 / 키 | 구조 |
|---|---|---|---|
| **SEED** | KISA (1999), 국내 표준, 전자상거래 | 128 / 128 | Feistel 16라운드 |
| **ARIA** | 국정원 + 학계 (2004), 국가·공공 | 128 / 128·192·256 | SPN, involution 기반 (암·복호 유사) |
| **LEA** | 국가보안기술연구소 (2013), 경량·고속 SW | 128 / 128·192·256 | **ARX**(가감산·회전·XOR), AES 보다 빠름 |
| **HIGHT** | KISA (2006), **RFID·USN 등 저전력** | 64 / 128 | Feistel 변형 (ARX) |

## 6. 기타 대칭 암호

| 알고리즘 | 특징 |
|---|---|
| **IDEA** | 128비트 키, PGP 에 사용, 특허 만료 |
| **Blowfish / Twofish** | 무료, Blowfish 는 키 스케줄이 느림 |
| **RC4** | 스트림, WEP·구 SSL 에 사용 → **취약, 사용 금지** |
| **RC5 / RC6** | 가변 파라미터 블록 암호 |
| **ChaCha20** | 모바일·TLS 1.3, RC4 대체 스트림 암호 (Poly1305 MAC 과 결합 = AEAD) |
