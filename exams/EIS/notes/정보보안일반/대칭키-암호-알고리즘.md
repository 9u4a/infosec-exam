## 블록 암호 vs 스트림 암호

| | 블록 암호 | 스트림 암호 |
|---|---|---|
| 처리 단위 | 고정 길이 블록(64/128비트) | 비트·바이트 단위 |
| 방식 | 평문 블록 ↔ 암호문 블록 | 평문 ⊕ 키스트림 |
| 특징 | 확산·혼돈, 재사용 가능 | 빠름, 오류 전파 적음, 하드웨어 적합 |
| 예 | DES, AES, SEED, ARIA | RC4, A5/1(GSM), ChaCha20, LFSR 기반 |
| 혼돈(Confusion) | 키와 암호문 관계 은폐 (치환) | |
| 확산(Diffusion) | 평문 1비트 변화가 암호문 전체에 퍼짐 (전치) | |

## 블록 암호 2대 구조

### Feistel 구조

- 평문을 좌·우(L, R) 반으로 나눠 라운드 함수 F를 반복.
  `L(i) = R(i-1)`, `R(i) = L(i-1) ⊕ F(R(i-1), K(i))`
- **암호화·복호화 구조가 동일**(라운드 키만 역순) → 구현 경제적.
- F 함수가 역함수일 필요 없음.
- 라운드 수↑ = 안전성↑ (보통 16라운드).
- 예: **DES, 3DES, SEED, Blowfish, RC5, CAST**

### SPN (Substitution-Permutation Network)

- 전체 블록에 S-box(치환) + P-box(전치) + 키 XOR을 라운드마다 적용.
- 병렬 처리 가능 → **빠름**, 하지만 복호화 시 역연산 필요(S-box·P-box 역함수).
- 예: **AES, ARIA, SHARK, IDEA(변형)**

## DES / 3DES

| 항목 | DES | 3DES |
|---|---|---|
| 블록 크기 | 64비트 | 64비트 |
| 키 길이 | 56비트(패리티 포함 64) | 112 또는 168비트 |
| 구조 | Feistel 16라운드 | DES 3회(EDE: 암·복·암) |
| 상태 | **1998년 무차별 공격으로 파괴** | 과도기용, 느림 → AES로 대체 |

- DES 약점: 짧은 키(56비트), 약한 키(weak key) 존재, 차분·선형 공격.
- 3DES 모드: DES-EEE3 / DES-EDE3(키 3개) / DES-EDE2(키 2개, K1=K3).

## AES (Rijndael)

- 2001 NIST 표준. **블록 128비트 고정**, 키 **128 / 192 / 256비트**.
- 라운드 수: 10 / 12 / 14 (키 길이별).
- 라운드 연산: **SubBytes**(S-box 치환) → **ShiftRows**(행 이동) → **MixColumns**(열 혼합) → **AddRoundKey**(키 XOR). 마지막 라운드는 MixColumns 생략.
- 갈루아체(GF(2^8)) 연산 기반. 현재까지 실용적 공격 없음.

## 국산 블록 암호

| 알고리즘 | 개발/용도 | 블록/키 | 구조 |
|---|---|---|---|
| **SEED** | KISA(1999), 국내 표준, 전자상거래 | 128 / 128 | Feistel 16라운드 |
| **ARIA** | 국정원+학계(2004), 국가·공공 | 128 / 128·192·256 | SPN, involution 기반(암·복호 유사) |
| **LEA** | 국가보안기술연구소(2013), 경량·고속 SW | 128 / 128·192·256 | ARX(가감산·회전·XOR), AES보다 빠름 |
| **HIGHT** | KISA(2006), **RFID·USN 등 저전력** | 64 / 128 | Feistel 변형(ARX) |

## 기타 대칭 암호

- **IDEA**: 128비트 키, PGP에 사용. 특허 만료.
- **Blowfish / Twofish**: 무료, Blowfish는 키 스케줄 느림.
- **RC4**: 스트림, WEP·구 SSL에 사용 → **취약(사용 금지)**.
- **RC5 / RC6**: 가변 파라미터 블록 암호.
- **ChaCha20**: 모바일·TLS 1.3, RC4 대체 스트림 암호(Poly1305 MAC과 결합 = AEAD).
