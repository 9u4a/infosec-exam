## 한 줄 정의

**"무엇을 지키려는가"** 로 구분하면 쉽다. 스테가노그래피는 *존재를 숨기고*, 암호화는 *내용을 못 읽게 하고*, 워터마킹·핑거프린팅은 *소유권·유출자를 사후에 밝히고*, DRM 은 *사용 시점을 통제*한다. 개념 비교가 핵심이다.

## 스테가노그래피 vs 암호화 vs 워터마킹

| | 스테가노그래피 | 암호화 | 워터마킹 |
|---|---|---|---|
| 목적 | **존재 자체를 은닉** | 내용을 읽지 못하게 | 저작권·출처 표시 |
| 들키면 | **실패** | 여전히 안전 | (숨긴 게 아니라 표시) |
| 예 | 이미지 LSB 에 메시지 삽입 | AES | 사진에 보이지 않는 소유자 정보 |

- 기법: **LSB 삽입**(이미지·오디오 최하위 비트) · 팔레트 · 주파수 영역(DCT) · 텍스트(공백·서식) · 네트워크(패킷 헤더 필드)
- **스테가분석**: 통계적 이상(히스토그램), 알려진 도구 시그니처

## 디지털 워터마킹

콘텐츠에 **소유권·저작권 정보를 삽입**하며, 복사·변형돼도 유지된다.

| 구분 | 종류 | 설명 |
|---|---|---|
| 인지성 | **가시적** | 방송사 로고처럼 보임 |
| | **비가시적** | 눈엔 안 보이고 검출기로만 확인 |
| 견고성 | **강성 (Robust)** | 압축·크롭·필터링에도 생존 → **저작권 증명** |
| | **연성 (Fragile)** | 조금만 변형돼도 깨짐 → **무결성·위변조 탐지** |

- 요구 특성: **비인지성**(품질 저하 최소) · **견고성** · **보안성**(비인가 제거·위조 불가) · **용량**
- 공격: 제거 공격 · 기하학적 왜곡 · 워터마크 위조 · 공모(collusion) 공격

## 핑거프린팅 · 포렌식 마킹

| | 핑거프린팅 | 포렌식 마킹 |
|---|---|---|
| 정의 | 워터마킹과 유사하나 **구매자마다 다른 식별 정보**를 삽입해 불법 유포자를 **추적** | 워터마킹 + 핑거프린팅 결합, 유출 시 **"누가·언제"** 추적 |
| 특이점 | **공모 공격**(여러 구매자가 사본을 비교해 핑거프린트 제거)에 대비한 코드 설계 필요 (예: Boneh-Shaw) | DRM·영상 유통에 활용 |

> [!함정] 워터마킹 vs 핑거프린팅
> 워터마킹은 **모두에게 같은 소유자 정보**, 핑거프린팅은 **구매자마다 다른 정보**다.

## DRM (Digital Rights Management)

디지털 콘텐츠의 **사용 권한을 지속적으로 통제**하는 기술이다.

| 구성요소 | 역할 |
|---|---|
| **콘텐츠 서버** | 원본 패키징 (암호화) |
| **라이선스 서버** | 사용 규칙(횟수·기간·기기·복사 여부) + 복호화 키 발급 |
| **DRM 컨트롤러** (클라이언트) | 라이선스 확인 후 복호화·재생, 규칙 강제 |
| **패키저** | 콘텐츠 암호화 + 메타데이터·워터마크 삽입 |

- 문서 DRM(사내): 파일 자체를 암호화 → 외부 반출돼도 열람·인쇄·캡처를 제어하고 로그를 추적
- 한계: 최종 출력 단계(화면 캡처 · 아날로그 홀), 클라이언트 우회
- 관련: **XrML / ODRL**(권리 표현 언어), 방송 **CAS**(제한수신)

## 저작권 보호 기술 종합

| 기술 | 언제 |
|---|---|
| **암호화** | 전달·저장 중 내용 보호 |
| **DRM** | 사용(재생·편집·복사) 시점 통제 |
| **워터마킹** | 사후 소유권 증명 / 무결성 확인 |
| **핑거프린팅 · 포렌식 마킹** | 사후 유출자 추적 |
