## 한 줄 정의

공개키 암호는 **"풀기 어려운 수학 문제"** 위에 세워진다. 알고리즘을 *어떤 난제에 기대는지*(소인수분해 · 이산대수 · 타원곡선)로 묶으면 RSA·DH·ECC 가 한 번에 정리된다. 필기·실기 공통이고 `암호학-기초` 노트의 확장이다.

## 1. 기반 난제별 분류

| 기반 난제 | 알고리즘 |
|---|---|
| **소인수분해** | RSA · Rabin |
| **이산대수 (DLP)** | Diffie-Hellman · ElGamal · DSA |
| **타원곡선 이산대수 (ECDLP)** | ECC · ECDH · ECDSA |
| **배낭 문제** | Merkle-Hellman (**깨짐**) |

## 2. RSA

### 키 생성

1. 큰 소수 p, q 선택 → **n = p·q**
2. φ(n) = (p−1)(q−1)
3. 공개 지수 e 선택 (1 < e < φ(n), gcd(e, φ(n)) = 1)
4. 개인 지수 d 계산 (e·d ≡ 1 mod φ(n))

| 구분 | 값 |
|---|---|
| **공개키** | (e, n) |
| **개인키** | (d, n) |
| 암호화 | `C = M^e mod n` |
| 복호화 | `M = C^d mod n` |
| 전자서명 | 개인키로 서명 `S = M^d mod n`, 공개키로 검증 |

- 안전성: **n 의 소인수분해가 어렵다**는 가정. 권장 키 길이 **2048비트 이상**(대칭 112비트급)
- 공격: 소인수분해 · 작은 e · 공통 모듈러스 · 타이밍 · 패딩 오라클 → **OAEP 패딩** 사용

## 3. ECC (타원곡선 암호)

타원곡선 `y² = x³ + ax + b` 위 점들의 군 연산(점 덧셈·스칼라 곱)을 쓴다. **같은 안전성을 훨씬 짧은 키로** 얻어 모바일·IoT·스마트카드에 유리하다.

| 대칭키 | RSA / DH | ECC |
|---|---|---|
| 80비트 | 1024 | 160 |
| 112비트 | 2048 | 224 |
| 128비트 | 3072 | 256 |
| 256비트 | 15360 | 512 |

파생: **ECDH**(키 교환) · **ECDSA**(서명) · 국산 **EC-KCDSA**

## 4. Diffie-Hellman 키 교환

- 공개값 p(소수), g(원시근). Alice 비밀 a, Bob 비밀 b
- 교환: `A = g^a mod p`, `B = g^b mod p`
- 공유 비밀: 양쪽 모두 `g^(ab) mod p` 계산
- **키 합의(agreement)** — 키 자체를 전송하지 않는다

> [!함정] 인증이 없다
> DH 는 **중간자(MITM)에 취약**하다 → 서명·인증서와 결합한다. **(EC)DHE** 는 임시(ephemeral) 키를 써서 **전방향 비밀성(PFS)** 을 제공한다 (개인키가 나중에 유출돼도 과거 세션키는 안전).

## 5. ElGamal · Rabin

| | ElGamal | Rabin |
|---|---|---|
| 기반 | 이산대수 | 소인수분해 |
| 특징 | 암호문이 **평문의 2배 크기** (비효율). 같은 평문도 매번 다른 암호문(확률적 암호) → 의미론적 안전성. 서명 버전이 **DSA** 의 기반 | `C = M² mod n` — RSA 보다 빠른 암호화. 복호화 시 **4개 후보** 중 선택 필요. 안전성이 소인수분해와 **동치**로 증명됨 |

## 6. 하이브리드 암호 시스템

**비대칭키로 대칭 세션키를 안전하게 전달**하고, 이후 대용량 데이터는 대칭키로 암·복호한다. SSL/TLS · PGP · S/MIME 모두 이 방식이다. (비대칭 = 키 분배·서명, 대칭 = 속도)

## 7. 대칭 vs 공개키 요약

| | 대칭키 | 공개키 |
|---|---|---|
| 키 | 1개 (공유) | 2개 (공개/개인) |
| 속도 | 빠름 | 느림 (100~1000배) |
| 키 분배 | 어려움 (사전 공유) | 쉬움 (공개키 배포) |
| 키 개수 (n명) | **n(n−1)/2** | **2n** |
| 제공 | 기밀성 | 기밀성 · 인증 · 부인방지 · 키 교환 |
| 무결성·부인방지 | ✗ (전자서명 불가) | ✓ |
