## 한 줄 정의

엔드포인트(PC·서버·모바일) 보안은 **막기(EPP) → 잡아내기(EDR) → 새나가지 않게(DLP·DRM) → 모바일 통제(MDM)** 로 층을 쌓는다. 각 솔루션이 **무엇을 지키는지**를 구분하는 게 핵심이다. {{16-5}} {{24-8}} {{29-4}}

## EPP vs EDR {{16-5}}

| | **EPP** | **EDR** |
|---|---|---|
| 목적 | **예방** — 알려진 위협 차단 | **탐지·대응** — 침입 후 행위 포착 |
| 방식 | 시그니처 · 평판 · 정적 휴리스틱 | 행위 분석 · 이상 탐지 · 이벤트 상관 |
| 대응 | 격리·삭제 | 원격 격리 · 프로세스 중단 · 롤백 · 포렌식 |
| 한계 | 미지·파일리스·정상 도구 악용을 못 잡음 | 경보가 많고 분석 인력 필요 |

실무는 EPP + EDR 통합이다. 확장형은 **XDR**(엔드포인트+네트워크+메일+클라우드 상관), **MDR**(관제 서비스 결합).

### EDR 이 보완하는 것

- 시그니처 백신의 한계(알려진 악성코드만) → **정상 프로세스를 악용하는 공격 · 파일리스 · APT** 탐지
- 기능: 행위 로깅 · 이상행위 탐지 · 위협 헌팅 · 원격 격리 · 타임라인 포렌식
- 수집: 프로세스 생성 트리 · 네트워크 연결 · 파일/레지스트리 변경 · DLL 로드 · 스크립트 실행

## DLP — 내부 정보 유출 방지 {{24-8}} {{29-4}}

**PC 에이전트 + 네트워크 센서**로 이동 경로를 감시·차단·기록한다.

| 배치 | 통제 대상 |
|---|---|
| **엔드포인트 DLP** (에이전트) | 오프라인 · USB · 인쇄 |
| **네트워크 DLP** (게이트웨이) | 메일 · 웹 |
| **스토리지 DLP** | 서버에 저장된 데이터 스캔 |

- 감시 채널: USB · 메일 첨부 · 메신저 · **웹 파일 업로드** · 인쇄 · 화면 캡처
- **HTTPS** 같은 암호화 통신도 에이전트/프록시에서 복호화해 검사
- 콘텐츠 인식: 정규식(주민번호·카드번호) · 지문(fingerprint) · 키워드 · 문서 분류 태그

### 인접 솔루션

| 솔루션 | 역할 |
|---|---|
| **DRM** | 문서 **자체를 암호화**하고 열람·편집·인쇄·기간 권한 부여 → 밖으로 나가도 무력 |
| **CASB** | SaaS 사용 가시성·통제 (섀도우 IT 탐지, 업로드 차단) |
| **NAC** | 접속 단말 **인증 + 무결성 점검**(백신·패치), 미달 시 격리·치료 |
| **워터마킹** | 출력물·화면에 사용자·시각 표시 → 유출 시 추적 |
| **EFS / BitLocker** | 디스크·파일 암호화 (분실·도난 대비) |

## MDM · BYOD 모바일 보안 {{22-13}} {{30-14}}

| 기술 | 개념 |
|---|---|
| **MDM** | **기기 전체**를 원격 관리 — 정책 적용 · 앱 화이트리스트 · 원격 잠금/**삭제(wipe)** · 탈옥·루팅 탐지 · 카메라·캡처 제어 |
| **MAM** | 업무용 **앱 단위** 관리·배포·삭제 (개인 영역은 간섭 안 함) |
| **컨테이너화** | 한 기기 안에서 업무/개인 영역을 **논리적으로 분리**, 업무 데이터는 암호화 컨테이너 저장·상호 복사 차단 |
| **모바일 가상화** | 업무용·개인용 **OS(가상 머신)** 를 각각 구동해 완전 격리 |
| **MCM** | 업무 문서의 안전한 배포·열람(뷰어) 통제 |

- BYOD 의 고민: **사생활 침해 vs 통제 · 분실·도난 · 비인가 앱** → 컨테이너화가 절충안
- 통합 관리: **EMM**(MDM+MAM+MCM), 더 넓게 **UEM**(PC 까지)

> [!함정] 컨테이너화 vs 모바일 가상화
> 둘 다 업무/개인 분리지만, 컨테이너화는 **한 OS 안의 논리적 분리**, 모바일 가상화는 **OS 를 둘 띄우는 완전 격리**다.
