## 한 줄 정의

Windows 계정 보안은 **누구인지(SID·인증) → 무엇을 할 수 있는지(그룹·UAC) → 무엇을 했는지(감사)** 의 흐름이다. 인증 구조(LSA·SAM·SRM)와 NTLM 단계는 서술형 단골이다. {{25-1}} {{26-13}} {{30-3}} {{30-6}}

## 인증 구조 — LSA · SAM · SRM

| 구성요소 | 역할 |
|---|---|
| **LSA** (Local Security Authority) | 인증 정책 관리 · SAM 접근 · 로컬 보안 정책 총괄 |
| **SAM** (Security Account Manager) | 로컬 계정·패스워드 **해시 저장 DB** (`%SystemRoot%\System32\config\SAM`) |
| **SRM** (Security Reference Monitor) | 접근 제어 판정 · 감사 로그 생성 · **SID 발급** |

> [!암기] 로그인 흐름
> 사용자 로그인 → **LSA** → **SAM** 조회(계정·해시 검증) → **SRM** 이 SID 발급·접근 제어

### SID — 계정의 고유 번호

| 끝자리 | 계정 | 대응 |
|---|---|---|
| **500** | Administrator (내장 관리자) | 삭제 불가 → **이름 변경** |
| **501** | Guest | **반드시 비활성화** |
| 1000~ | 일반 사용자 | |

## 인증 방식 — LM · NTLM · NTLMv2

| 방식 | 특징 | 수준 |
|---|---|---|
| **LM** | DES 기반 · 14자 이하 **대문자 변환** · 7자씩 분할 | 매우 낮음 (수분 내 크랙) |
| **NTLM** | MD4 해시 + Challenge/Response | 낮음 (**Pass-the-Hash** 취약) |
| **NTLMv2** | 현재 기본값, HMAC-MD5 강화 | 상대적으로 높음 (그래도 Kerberos 권장) |

### NTLM 인증 4단계 (서술형 단골)

1. 클라이언트 → 서버: **인증 요청**
2. 서버 → 클라이언트: **Challenge** 전송
3. 클라이언트: 패스워드 해시로 Challenge 를 암호화한 **Response** 전송
4. 서버: Response 검증 후 인증 허가

## 권한 — 그룹과 UAC

| 그룹 | 권한 |
|---|---|
| Administrators | 전권 |
| **Power Users** | 표준보다 많고 관리자보다 제한 (레거시) |
| **Backup Operators** | 백업·복원을 위해 파일 권한을 우회 → **권한 상승 악용 주의** |
| Users / Guests | 일반 / 임시 |
| **Remote Desktop Users** | RDP 접속 허용 |

### UAC (사용자 계정 컨트롤)

관리자 계정도 평소엔 **표준 토큰**으로 동작하다가 시스템 변경 때 동의를 요구한다 (관리자: 예/아니오, 표준: 관리자 암호). "관리자 권한으로 실행"으로 상승한다.

> [!함정] [예] 버튼이 비활성이고 [아니오]만 보이면
> 참조할 로컬 Administrator 가 **비활성·삭제**됐거나 시스템 파일·정책이 손상된 경우다.

## 계정·잠금 정책 권장값

| 정책 | 권장 |
|---|---|
| 최소 암호 길이 | 8자 이상 |
| 최대 암호 사용 기간 | 90일 |
| 최소 암호 사용 기간 | 1일 (즉시 재변경 방지) |
| 암호 복잡도 | 대·소문자 + 숫자 + 특수문자 |
| 암호 히스토리 | 12개 (재사용 방지) |
| 계정 잠금 임계값 | 5회 |
| 잠금 기간 / 초기화 시간 | 60분 |

## 감사 (Audit) 정책

| 정책 | 기록 대상 |
|---|---|
| **계정 관리 감사** | 계정 생성·삭제 · 그룹 변경 · 암호 재설정 |
| **로그온 이벤트 감사** | **해당 컴퓨터**의 로컬 로그온 (성공/실패) |
| **계정 로그온 이벤트 감사** | 자격증명을 **검증한 위치(DC)** 의 로그온 |
| **권한 사용 감사** | SeBackupPrivilege 등 사용자 권한 행사 |
| **개체 액세스 감사** | 파일·레지스트리 접근 (**SACL** 설정 필요) |
| **정책 변경 감사** | 보안 정책·감사 설정 변경 |

> [!함정] 로그온 vs 계정 로그온
> 로그온 이벤트 = 접속한 *그 컴퓨터*, 계정 로그온 이벤트 = 자격증명을 *검증한 서버(DC)*.

이벤트 로그 크기: `단일 이벤트 크기 × 일일 이벤트 수 × 보관일수`. 이벤트 뷰어 → 로그 속성 → 최대 로그 크기 + 초과 시 동작.

## 관리 명령어

| 명령 | 용도 |
|---|---|
| `net user` · `net localgroup` | 계정 · 그룹 관리 |
| `net share` | 공유 목록·설정·해제 (기본 공유 `C$` `ADMIN$` `IPC$`) |
| `net session` | 원격 세션 조회 |
| `query session` / `qwinsta` | RDP 세션 조회 |
| `logoff [ID]` / `rwinsta [ID]` | 세션 강제 종료 (침해 대응) |
| `secpol.msc` / `gpedit.msc` | 로컬 보안 정책 / 그룹 정책 |
| `ncpa.cpl` | 네트워크 어댑터 (NetBIOS over TCP/IP 끄기) |

## 보호 기능

### NTFS 와 암호화

- NTFS: 저널링 · ACL 권한 · EFS · 압축 · 대용량
  - **ADS**(대체 데이터 스트림): 악성코드 은닉에 악용
  - **MFT** 에 모든 파일·디렉터리 메타데이터 저장

| | EFS | BitLocker |
|---|---|---|
| 단위 | 파일·폴더 | **볼륨 전체** |
| 조건 | NTFS 만, 사용자 인증서 기반 | TPM 연동, OS 볼륨 보호 |

### 레지스트리 5대 루트 키

| 키 | 약어 | 저장 내용 |
|---|---|---|
| HKEY_LOCAL_MACHINE | HKLM | 시스템 전체 설정·하드웨어 (**SAM · SECURITY · SOFTWARE · SYSTEM** 하위) |
| HKEY_CURRENT_USER | HKCU | 현재 로그인 사용자 |
| HKEY_CLASSES_ROOT | HKCR | 확장자·COM 객체 연결 |
| HKEY_USERS | HKU | 모든 사용자 프로파일 |
| HKEY_CURRENT_CONFIG | HKCC | 현재 하드웨어 프로파일 |
