## 로컬 기본 그룹

| 그룹 | 권한 |
|---|---|
| Administrators | 전권 |
| **Power Users** | 표준보다 많음, 관리자보단 제한 (레거시) |
| **Backup Operators** | 백업·복원 위해 파일 권한 우회 → 권한 상승 악용 주의 |
| Users | 일반 |
| Guests | 임시 |
| **Remote Desktop Users** | RDP 접속 허용 대상 |

## UAC (사용자 계정 컨트롤)

관리자 계정도 평소엔 표준 토큰으로 동작, 시스템 변경 시 동의 요구(관리자=예/아니오, 표준=관리자 암호). "관리자 권한으로 실행"으로 상승.
- [예] 버튼 비활성 + [아니오]만 → 참조할 로컬 Administrator 비활성/삭제, 또는 시스템 파일·정책 손상

## 감사(Audit) 정책

| 정책 | 기록 대상 |
|---|---|
| **계정 관리 감사** | 계정 생성·삭제·그룹 변경·암호 재설정 |
| **로그온 이벤트 감사** | 해당 컴퓨터의 로컬 로그온(성공/실패) |
| **계정 로그온 이벤트 감사** | 자격증명을 **검증한 위치**(DC)에서의 로그온 |
| **권한 사용 감사** | SeBackupPrivilege 등 사용자 권한 행사 |
| **개체 액세스 감사** | 파일·레지스트리 접근(SACL 설정 필요) |
| **정책 변경 감사** | 보안 정책·감사 설정 변경 |

이벤트 로그 크기 산정: `단일 이벤트 크기 × 일일 이벤트 수 × 보관일수`.
설정: 이벤트 뷰어 → 로그 속성 → 최대 로그 크기 + 초과 시 동작.

## 명령어

| 명령 | 용도 |
|---|---|
| `net user` | 계정 조회·생성·변경 |
| `net localgroup` | 그룹 관리 |
| `net share` | 공유 폴더 목록·설정·해제 (기본 공유 C$, ADMIN$, IPC$) |
| `net session` | 원격 세션 조회 |
| `query session` / `qwinsta` | RDP 세션 조회 |
| `logoff [ID]` / `rwinsta [ID]` | 세션 강제 종료 (침해 대응) |
| `secpol.msc` / `gpedit.msc` | 로컬 보안 정책 / 그룹 정책 |
| `ncpa.cpl` | 네트워크 어댑터 (NetBIOS over TCP/IP 사용 안 함) |

## NTFS 보안 기능

저널링, ACL 기반 파일/폴더 권한, EFS 암호화, ADS(대체 데이터 스트림 — 악성코드 은닉에 악용), 압축, 대용량 파일.
MFT(Master File Table)에 모든 파일·디렉터리의 메타데이터를 저장한다.

## 인증 구조 (LSA · SAM · SRM) — 서술형 단골

| 구성요소 | 역할 |
|---|---|
| **LSA** (Local Security Authority) | 인증 정책 관리, SAM DB 접근, 로컬 보안 정책 총괄 |
| **SAM** (Security Account Manager) | 로컬 계정·패스워드 해시 저장 DB (`%SystemRoot%\System32\config\SAM`) |
| **SRM** (Security Reference Monitor) | 접근 제어 판정, 감사 로그 생성, SID 발급 |

로그인 흐름: 사용자 로그인 → **LSA** → **SAM DB** 조회(계정·해시 검증) → **SRM**이 SID 발급·접근 제어.

## SID (Security Identifier)

| SID 값 | 계정 |
|---|---|
| **500** | Administrator (내장 관리자, 삭제 불가 — 이름 변경으로 대응) |
| **501** | Guest (반드시 비활성화) |
| 1000~ | 일반 사용자 계정 |

## LM vs NTLM vs NTLMv2

| 인증 방식 | 특징 | 보안 수준 |
|---|---|---|
| **LM** | LAN Manager, DES 기반·14자 이하 대문자 변환·7자씩 분할 | 매우 낮음(수분 내 크랙) |
| **NTLM** | MD4 해시, Challenge/Response | 낮음(Pass-the-Hash 취약) |
| **NTLMv2** | 현재 기본값, HMAC-MD5 기반 강화 | 상대적으로 높음(그래도 Kerberos 권장) |

**NTLM 인증 4단계(Challenge/Response, 서술형 단골)**:
① 클라이언트 → 서버: 인증 요청 ② 서버 → 클라이언트: Challenge 전송
③ 클라이언트: 패스워드 해시로 Challenge를 암호화해 Response 생성·전송 ④ 서버: Response 검증 후 인증 허가.

## 레지스트리 5대 루트 키

| 키 | 약어 | 저장 내용 |
|---|---|---|
| HKEY_LOCAL_MACHINE | HKLM | 시스템 전체 설정·하드웨어, **SAM·SECURITY·SOFTWARE·SYSTEM** 하위 위치 |
| HKEY_CURRENT_USER | HKCU | 현재 로그인 사용자 설정 |
| HKEY_CLASSES_ROOT | HKCR | 파일 확장자·COM 객체 연결 정보 |
| HKEY_USERS | HKU | 모든 사용자 프로파일 |
| HKEY_CURRENT_CONFIG | HKCC | 현재 하드웨어 프로파일 |

## 계정·잠금 정책 권장값

| 정책 | 권장값 |
|---|---|
| 최소 암호 길이 | 8자 이상 |
| 최대 암호 사용 기간 | 90일 |
| 최소 암호 사용 기간 | 1일 (즉각 재변경 방지) |
| 암호 복잡도 | 대소문자+숫자+특수문자 |
| 암호 히스토리 | 12개(이전 패스워드 재사용 방지) |
| 계정 잠금 임계값 | 5회 |
| 계정 잠금 기간 / 초기화 시간 | 60분 |

## EFS vs BitLocker

| 기능 | 설명 |
|---|---|
| **EFS** | 파일·폴더 단위 암호화, NTFS에서만 지원, 사용자 인증서 기반 |
| **BitLocker** | 드라이브(볼륨) 전체 암호화, TPM 칩 연동, OS 볼륨 보호 |
