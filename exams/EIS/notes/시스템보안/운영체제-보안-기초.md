## 한 줄 정의

OS 보안의 뼈대는 **"모든 접근을 반드시 거치는 작고 검증 가능한 검문소(참조 모니터)"** 를 만들고, 그것을 **하드웨어(TPM)로 뒷받침**하는 것이다. 필기 단골이고 실기엔 배경 지식으로 쓰인다.

## 1. 권한 경계 — 보호 링

CPU 가 제공하는 특권 수준이다. x86 은 Ring 0~3.

| Ring | 대상 |
|---|---|
| **0** | 커널 (모든 명령·메모리 접근) |
| 1 · 2 | 드라이버·서비스 (대부분 OS 는 0 과 3 만 사용) |
| **3** | 사용자 애플리케이션 |

- 하이퍼바이저는 Ring -1 (VMX root), SMM 은 Ring -2 로 표현하기도 한다
- 사용자 → 커널 전환은 **시스템 콜(트랩)** 으로만 가능하다

## 2. 접근 검문소 — 참조 모니터

주체가 객체에 접근할 때마다 **접근 규칙을 강제하는 추상 개념**이다.

| 요건 | 의미 |
|---|---|
| **격리성** (부정조작 방지) | 변조·우회할 수 없다 |
| **완전성** (항상 호출) | 모든 접근이 반드시 거친다 |
| **검증가능성** | 작고 단순해 정확성을 분석·시험할 수 있다 |

참조 모니터를 구현한 HW·SW·펌웨어가 **보안 커널**이다.

### TCB (Trusted Computing Base)

보안 정책을 강제하는 **모든 보호 메커니즘의 집합**(HW+SW+펌웨어)이다.

- 작고 검증될수록 신뢰도↑ → **최소화**가 원칙
- 보안 경계(security perimeter)가 TCB 와 비-TCB 를 가른다

## 3. 하드웨어 신뢰 기반

### TPM (Trusted Platform Module)

메인보드의 **암호 연산·키 저장 전용 칩**(TCG 표준)이다.

- 기능: 키 생성·봉인(sealing) · 무결성 측정값 저장(**PCR**) · 원격 증명(attestation) · 난수 생성
- **신뢰 부팅(Measured Boot)**: 펌웨어 → 부트로더 → 커널의 해시를 PCR 에 누적해 변조 탐지
- BitLocker·디스크 암호화 키를 TPM 에 봉인 → **디스크만 훔쳐도 복호화 불가**
- Secure Boot(서명된 부트로더만 실행)와 함께 루트킷·부트킷을 막는다

### 그 밖의 신뢰 하드웨어

| 장치 | 설명 |
|---|---|
| **HSM** | 서버용 키 관리 전용 장비 (FIPS 140-2/3) |
| **TEE** | ARM TrustZone · Intel SGX — 일반 OS 와 격리된 영역에서 처리 |
| **Secure Element** | 스마트카드·모바일의 변조 방지 칩 |

## 4. 평가 기준의 역사

| 기준 | 특징 |
|---|---|
| **TCSEC** (Orange Book) | 미 국방부 1985, 기밀성 중심. **D < C1 < C2 < B1 < B2 < B3 < A1** (7등급) |
| **ITSEC** | 유럽 1991. 기능(F)과 보증(E1~E6) 분리, 기밀성·무결성·가용성 |
| **CC** (ISO 15408) | 국제 통합. PP / ST / **EAL1~7** (→ CC 노트) |

> [!암기] TCSEC 포인트
> **C2** = 임의적 접근통제 + 감사 · **B1부터 강제적 접근통제(MAC) + 보안 레이블** 요구
