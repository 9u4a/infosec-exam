## 유형

| 유형 | 설명 |
|---|---|
| **스택 버퍼 오버플로우** | 지역 버퍼 초과 입력 → 스택의 SFP·**복귀주소(RET)** 덮어써 임의 코드 실행 |
| **힙 버퍼 오버플로우** | `malloc` 영역 초과 → 인접 청크 메타데이터·함수 포인터 변조 |
| **정수 오버플로우** | 크기 계산이 wrap-around → 작은 버퍼 할당 후 큰 복사 |

## 위험 함수 → 안전 함수

| 위험 | 대체 |
|---|---|
| `strcpy` | `strncpy` / `strlcpy` |
| `strcat` | `strncat` / `strlcat` |
| `sprintf` | `snprintf` |
| `gets` | `fgets` |
| `scanf("%s")` | `scanf("%9s")` (폭 지정) |

```c
strncpy(buf, argv[1], sizeof(buf)-1);
buf[sizeof(buf)-1] = '\0';   // strncpy는 널 종료 보장 안 함
```

## 익스플로잇 구성 요소

- **셸코드(Shellcode)**: 기계어로 된 익스플로잇 본체 (셸 실행 등)
- **NOP sled**: `0x90` 반복 → 착지 주소 오차 흡수
- **jmp esp / call esp**: ESP가 가리키는(주입한 셸코드) 위치로 점프하는 가젯
- **RET 덮어쓰기**: 복귀주소를 셸코드 주소로 변경

## 방어 기법

| 기법 | 원리 |
|---|---|
| **Stack Guard / Canary** | 버퍼와 RET 사이에 카나리 값 → 함수 반환 직전 변조 확인, 변조 시 abort |
| **ASLR** | 스택·힙·라이브러리·실행 이미지 시작 주소를 실행마다 무작위화 → 주소 예측 불가 |
| **DEP / NX bit** | 데이터 영역(스택·힙) 실행 금지 → 주입한 셸코드 실행 불가 (→ 우회: ROP, ret2libc) |
| **RELRO** | GOT를 읽기 전용화 (GOT overwrite 방어) |
| **PIE** | 실행 파일 자체도 ASLR 대상으로 |
| **FORTIFY_SOURCE** | 컴파일 시 크기를 아는 함수 호출을 검사 버전으로 치환 |

## 프로세스 메모리 영역

| 영역 | 설명 |
|---|---|
| **Stack** | 지역 변수·함수 인자·복귀주소(RET) — 높은 주소에서 낮은 주소로 증가 |
| **Heap** | `malloc` 등 동적 할당 메모리 — 낮은 주소에서 높은 주소로 증가 |
| **Data** | 전역·정적 변수(초기화됨) |
| **Text(Code)** | 실행 코드(읽기·실행만, 쓰기 불가) |

공격 흐름: 취약 함수(`strcpy`/`gets`)로 버퍼 초과 입력 → RET를 셸코드(또는 ESP) 주소로 변조 → NOP Sled(`0x90`)로 착지 오차 흡수 → 셸코드 내 `setreuid(0,0)` 호출로 root 권한 획득 후 `/bin/bash` 실행.

**ASLR 확인/설정(Linux)**:
```bash
cat /proc/sys/kernel/randomize_va_space   # 0=비활성, 1=부분 무작위, 2=완전 무작위(스택+힙+라이브러리)
echo 2 > /proc/sys/kernel/randomize_va_space
```

## ASLR 우회

- **ret2libc / ROP**: 셸코드 없이 기존 라이브러리 코드 조각(gadget)을 연결해 실행 (DEP 우회)
- **정보 노출(info leak)**: 포맷 스트링·부분 오버플로우로 주소를 유출한 뒤 계산

## x86-64 호출 규약 & 동적 링킹 (23-2, 23-3)

**System V AMD64 ABI — 정수/포인터 인자 전달 순서**:

| 인자 | 1 | 2 | 3 | 4 | 5 | 6 | 반환값 |
|---|---|---|---|---|---|---|---|
| 레지스터 | **RDI** | **RSI** | **RDX** | RCX | R8 | R9 | RAX |

- `printf("%c,%c,%c", 'A','B','C')` → 포맷 문자열 = RDI, `'A'` = RSI, `'B'` = RDX, `'C'` = RCX.
- 7번째부터는 스택으로 전달. (32비트 x86은 전부 스택, cdecl)

**동적 링킹(Dynamic Linking)** 시 외부 라이브러리 함수 호출 경로:

- **PLT (Procedure Linkage Table)**: 코드가 외부 함수를 호출할 때 거치는 점프 테이블(스텁).
- **GOT (Global Offset Table)**: 실제 함수의 최종 주소가 채워지는 데이터 테이블.
- **Lazy binding**: 함수를 처음 호출할 때 동적 로더가 주소를 찾아 GOT에 기록, 이후는 GOT 직접 참조.
- 공격: **GOT overwrite** — GOT 항목을 조작해 정상 함수 호출을 공격자 코드로 리디렉션 → **RELRO**로 방어.
- 정적 링킹(Static Linking)은 라이브러리를 실행 파일에 포함 → PLT/GOT 불필요, 파일 크기 큼.
