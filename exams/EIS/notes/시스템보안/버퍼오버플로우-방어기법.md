## 한 줄 정의

버퍼 크기보다 **큰 입력**으로 인접 메모리(특히 복귀주소)를 덮어 **임의 코드를 실행**시키는 공격이다. 시험은 "유형 → 위험 함수 → 방어 기법 → 우회" 순으로, 그리고 메모리 구조·호출 규약까지 묻는다. {{4-10}} {{7-2}} {{9-3}} {{21-9}}

## 공격 흐름

1. 취약 함수(`strcpy` · `gets`)에 버퍼보다 긴 입력
2. **RET(복귀주소)** 를 셸코드(또는 ESP) 주소로 덮어쓰기
3. **NOP sled**(`0x90`)로 착지 주소 오차 흡수
4. 셸코드가 `setreuid(0,0)` 후 `/bin/bash` 실행 → root 획득

### 유형

| 유형 | 설명 |
|---|---|
| **스택** | 지역 버퍼 초과 → SFP·**RET** 덮어쓰기 |
| **힙** | `malloc` 영역 초과 → 인접 청크 메타데이터·함수 포인터 변조 |
| **정수** | 크기 계산이 wrap-around → 작게 할당하고 크게 복사 |

### 익스플로잇 구성 요소

- **셸코드**: 기계어 익스플로잇 본체
- **NOP sled**: `0x90` 반복
- **jmp esp / call esp**: ESP 가 가리키는(주입한) 셸코드로 뛰는 가젯

## 프로세스 메모리 영역

| 영역 | 내용 | 방향 |
|---|---|---|
| **Stack** | 지역 변수 · 인자 · RET | 높은 → 낮은 주소로 증가 |
| **Heap** | `malloc` 동적 할당 | 낮은 → 높은 주소로 증가 |
| **Data** | 전역·정적 변수 | |
| **Text** | 실행 코드 (읽기·실행만) | |

## 위험 함수 → 안전 함수

| 위험 | 대체 |
|---|---|
| `strcpy` | `strncpy` / `strlcpy` |
| `strcat` | `strncat` / `strlcat` |
| `sprintf` | `snprintf` |
| `gets` | `fgets` |
| `scanf("%s")` | `scanf("%9s")` (폭 지정) |

```c
strncpy(buf, argv[1], sizeof(buf)-1);
buf[sizeof(buf)-1] = '\0';   // strncpy 는 널 종료를 보장하지 않는다
```

## 방어 기법

| 기법 | 원리 |
|---|---|
| **Stack Guard / Canary** | 버퍼와 RET 사이 카나리 값 → 반환 직전 변조 확인, 변조 시 abort |
| **ASLR** | 스택·힙·라이브러리 시작 주소를 **실행마다 무작위화** |
| **DEP / NX** | 스택·힙 등 데이터 영역 **실행 금지** |
| **RELRO** | GOT 를 읽기 전용으로 (GOT overwrite 방어) |
| **PIE** | 실행 파일 자체도 ASLR 대상으로 |
| **FORTIFY_SOURCE** | 컴파일 시 크기를 아는 호출을 검사 버전으로 치환 |

ASLR 확인·설정(Linux):

```bash
cat /proc/sys/kernel/randomize_va_space   # 0 비활성 · 1 부분 · 2 완전 (스택+힙+라이브러리)
echo 2 > /proc/sys/kernel/randomize_va_space
```

> [!함정] 방어는 우회된다
> - DEP 우회 → **ret2libc / ROP**: 셸코드 없이 기존 라이브러리 코드 조각(gadget)을 연결
> - ASLR 우회 → **정보 노출(info leak)**: 포맷 스트링·부분 오버플로우로 주소를 알아낸 뒤 계산

## x86-64 호출 규약 {{23-2}}

System V AMD64 ABI 의 정수·포인터 인자 순서다.

| 인자 | 1 | 2 | 3 | 4 | 5 | 6 | 반환 |
|---|---|---|---|---|---|---|---|
| 레지스터 | **RDI** | **RSI** | **RDX** | RCX | R8 | R9 | RAX |

- 예: `printf("%c,%c,%c", 'A','B','C')` → 포맷 = RDI, `'A'` = RSI, `'B'` = RDX, `'C'` = RCX
- 7번째 인자부터는 스택. (32비트 x86 은 전부 스택, cdecl)

## 동적 링킹: PLT 와 GOT {{23-3}}

| 용어 | 역할 |
|---|---|
| **PLT** | 외부 함수 호출 시 거치는 점프 테이블(스텁) |
| **GOT** | 실제 함수의 최종 주소가 채워지는 데이터 테이블 |
| **Lazy binding** | 처음 호출 때 로더가 주소를 찾아 GOT 에 기록, 이후엔 GOT 직접 참조 |

- 공격 **GOT overwrite**: GOT 항목을 조작해 정상 호출을 공격자 코드로 → **RELRO** 로 방어
- 정적 링킹은 라이브러리를 실행 파일에 포함 → PLT/GOT 불필요, 파일 큼
