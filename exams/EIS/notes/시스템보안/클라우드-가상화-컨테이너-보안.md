## 한 줄 정의

클라우드 보안은 **가상화 계층의 위협(VM 탈출·컨테이너 탈출)** 과 **책임 공유 모델(이용자가 지킬 몫)** 을 구분하는 것이 출발점이다. 사고의 대부분은 기술 결함이 아니라 **잘못된 설정**에서 나온다.

> [!팁] 최신 출제 범위
> 최신 정보보안기사 범위다. IaaS/PaaS/SaaS 정의는 `robots-모바일앱-클라우드-보안` 노트와 함께 보자.

## 1. 가상화 구조

| 유형 | 설명 | 예 |
|---|---|---|
| **Type 1** (베어메탈) | 하드웨어 위에서 **직접** 실행 | ESXi · Hyper-V · Xen · KVM |
| **Type 2** (호스트형) | 호스트 OS **위에서** 실행 | VirtualBox · VMware Workstation |
| **컨테이너** | 호스트 **커널을 공유**, 프로세스 수준 격리 | Docker · containerd |

VM 은 각자 OS 라 **완전 격리·무겁고**, 컨테이너는 **가볍고 빠르지만 커널 공유라 격리가 약하다.**

## 2. 가상화(VM) 위협

| 위협 | 설명 |
|---|---|
| **VM Escape** | 게스트 VM 에서 하이퍼바이저·호스트로 침투 → 다른 VM 전체 장악 |
| **VM Hopping** | 같은 호스트의 다른 VM 으로 이동 |
| **VM Sprawl** | 관리 안 되는 VM 난립 → 패치 누락·공격 표면 확대 |
| **하이퍼재킹** | 악성 하이퍼바이저를 하위에 삽입 |
| **자원 고갈** | 한 VM 이 CPU·메모리 독점 → 다른 VM DoS |
| **이미지·스냅샷 유출** | 이미지에 남은 크리덴셜·데이터 |
| **부채널** | 공유 캐시·CPU 를 통한 정보 유출 (co-residency) |

대응: 하이퍼바이저 최소화·패치 · VM 간 네트워크 분리(**마이크로세그멘테이션**) · 이미지 무결성·서명 · 테넌트 격리 · 스냅샷 암호화

## 3. 컨테이너 보안

**위협:** 컨테이너 탈출(권한 있는 컨테이너·커널 취약점) · 취약한 베이스 이미지 · 시크릿 하드코딩 · 과도한 권한(`--privileged`) · 레지스트리 변조

| 단계 | 대응 |
|---|---|
| 이미지 | 신뢰 레지스트리 · 취약점 스캔(Trivy·Clair) · 서명(Notary/Cosign) · 최소 베이스(distroless) |
| 런타임 | 비루트 실행 · `--cap-drop ALL` · 읽기 전용 파일시스템 · seccomp/AppArmor/SELinux · 리소스 제한(cgroups) |
| 오케스트레이션 (K8s) | RBAC · NetworkPolicy · Pod Security Standards · 시크릿은 etcd 암호화·외부 볼트 · 관리 API 인증 |

## 4. 책임 공유 모델

| 계층 | IaaS | PaaS | SaaS |
|---|---|---|---|
| 데이터 · 계정 · 접근관리 | **이용자** | **이용자** | **이용자** |
| 애플리케이션 | 이용자 | 이용자 | CSP |
| OS · 미들웨어 · 런타임 | 이용자 | CSP | CSP |
| 가상화 · 물리 인프라 | CSP | CSP | CSP |

> [!함정] "클라우드는 안전하다"가 아니라 "안전하게 쓸 수 있다"
> 데이터·계정·접근관리는 **어떤 모델이든 이용자 책임**이다. 사고 원인 대부분은 **오픈 버킷, 과도한 IAM 권한** 같은 잘못된 설정이다.

### 클라우드 보안 위협 (CSA)

데이터 유출 · **잘못된 설정·부적절한 변경 관리** · 취약한 IAM · 계정 탈취 · 내부자 · 안전하지 않은 API · 제한된 가시성 · 공급망

## 5. 솔루션 · 인증

| 항목 | 설명 |
|---|---|
| **CASB** | 이용자↔클라우드 사이 프록시 — 가시성 · 접근통제 · DLP · 위협 탐지 |
| **CSPM** | 클라우드 **설정 오류**를 지속 점검 |
| **CWPP** | 클라우드 **워크로드**(VM·컨테이너·서버리스) 보호 |
| **SASE** | SD-WAN + 클라우드 보안(SWG·CASB·ZTNA·FWaaS) 통합 |
| **CSAP** | 국내 공공기관용 클라우드 보안 인증(KISA), IaaS/SaaS/DaaS 등급제 |
| **ISO 27017 / 27018** | 클라우드 보안통제 / 클라우드 개인정보(PII) 보호 |
