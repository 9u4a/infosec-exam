## 한 줄 정의

유닉스 파일 권한은 **누가(u·g·o) 무엇을(r·w·x)** 할 수 있는지를 정하고, **특수 비트**는 "실행하는 순간 다른 주체의 권한을 빌리는" 예외 장치다. 취약한 SetUID root 파일은 곧바로 **권한 상승 통로**가 되므로 시험은 읽기 → 점검 → 제거 순서로 묻는다. {{27-15}} {{1-11}}

## 권한 표기 읽는 법

`-rwxr-x--x` 를 **타입 / 소유자 / 그룹 / 기타** 로 끊고, 자리마다 `r=4 · w=2 · x=1` 을 더한다.

| 구간 | 표기 | 합 | 할 수 있는 일 |
|---|---|---|---|
| 타입 | `-` | — | 일반 파일 |
| 소유자(u) | `rwx` | 7 | 읽기·쓰기·실행 |
| 그룹(g) | `r-x` | 5 | 읽기·실행 (쓰기 ✗) |
| 기타(o) | `--x` | 1 | 실행만 |

→ 결과 **751**

> [!팁] 디렉터리에서는 뜻이 다르다
> `r` = 목록 조회 · `w` = 파일 생성·삭제 · `x` = 진입(cd)·내부 접근

타입 문자: `d` 디렉터리 · `l` 링크 · `c`/`b` 장치.

## 특수 비트 3종

| 비트 | 값 | 표기 위치 | 효과 |
|---|---|---|---|
| **SetUID** | 4000 | 소유자 `x` 자리 → `s` | 실행 중 **파일 소유자 권한** |
| **SetGID** | 2000 | 그룹 `x` 자리 → `s` | 실행 중 **소유 그룹 권한** · 디렉터리면 그룹 상속 |
| **Sticky** | 1000 | 기타 `x` 자리 → `t` | 디렉터리 안 파일은 **소유자·root만 삭제** |

- 대표 예: `/usr/bin/passwd`(SetUID, 일반 사용자가 root 소유 `shadow` 를 수정), `/tmp`(Sticky)
- 실행 권한이 없는데 특수 비트만 있으면 **대문자** `S`·`T` → 효과 없음

> [!함정] SetUID 는 "실행한 사람"이 아니라 "파일 주인"의 권한
> 소유자가 root 인 SUID 파일에 취약점이 있으면 일반 사용자가 root 셸을 얻는다.

## 위험한 SUID 찾아서 없애기

정상 SUID(passwd·su·sudo·ping·mount·crontab·chsh) 외 파일, 사용자 스크립트·복사본은 의심 대상이다.

```bash
find / -user root -type f \( -perm -4000 -o -perm -2000 \) -exec ls -al {} \;
find / -perm -4000 2>/dev/null     # SUID 만
find / -perm -2000 2>/dev/null     # SGID 만

chmod -s <파일>                    # SUID/SGID 제거
chmod u-s <파일>   /   chmod g-s <파일>
```

## RUID · EUID · SUID(saved)

프로세스는 UID 를 3개 가진다. **권한 판단은 EUID** 로 한다.

| 이름 | 의미 |
|---|---|
| RUID | 실제로 실행한 사용자 |
| EUID | 지금 권한 판단에 쓰이는 UID |
| SUID(saved) | 나중에 돌아갈 UID 보관 |

SetUID root 실행 직후 → RUID=사용자 · EUID=0 · SUID=0

- `setuid(600)` (EUID=0 일 때): 셋 다 600 → **영구 강등**, 복원 불가
- `seteuid(600)`: EUID 만 변경 → SUID 로 **복원 가능**

## umask — 새 파일에서 "뺄" 권한

**기본 권한 − umask** 가 새 파일·디렉터리의 권한이다. 기본값은 파일 666, 디렉터리 777.

| umask | 파일 | 디렉터리 | 비고 |
|---|---|---|---|
| 022 | 644 | 755 | 일반 기본값 |
| 027 | 640 | 750 | 보안 강화 권장 |
| 077 | 600 | 700 | 본인만 접근 |

설정 위치: `/etc/profile` · `/etc/bashrc` · `~/.bashrc` 의 `umask 022`

> [!함정] 백업 스크립트
> {{15-14}} `/etc/*` 를 tar 로 묶으면 `shadow` 도 들어간다. 스크립트 맨 앞에 `umask 266`(또는 077)을 넣어 결과 tar 가 **소유자 읽기 전용(400)** 이 되게 한다.
