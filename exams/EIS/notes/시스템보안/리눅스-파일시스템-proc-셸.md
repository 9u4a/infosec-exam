## 한 줄 정의

파일시스템·/proc·셸은 **침해 분석의 도구상자**다. 파일 시간(MAC)으로 "언제 바뀌었나"를, `/proc` 으로 "무엇이 돌고 있나"를, `find` 로 "어떤 파일이 수상한가"를 찾는다. 경쟁 조건은 이 도구들이 노리는 대표 취약점이다. {{1-12}} {{8-4}} {{24-9}}

## 저널링 (Journaling) {{5-1}}

파일 변경 전에 **저널(로그) 영역에 먼저 기록**하고 수행한다. 비정상 종료로 손상돼도 저널을 재생(replay)해 빠르게 복구한다.

- 리눅스 **ext3** 부터 지원 (ext2 는 없음). ext4 · XFS · JFS · ReiserFS 도 저널링
- ext3 저널 모드: `journal`(데이터+메타데이터) · **`ordered`(기본, 메타데이터만)** · `writeback`

### 윈도우 — NTFS {{29-2}}

| NTFS 기능 | |
|---|---|
| 저널링 · 대용량 | 대용량 파일 지원 |
| 보안 | 파일/폴더 단위 **ACL**, **EFS 암호화** |
| 기타 | 압축 · 쿼터 · ADS |

FAT32 는 권한·저널·4GB 이상 파일을 지원하지 않는다.

## MAC Time — 파일의 시간 3종

| 속성 | 의미 | 바뀌는 때 |
|---|---|---|
| **Mtime** | 내용 수정 | 파일 내용이 바뀔 때 |
| **Atime** | 접근 | 파일을 읽을 때 |
| **Ctime** | 속성 변경 | 권한·소유자 등 메타데이터가 바뀔 때 |

`stat <파일>` 로 셋 다 본다. 침해 분석에서는 보통 **Mtime** 기준으로 특정 시각 이후 바뀐 파일을 찾는다.

> [!함정] touch 로 시간을 되돌려도 Ctime 은 남는다
> 공격자가 `touch` 로 Mtime 을 위조해도 Ctime 까지 숨기지 못하는 경우가 많다.

## /proc 가상 파일시스템 {{8-4}} {{24-9}}

메모리에만 존재하며 커널·프로세스 상태를 파일처럼 보여 준다.

| 경로 | 내용 |
|---|---|
| `/proc/<PID>/exe` | 실행 파일로의 심볼릭 링크 |
| `/proc/<PID>/cmdline` | 실행 시 명령행 인자 |
| `/proc/<PID>/fd/` | 프로세스가 연 파일 디스크립터 |
| `/proc/<PID>/maps` | 메모리 매핑 (ASLR 확인) |
| `/proc/sys/net/ipv4/...` | 커널 네트워크 파라미터 (`ip_forward` 등) |

> [!팁] `ps` 를 믿을 수 없을 때
> `ls /proc` 로 실제 실행 중인 PID 목록을 직접 본다.

## hosts 파일 {{9-1}}

도메인 ↔ IP 정적 매핑이며 **DNS 질의보다 우선**한다.

- Linux/Unix: `/etc/hosts`
- Windows: `C:\Windows\System32\drivers\etc\hosts` (7 이상은 관리자 권한 없이 수정 불가)
- 악성코드가 변조해 **파밍**(정상 도메인 → 악성 IP)에 쓴다

## find 활용 {{1-12}}

```bash
find /etc/apache/conf -type f -mtime -10      # 10일 이내 내용 변경
find / -type f -mtime +365                    # 1년 이상 미변경
find / -newer /etc/passwd                      # 특정 파일보다 최근 변경
find / \( -perm -4000 -o -perm -2000 \) -type f   # SUID / SGID
find / -nouser -o -nogroup                     # 소유자 없는 파일 (침해 흔적)
```

| 옵션 | 뜻 |
|---|---|
| `-mtime -10` | 10일 **이내** |
| `-mtime +10` | 10일 **이전** |
| `-mmin -60` | 60분 이내 |

## Race Condition (경쟁 조건) {{19-3}}

여러 프로세스가 공유 자원에 동시에 접근할 때 **타이밍**에 따라 결과가 달라지는 점을 악용한다.

- 대표 유형 **TOCTOU** (Time-of-Check to Time-of-Use): 검사와 사용 *사이*에 심볼릭 링크를 바꿔치기
- 위험한 경우: SUID 프로그램이 `/tmp` 에 **예측 가능한 이름**으로 임시 파일을 만들 때
- 대응: 검사~사용을 원자적으로 (`O_CREAT|O_EXCL`), 임시 파일은 `mkstemp()`, umask 강화, 락 사용

## 셸 (Shell) {{28-13}}

**사용자와 커널 사이의 명령어 해석기**(인터페이스)다.

1. 명령어 해석·실행
2. 셸 스크립트 프로그래밍 (변수·제어문)
3. 환경 설정 (환경변수 · 리다이렉션 · 파이프)
4. 작업 제어 (포그라운드 / 백그라운드)

종류는 sh · bash · csh · ksh · zsh. 로그인 셸은 `/etc/passwd` 7번째 필드이고, 계정 잠금용은 `/sbin/nologin` · `/bin/false` 다.
