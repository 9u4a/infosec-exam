## 한 줄 정의

침해사고가 나면 **정해진 절차(대응 7단계)** 로 막고, **증거를 훼손하지 않고(포렌식 5원칙)** 모으고, **법이 정한 곳에 알리는(통지·신고)** 것이 한 흐름이다. {{8-13}} {{16-12}} {{17-6}} {{30-9}} {{14-5}}

## 침해사고 대응 7단계

사고 전 준비 → 사고 탐지 → **초기 대응** → 대응 전략 체계화 → 사고 조사(포렌식·원인 분석) → 보고서 작성 → 복구 및 해결(재발 방지)

> [!함정] 순서 주의
> '**초기 대응**'(초동 조치·확산 차단·증거 보존 시작)이 '**대응 전략 체계화**' 보다 먼저다.

NIST SP 800-61: 준비 → 탐지·분석 → 봉쇄·근절·복구 → 사후 활동

## 디지털 포렌식

### 5대 원칙

| 원칙 | 내용 |
|---|---|
| **정당성** | 적법한 절차로 수집 (위법수집증거 배제) |
| **재현성** | 같은 조건 → 같은 결과 |
| **신속성** | 즉시 대응 (휘발성 데이터 소실 방지) |
| **연계보관성** (Chain of Custody) | 수집 → 이송 → 분석 → 보관 → 제출 각 단계의 책임자·시각·방법 기록 |
| **무결성** | 원본과 동일함을 **해시**로 증명, 쓰기방지장치로 이미징 후 **사본 분석** |

### 수집 우선순위 — 휘발성 순서

> [!암기] 레지스터·캐시 → 메모리(RAM) → 네트워크 연결·프로세스 상태 → 임시 파일 → 디스크 → 원격 로그 → 물리 백업

### 분석 유형

| 유형 | 내용 | 도구 |
|---|---|---|
| **정적 분석** | 실행하지 않고 구조·문자열·시그니처·디스어셈블 | PEiD · IDA · Ghidra · YARA |
| **동적 분석** | 격리 환경(**샌드박스**)에서 실행 후 행위·네트워크·시스템 변경 관찰 | Cuckoo · Any.Run |

anti-VM / anti-debugging 회피 기법에 주의한다.

### 로그 분석 포인트

- 유닉스: `utmp` `wtmp` `btmp` `lastlog` `pacct` · `/var/log/messages` · `secure`
- 웹: access log(공격 요청) · error log
- 삭제된 실행 파일: `/proc/<PID>/exe (deleted)` → `cp /proc/<PID>/exe 복원경로`
- `ps` 변조 의심 시: `/proc` 직접 조사 · `lsof` · 정적 컴파일 도구

## 신고 · 통지 · 경보

### 개인정보 유출 통지·신고 (현행)

- **정보주체 통지**: 유출을 알게 되면 **지체 없이** (정당 사유 없으면 **72시간 이내**)
  - 통지 내용: 유출 항목·시점·경위 · 정보주체가 할 수 있는 조치 · 처리자 대응·구제절차 · 신고 담당부서·연락처
- **개인정보위 / KISA 신고**: **1천 명 이상** 유출 또는 민감·고유식별정보 유출 시 **72시간 이내**

> [!현행] 통지 기준
> **종전(기출 대비)**: 옛 정보통신망법 회차(7-13 등)는 **"지체 없이 5가지 통지"** 기준으로 채점.
> **현행**: 개인정보보호법 제34조로 통합.

### 사이버 위기경보 5단계 {{14-5}}

> [!암기] 정상 → 관심 → 주의 → 경계 → 심각 (파랑 → 노랑 → 주황 → 빨강)

| 단계 | 의미 |
|---|---|
| 관심 | 위협 징후 탐색·정보 수집 |
| 주의 | 다수 기관 피해 우려 |
| 경계 | 복수 분야 피해 확산 |
| 심각 | 국가적 피해, 범정부 대응 |

발령: 과기정통부(민간) · 국정원(공공) · 국방부(국방)

## 침해대응 유관 기관

| 기관 | 역할 |
|---|---|
| **KISA** (KrCERT/CC) | 민간 침해사고 접수·분석·전파, 보호나라 |
| **ISAC** {{13-2}} | 금융·통신·에너지 등 **분야별** 실시간 경보·분석 체계 운영, 취약점 정보 공유 |
| **국가사이버안보센터** (NCSC) | 공공·국가기관 총괄 |
| **CERT / CSIRT** | 조직 내부 침해사고 대응팀 |
