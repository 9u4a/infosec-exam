> 기준 시점: 2026-09 · 개인정보보호법 시행령/고시 제2026-9호(2026.7.1) · 2026.9.11 개정. 옛 회차 정답은 출제 당시 기준.

## 한 줄 정의

**ISMS-P 의 국제 짝**이다. 국제 표준은 **ISO/IEC 27000 시리즈 · NIST · 기타 프레임워크**로, 국내 인증은 **ISMS-P · CC · CSAP** 로 나뉜다. 번호(27001·27002·27017·27018·27701)와 역할을 짝으로 외운다. 필기 단골이다.

## ISO/IEC 27000 시리즈

| 표준 | 내용 |
|---|---|
| **27000** | 용어·개요 |
| **27001** | ISMS **요구사항**(인증 기준), Annex A 통제목록. 2022판은 계획-실행-평가-개선 |
| **27002** | 정보보안 **통제 실무 지침** (구현 가이드). 2022판 = **93개 통제, 4개 테마**(조직·인적·물리·기술) + 5개 속성 태그 |
| **27003** | ISMS 구현 가이드 |
| **27004** | 보안 측정·지표 |
| **27005** | 정보보안 **위험관리** |
| **27011** | 통신 사업자 |
| **27017** | **클라우드 서비스** 보안 통제 |
| **27018** | 클라우드 **개인정보(PII)** 보호 |
| **27701** | **개인정보보호 관리체계(PIMS)** — 27001/27002 확장, GDPR 대응 |
| **27031 / 27035 / 27037** | 사업연속성 / 침해사고 관리 / 디지털 증거 |

> [!함정] 27001 vs 27002
> **27001 = 요구사항(인증 대상)**, **27002 = 실무 지침(인증 대상 아님)** 이다.

27001 인증 구조: 인정기관(KAB 등) → 인증기관 → 조직. 유효 **3년**, 매년 사후심사.

## NIST 프레임워크

| 문서 | 내용 |
|---|---|
| **CSF** | **거버넌스 · 식별 · 보호 · 탐지 · 대응 · 복구** (1.x 는 5개 기능, **2.0 은 거버넌스가 추가돼 6개**). 자율 프레임워크 |
| **SP 800-53** | 연방 시스템 보안·프라이버시 통제 카탈로그 |
| **SP 800-61** | 침해사고 대응 — 준비 → 탐지·분석 → 봉쇄·근절·복구 → 사후 |
| **SP 800-37 (RMF)** | 위험관리 프레임워크 |
| **SP 800-63** | 디지털 신원(인증) 지침 — AAL / IAL / FAL 등급 |

## 기타 국제 표준

| 표준 | 내용 |
|---|---|
| **ISO 22301** | 사업연속성 관리체계 (BCMS) |
| **ISO 31000** | 리스크 관리 일반 |
| **COBIT** | IT 거버넌스 프레임워크 |
| **ITIL** | IT 서비스 관리 |
| **PCI-DSS** | 카드 데이터 보안 (12개 요구사항) |
| **GDPR** | EU 개인정보보호 규정 (과징금 전세계 매출 4% 또는 2천만 유로) |

## 국내 인증제도 비교

| 인증 | 대상 | 주관 | 유효기간 |
|---|---|---|---|
| **ISMS-P** | 정보보호 및 개인정보보호 **관리체계** | KISA / 한국정보통신진흥협회, 개인정보위·과기정통부·방통위 | 3년 (사후 연 1회) |
| **CC 인증** | 정보보호 **제품**의 보안 기능 | IT보안인증사무국 / 국정원 | — |
| **CSAP** | 공공용 **클라우드 서비스** | KISA | 5년 (사후 연 1회) |
| **PIPL** (우수 개인정보 처리자) 등 | 상황별 | 개인정보위 | — |
| 정보보호 준비도 평가 / 정보보호 공시 | 기업의 정보보호 투자·인력 현황 공개 | KISA | 연 단위 |

PIMS + ISMS 는 **2018 년 ISMS-P 로 통합**됐고 PIMS 단독 인증은 폐지됐다.

## 관리체계 공통 사이클 — PDCA

> [!암기] Plan → Do → Check → Act
> **Plan** 정책·범위·위험평가·대책 수립 → **Do** 구현·운영 → **Check** 모니터링·내부감사·경영진 검토 → **Act** 시정·개선. **지속적 개선**이 핵심이다.
