> 기준 시점: 2026-09 · NIST SP 800-207(2020) · CISA ZTMM 2.0(2023) · 과기정통부·KISA 「제로트러스트 가이드라인」 1.0(2023)·2.0(2024).

## 한 줄 정의

**"절대 신뢰하지 말고, 항상 검증하라 (Never trust, always verify)."** 내부망에 있다는 이유로 믿지 않고, **모든 접근 요청마다** 사용자·기기·상황을 확인해 **최소 권한**만 **세션 단위**로 준다. 제품이 아니라 **보안 설계 원칙(아키텍처)** 이다.

## 경계 기반 보안 vs 제로트러스트

| 구분 | 경계 기반 (성곽 모델) | 제로트러스트 |
|---|---|---|
| 신뢰 기준 | **위치** (내부망 = 신뢰) | **신원·기기 상태·맥락** |
| 검증 시점 | 입구에서 1회 | **요청마다 지속** |
| 내부 이동 | 자유 (측면 이동 쉬움) | **마이크로 세그멘테이션**으로 차단 |
| 원격 접속 | VPN → 망 전체 접근 | ZTNA → **해당 앱만** 접근 |
| 약점 | 내부자·계정 탈취·클라우드 | 구축 복잡, 정책 관리 부담 |

## NIST SP 800-207 구성 요소

| 구성 요소 | 역할 |
|---|---|
| **PE** (Policy Engine) | 접근 허용·거부 **결정** (신뢰 알고리즘) |
| **PA** (Policy Administrator) | 결정을 받아 세션·토큰 **생성/종료 명령** |
| **PEP** (Policy Enforcement Point) | 주체와 자원 사이에서 실제 **연결 허용·차단** |

- **PDP**(Policy Decision Point) = PE + PA. 제어 평면은 PDP, 데이터 평면은 PEP
- PE 입력: IAM·ID 정보, 기기 상태(CDM), 위협 인텔리전스, 접근 로그, 산업 규제

> [!암기] 결정(PE) → 지시(PA) → 집행(PEP)
> 판사(PE)가 판결하고, 법원 행정(PA)이 명령을 내리고, 경비(PEP)가 문을 연다.

## 핵심 원칙 (NIST 7원칙 요약)

1. 모든 데이터·서비스를 **자원**으로 본다
2. 네트워크 위치와 상관없이 **모든 통신을 보호**한다
3. 자원 접근은 **세션 단위**로 허가한다
4. 접근은 **동적 정책**(신원·기기·행위·환경)으로 결정한다
5. 모든 자산의 **무결성·보안 상태를 감시**한다
6. 인증·인가를 접근 전에 **엄격하고 동적으로** 적용한다
7. 자산·트래픽 정보를 **수집해 보안을 계속 개선**한다

## 성숙도 모델 (CISA ZTMM 2.0)

| 구분 | 내용 |
|---|---|
| **5대 기둥** | 신원(Identity) · 기기(Devices) · 네트워크 · 애플리케이션·워크로드 · 데이터 |
| 공통 역량 | 가시성·분석 · 자동화·오케스트레이션 · 거버넌스 |
| 성숙도 4단계 | **기존(Traditional) → 초기(Initial) → 향상(Advanced) → 최적(Optimal)** |

- 국내 가이드라인도 신원·기기·네트워크·시스템·애플리케이션·데이터를 핵심 요소로 둔다
- 2.0(2024)은 **성숙도 단계별 도입 절차**와 점검 항목을 보강했다

## 구현 기술

| 기술 | 내용 |
|---|---|
| **MFA · IAM** | 강한 인증, 역할·속성 기반 최소 권한 |
| **마이크로 세그멘테이션** | 워크로드 단위로 망을 잘게 분리 → 측면 이동 차단 |
| **SDP** (Software Defined Perimeter) | 인증 전엔 서비스가 **보이지 않음** (SPA, 단일 패킷 인가) |
| **ZTNA** | 사용자 ↔ **특정 앱**만 연결, VPN 대체 |
| **EDR · MDM** | 기기 보안 상태를 접근 판단에 반영 |
| **SASE** | SD-WAN + 클라우드 보안(SWG · CASB · ZTNA · FWaaS) 통합 |

> [!함정] 제로트러스트 = 제품 구매가 아니다
> "ZTNA 솔루션을 샀으니 제로트러스트 완료" 는 오답이다. **원칙·아키텍처**이고 단계적으로 성숙도를 올린다.

> [!함정] VPN 과의 차이
> VPN 은 인증 후 **망 전체**에 들어가게 한다. ZTNA 는 **허락된 앱 하나**만 연결하고 접속 중에도 계속 재평가한다.
