## 한 줄 정의

보안 관제는 **로그·이벤트를 모아서(수집) → 이상을 찾아서(탐지) → 판정하고(분석) → 막는(대응)** 일이다. 솔루션은 **ESM → SIEM → SOAR** 로 진화했고, 위협 정보는 **TMS · CTI · ISAC** 로 공유한다. {{1-6}} {{13-2}} {{16-8}} {{25-12}} {{29-15}} {{31-12}} {{32-5}}

## 1. 솔루션 계보

| 솔루션 | 세대 | 특징 |
|---|---|---|
| **ESM** | 1세대 | 방화벽·IDS 등 **보안장비 로그**를 통합 관제, 실시간 상관분석 |
| **SIEM** {{31-12}} {{32-5}} | 2세대 | 보안장비 + **서버·앱·네트워크 전 IT 로그**를 **빅데이터** 기반으로 수집·통합·분석. 장기 저장 · 컴플라이언스 리포트 · 포렌식 |
| **SOAR** {{25-12}} | 3세대 | 2015 가트너 제시. **AI/자동화 플레이북**으로 경보 분류·**대응까지 자동 수행**, SIEM 보다 진보 |
| **TMS** {{16-8}} | — | 전사 IT 위협정보를 수집·분석·경보·관리, 외부 **공신력 있는 기관의 위협정보**를 실시간 연동 |
| **XDR** | 최신 | 엔드포인트·네트워크·메일·클라우드 탐지를 상관분석 |

> [!암기] SIEM 과 SOAR 의 차이
> **SIEM = 모아서 찾기(탐지)**, **SOAR = 찾은 것에 대한 대응 자동화.**

## 2. SIEM 로그 처리 4단계 {{1-6}}

| 단계 | 내용 |
|---|---|
| **로그 수집** | 에이전트·SNMP·syslog 로 중앙 서버에 저장 |
| **로그 분류** | 이벤트 누적 횟수 등 유사 정보를 그룹핑 |
| **로그 변환 (정규화)** | 서로 다른 포맷을 공통 스키마로 표준화 |
| **로그 분석 (상관분석)** | 룰·통계·머신러닝으로 위협 탐지, 경보 발생 |

### 관제 시스템의 3대 구성요소 {{29-15}}

1. **에이전트(수집 센서)** — 서버·네트워크·보안장비에 설치돼 로그·이벤트를 중앙으로 전송
2. **정보 수집(관리) 서버** — 수집·정규화·상관분석·처리 후 DB 저장
3. **콘솔(관제 화면)** — 분석 결과·경보를 시각화, 관제 요원이 조회·대응

## 3. 관제 절차와 운영

```text
수집(로그·이벤트) → 탐지(룰·시그니처·이상행위) → 분석(정탐/오탐 판정, 심각도 등급)
 → 대응(차단·격리·조치 요청) → 보고·전파 → 사후관리(룰 튜닝·재발방지)
```

- **1차(관제) 대응**: 24×365 모니터링, 경보 1차 판단, 단순 차단
- **2차(심층) 분석**: 정밀 분석 · 포렌식 · 침해 여부 확정 · 위협 헌팅
- 지표: 탐지 건수 · **오탐률(FP)** · **MTTD**(평균 탐지 시간) · **MTTR**(평균 대응 시간)

### 관제 유형

| 유형 | 설명 | 장단점 |
|---|---|---|
| **자체 관제** | 조직이 직접 SOC 운영 | 내부 이해도↑, 비용·인력 부담 |
| **파견 관제** | 전문업체 인력이 고객사에 상주 | 통제 용이, 인건비 |
| **원격 관제** | 관제업체 센터에서 원격 모니터링 | 비용 효율, 내부 맥락 부족 |
| **클라우드 관제** | SECaaS — 관제 기능을 클라우드로 | 빠른 도입, 데이터 위탁 이슈 |

## 4. 위협 정보 — CTI 와 ISAC

### 위협 인텔리전스 (CTI)

| 구분 | 내용 | 가치 |
|---|---|---|
| **IOC** (침해지표) | 악성 IP·도메인·해시·URL — 즉시 차단용 | **단기** |
| **TTP** (전술·기법·절차) | 공격자 행동 패턴 (MITRE ATT&CK) | **오래 감** |

**STIX**(위협정보 표현 표준) / **TAXII**(교환 프로토콜)로 기관 간 공유한다. 출처는 상용 피드 · KISA C-TAS · ISAC · OSINT.

### 정보공유분석센터 (ISAC) {{13-2}}

침해사고 시 **실시간 경보·분석 체계**를 운영하며 **금융·통신 등 분야별** 정보통신기반시설을 보호하는 기관이다.

- 근거: 정보통신기반보호법 §16. 회원사 간 취약점·침해정보 공유, 분야별 관제
- 유관: **KISA**(민간 종합, C-TAS), **국가사이버안보센터**(공공), 금융보안원(금융 ISAC)
