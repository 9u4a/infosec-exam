## 한 줄 정의

포트 스캔은 **어느 포트가 열려 있는지** 알아내는 정찰이다. 시험은 스캔별로 *보내는 플래그 · 열린/닫힌 포트의 응답 · 특징* 을 표로 묻는다. {{4-8}} {{6-1}} {{10-1}} {{14-14}} {{27-6}}

## 1. TCP 스캔

| 스캔 | 보내는 플래그 | 열린 포트 | 닫힌 포트 | 특징 |
|---|---|---|---|---|
| **Connect (Open)** | 정상 3-way | 연결 성립 | RST+ACK | 로그가 남음, 권한 불필요 |
| **SYN (Half-Open)** | SYN | SYN+ACK (스캐너가 RST) | RST+ACK | **스텔스** — 세션 미완성, root 필요 |
| **FIN** | FIN | 무응답 | RST | RFC 793, 방화벽 우회 |
| **NULL** | 플래그 없음 | 무응답 | RST | 〃 |
| **Xmas** | FIN+PSH+URG | 무응답 | RST | 〃 |
| **ACK** | ACK | RST (unfiltered) | RST | **포트 개폐가 아니라 방화벽 필터링 여부** 판별 (무응답 → filtered) |

> [!암기] FIN · NULL · Xmas 판별
> **RST 가 오면 닫힘, 무응답이면 열림 또는 필터링.** 
> Windows 등 RFC 를 안 지키는 스택은 항상 RST 를 보내 **구분이 안 된다.**

## 2. UDP 스캔

- 닫힌 포트: **ICMP Port Unreachable** (Type 3, Code 3)
- 열린 포트: 무응답 (또는 애플리케이션 응답) → 느리고 불확실

## 3. 기타 기법

| 기법 | 설명 |
|---|---|
| **Decoy** (`nmap -D`) | 위장 IP 를 섞어 실제 공격 IP 은닉 |
| **Idle (Zombie)** | 제3의 유휴 호스트의 **IP ID 증가**를 관찰해 완전 익명 스캔 |
| **Fragment** | 패킷을 잘게 쪼개 IDS·방화벽 우회 (tiny fragment) |
| **배너 그래빙** | 열린 포트에 연결해 서비스·버전 수집 → CVE 매핑 |

## 4. 스캔 · 패킷 생성 도구

| 도구 | 특징 |
|---|---|
| **nmap** | 대표 스캐너. `-sS`(SYN) · `-sT`(Connect) · `-sU`(UDP) · `-sF/-sN/-sX` · `-O`(OS) · `-sV`(버전) |
| **hping3** | Salvatore Sanfilippo 제작. TCP·UDP·**ICMP**·RAW-IP 패킷을 직접 생성 → 방화벽 룰 테스트 · 커스텀 스캔 · **DDoS 훈련(부하 발생)** |
| **Scapy** | 파이썬 기반 패킷 조작 프레임워크 |

예) `hping3 -S -p 80 --flood --rand-source <target>` — SYN flood 시뮬레이션

## 5. 탐지 · 대응

- 짧은 시간에 다수 포트 접근 → IDS(portscan preprocessor), 방화벽 rate limit
- 불필요한 서비스 포트 폐쇄 · 배너 최소화 · **스텔스(무응답 DROP) 정책**
