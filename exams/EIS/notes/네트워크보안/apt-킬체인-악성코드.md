## 한 줄 정의

**APT** 는 특정 표적을 대상으로 다양한 기법을 써서 **장기간 은밀하게** 침투하는 공격이다. 시험은 "단계(킬체인) → 진입로 → 회피·지속 기법 → 악성코드 종류" 순으로 묻는다. 단발성 공격과의 차이는 **표적성 + 지속성 + 은밀성**. {{5-11}} {{7-5}} {{17-1}} {{21-5}}

## 1. 공격 단계 — 킬체인과 ATT&CK

### 사이버 킬체인 (록히드마틴, 7단계)

> [!암기] 정찰 → 무기화 → 전달 → 취약점 공격 → 설치 → **C2** → 표적 행동

어느 한 단계만 확실히 끊어도 **최종 목표 달성을 차단**할 수 있다는 것이 핵심 아이디어다.

### MITRE ATT&CK — 킬체인의 세분화판

실제 공격에서 관찰된 **전술(Tactic)·기술(Technique)·절차(TTP)** 를 체계화한 무료 지식베이스. 위협 헌팅과 탐지 커버리지 평가에 쓴다. (Unified Kill Chain 은 14단계 확장판)

| 순서 | 전술 |
|---|---|
| 1~3 | 정찰 → 자원 개발 → **초기 침투** |
| 4~6 | 실행 → **지속성** → 권한 상승 |
| 7~9 | **방어 우회**(루트킷·난독화) → 자격증명 접근 → 정보 수집(Discovery) |
| 10~12 | **내부 이동** → 데이터 수집 → C2 |
| 13~14 | 유출(Exfiltration) → 영향(Impact, 파괴·랜섬웨어) |

## 2. 초기 침투 — APT 의 진입로

| 기법 | 설명 |
|---|---|
| **스피어피싱** | 특정 인물을 겨냥한 맞춤 악성 메일·첨부 |
| **워터링홀** | 표적이 자주 가는 사이트를 먼저 감염 |
| **드라이브 바이 다운로드** | 취약한 브라우저·플러그인으로 **방문만 해도** 설치 |
| **공급망 공격** {{11-10}} | 빌드·배포 서버·업데이트 채널·오픈소스 의존성을 침해 → 개발사가 패키징할 때 **정상 파일에 악성 모듈이 삽입**돼 배포 |

공급망 공격 사례: SolarWinds · 3CX · xz-utils 백도어. 사용자는 서명된 정상 업데이트로 인식한다.
대응: **SBOM** · 코드 서명 검증 · 빌드 무결성(재현 가능 빌드) · 의존성 고정·스캔 · 공급업체 보안 실사

### 드라이브 바이 다운로드 흐름

1. 공격자가 정상 사이트 A 에 악성 코드를 심는다 (주로 `<iframe width=0 height=0 src="B">` 처럼 **보이지 않게**)
2. 피해자가 A 를 정상 방문
3. 은닉 iframe 이 악성 사이트 B 에 자동 연결 (필요 시 C 로 리다이렉트)
4. 브라우저·플러그인(Flash·PDF·ActiveX) 취약점 실행
5. 악성코드 자동 다운로드·설치
6. 감염 PC 가 C2 와 통신 시작

탐지: HTTP Referer(유입 경로) · 브라우저 캐시 분석(IECacheView) · 프로세스 트리(Process Explorer) · 비정상 TCP 연결(TCPView). 은닉 스크립트는 흔히 `unescape()` 와 16진수 인코딩을 쓴다.

## 3. 회피 · 지속 기법

| 기법 | 설명 |
|---|---|
| **DGA** | 매일 수천 개 도메인을 생성해 그중 하나로 C2 접속 → 블랙리스트 회피 |
| **Fast Flux** | C2 의 IP 를 DNS 로 매우 빠르게 계속 변경 → IP 차단 회피 |
| **Domain Shadowing** | 탈취한 합법 도메인의 서브도메인을 C2 로 → 평판 기반 차단 우회 |
| **Pass the Hash** | LSASS 메모리의 NTLM 해시를 **그대로 제출**해 원격 인증 (크래킹 불필요) |
| **Living off the Land** | PowerShell·WMI 등 정상 도구로 공격 (파일리스) |
| **Run 키 등록** | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` 에 경로 등록 → 재부팅 후에도 지속 |

> [!함정] DGA vs Fast Flux
> DGA 는 **도메인 이름**을 계속 바꾸고, Fast Flux 는 한 도메인의 **IP** 를 계속 바꾼다.

## 4. 악성코드 유형

| 유형 | 설명 |
|---|---|
| **바이러스** | 숙주 파일에 기생, 사용자 실행으로 전파 |
| **웜** | **자가 복제**, 네트워크로 자동 전파 |
| **트로이목마** | 정상 프로그램 위장, 자가 복제 없음 |
| **드롭퍼** | payload 를 품고 있다가 시스템에 떨어뜨려 설치 |
| **인젝터** | 파일 없이 정상 프로세스 메모리에 코드 주입 |
| **다운로더** | payload 를 원격에서 받아옴 |
| **루트킷** | 커널·명령어(ps/ls/netstat) 변조로 은닉 |
| **랜섬웨어** | 파일 암호화 후 금전 요구 |
| **백도어** | 정상 인증을 우회하는 원격 접속 통로 |
| **봇 / 좀비** | C2 명령을 받는 감염 호스트 (봇넷) |

## 5. 분석 도구와 난독화

| 유형 | 도구 |
|---|---|
