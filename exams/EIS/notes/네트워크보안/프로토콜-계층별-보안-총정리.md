## 한 줄 정의

흩어진 네트워크 노트를 **계층으로 묶는 지도**다. "이 프로토콜·공격·대응이 *몇 계층* 인가?" 를 바로 답할 수 있게 한다. 필기·실기 공통.

## OSI 7 계층과 TCP/IP 4 계층

| OSI | TCP/IP | 대표 프로토콜 | PDU |
|---|---|---|---|
| 7 응용 · 6 표현 · 5 세션 | 응용 | HTTP · DNS · SMTP · FTP · SSH · SNMP · TLS | 메시지/데이터 |
| 4 전송 | 전송 | **TCP · UDP** | 세그먼트 / 데이터그램 |
| 3 네트워크 | 인터넷 | **IP · ICMP · ARP · IGMP**, IPSec | 패킷 |
| 2 데이터링크 · 1 물리 | 네트워크 액세스 | Ethernet · PPP · MAC · 스위치/허브 | 프레임 / 비트 |

## 계층별 보안 프로토콜

| 계층 | 보안 프로토콜 | 보호 대상 |
|---|---|---|
| 응용 | **S/MIME · PGP**(메일) · **SSH**(원격) · **HTTPS** · **DNSSEC** · SET · S-HTTP · Kerberos | 특정 애플리케이션 |
| 전송 | **SSL/TLS** · DTLS(UDP) | TCP 세션 (소켓 위) |
| 네트워크 | **IPSec**(AH/ESP) · VPN | IP 패킷 전체 (앱 무관) |
| 데이터링크 | **PPTP · L2TP · L2F** · **802.1X** · **MACsec(802.1AE)** · WPA2/3 | 구간(링크) |

> [!팁] 낮을수록 투명, 높을수록 강력
> **낮은 계층 보호**는 상위에 투명하지만 종단 간 보장이 약하고, **높은 계층 보호**는 종단 간이 강력하지만 애플리케이션마다 구현이 필요하다.

## 계층별 대표 공격 → 대응

| 계층 | 공격 | 대응 |
|---|---|---|
| **물리** | 도청(탭) · 케이블 절단 · 재밍 | 물리 보안 · 광케이블 · TEMPEST |
| **데이터링크** | ARP 스푸핑 · MAC 플러딩 · VLAN 홉핑 · STP 조작 | DAI · 포트 보안 · DHCP 스누핑 · BPDU 가드 |
| **네트워크** | IP 스푸핑 · Smurf · 라우팅 변조 · 단편화 공격 | Ingress/Egress 필터링 · uRPF · IPSec · 라우팅 인증 |
| **전송** | SYN 플러딩 · 세션 하이재킹 · 포트 스캔 | SYN 쿠키 · 상태 추적 방화벽 · TLS |
| **세션/표현** | 세션 예측·고정 · SSL 다운그레이드(POODLE·FREAK) | 강한 세션 ID·재발급 · TLS 1.2+ · HSTS |
| **응용** | SQLi · XSS · DNS 스푸핑 · 스팸 · 웹셸 · GET 플러딩 | 입력 검증 · WAF · DNSSEC · SPF/DKIM/DMARC · L7 방어 |
