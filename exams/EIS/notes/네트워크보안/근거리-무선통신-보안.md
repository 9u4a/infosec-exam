## 한 줄 정의

Wi-Fi 가 아닌 **근거리·저전력 무선**(블루투스 · RFID/NFC · Zigbee)과 이동통신의 보안을 묶은 노트다. 필기 단골이고, 공통 약점은 **"짧은 거리·가벼운 기기라 인증과 암호가 약하다"** 는 점이다.

> [!팁] Wi-Fi 는 별도 노트
> 무선랜(WEP/WPA)은 `무선랜-보안` 노트를 본다.

## 1. 블루투스

- 2.4GHz ISM 대역, **주파수 호핑(FHSS)**, 클래스별 도달 거리 1m~100m
- 페어링: 레거시(PIN) → **SSP** — Numeric Comparison · Passkey · Just Works · OOB
- BLE(저전력)는 IoT·웨어러블에 널리 쓰인다

### 블루투스 공격

| 공격 | 설명 | 위험 |
|---|---|---|
| **블루재킹** (Bluejacking) | 비인가 기기에 **스팸 메시지·명함** 푸시 | 경미 |
| **블루스나핑** (Bluesnarfing) | 페어링 없이 연락처·문자·일정 **데이터 탈취** | 높음 |
| **블루버깅** (Bluebugging) | 기기를 **원격 제어** (통화·문자 발신, 도청) | 매우 높음 |
| 블루프린팅 | 제조사·모델 등 기기 정보 수집 (정찰) | |
| **BlueBorne** | 페어링 없이 취약점으로 RCE (2017) | |
| **KNOB** | 암호화 키 엔트로피를 1바이트로 강제 다운그레이드 | |

> [!함정] 재킹 · 스나핑 · 버깅 구분
> **재킹 = 보내기(스팸)**, **스나핑 = 빼가기(데이터)**, **버깅 = 조종하기(제어·도청)**

대응: 비사용 시 **비활성** · 검색 불가(non-discoverable) 모드 · "Just Works" 지양 · 최신 패치 · 모르는 페어링 거부

## 2. RFID

태그(안테나 + 칩) ↔ 리더가 무선으로 인식한다. 수동형(배터리 없음) / 능동형.

| 주파수 | 용도 |
|---|---|
| LF 125kHz | 출입증 |
| HF 13.56MHz | 교통카드 · NFC |
| UHF 900MHz | 물류 |

### 위협과 대응

| 위협 | 대응 |
|---|---|
| 스키밍(무단 판독) · 도청 | 암호화 · 접근제어 · 거리 제한 |
| 태그 복제·위조 | 상호 인증 · 챌린지-응답 · 디지털 서명 |
| 위치 추적 (프라이버시) | **Kill 명령**(폐기 시 비활성) · 블로커 태그 · 패러데이 케이지 |
| 스푸핑·재전송 | 논스 · 타임스탬프 |

저전력 태그 보호에는 경량 암호(**HIGHT**, PRESENT)를 쓴다.

## 3. NFC

RFID HF(13.56MHz) 기반이며 **약 4cm 초근거리**다. 결제·태그·P2P 에 쓴다.

- 모드: Reader/Writer · P2P · Card Emulation (모바일 결제 — Secure Element / HCE)
- 위협: 도청(근거리라 제한적) · 데이터 변조·삽입 · **릴레이 공격**(중계로 거리 위장) · 악성 태그(피싱 URL)
- 대응: 보안 채널(NFC-SEC) · 결제는 SE 에 격리 · 태그 서명 검증

## 4. Zigbee · 저전력 메시

IEEE 802.15.4 기반의 **저전력·저대역·메시 네트워크**(스마트홈·센서망)다.

- 보안: AES-128 CCM* · 네트워크 키 · 링크 키
- 약점: **초기 키 배포·조인 과정** (오픈 조인, 키 스니핑)
- 유사 기술: Z-Wave · Thread · LoRaWAN(광역 저전력)

## 5. 이동통신 (LTE/5G) 보안 개요

- 상호 인증 (USIM 기반 AKA) · 무선 구간 암호화 · 무결성 보호
- **5G**: 가입자 영구 식별자 **SUPI 를 암호화(SUCI)** 해 IMSI 캐처(스팅레이)를 방어, 네트워크 슬라이싱 격리
