## 한 줄 정의

**IDS** 는 침입을 *탐지·경보*하고, **IPS** 는 *실시간 차단*한다. 시험은 "어디에 설치하나(HIDS/NIDS) → 어떻게 탐지하나(오용/이상) → 틀리면 어떻게 되나(오탐/미탐) → 어디에 배치하나" 순서로 묻는다. {{1-7}} {{4-7}} {{13-3}} {{25-16}} {{26-5}}

## 1. 설치 위치별 — HIDS vs NIDS

| | HIDS (호스트) | NIDS (네트워크) |
|---|---|---|
| 설치 | 서버 각각 | 세그먼트당 1대 (미러/TAP 포트) |
| 분석 대상 | 시스템 콜 · 파일 무결성 · 로그 · 레지스트리 · 권한 탈취 | 패킷 페이로드 |
| 암호화 트래픽 | 내부에서 복호화 후 확인 가능 | **불가** (스위칭 환경도 한계) |
| 예 | Tripwire · OSSEC | Snort · Suricata |

스위치 환경에서는 **포트 미러링(SPAN)** 또는 **네트워크 TAP** 으로 트래픽을 복제해 수집한다.

## 2. 탐지 방식 — 오용 vs 이상

| | **오용** (시그니처·지식기반) | **이상** (행위기반·통계) |
|---|---|---|
| 원리 | 알려진 공격 패턴과 비교 | 정상 프로파일 학습 → 벗어나면 탐지 |
| 장점 | 오탐 낮음, 명확 | **미지의 공격(제로데이)** 탐지 |
| 단점 | 미지·변형 공격 탐지 불가, 룰 갱신 필요 | **오탐 높음**, 정상 기준 설정이 어려움 |
| 기법 | 시그니처 매칭 · 전문가 시스템 · 상태 전이 분석 · 페트리넷 | 통계 분석 · 기계학습/신경망 · 데이터 마이닝 · 임계치 |

### 오탐 vs 미탐

| | 정의 | 영향 |
|---|---|---|
| **오탐** (False Positive) | 정상을 공격으로 판단 | 경보 피로, 운영 방해 |
| **미탐** (False Negative) | 공격을 정상으로 판단 | **침해 방치 — 더 위험** |

> [!암기] 시그니처 기반 → 미탐↑ · 이상탐지 기반 → 오탐↑ (룰 튜닝으로 균형)

정탐(TP)·정탐거부(TN)를 포함한 4분면에서 **정확도 = (TP + TN) / 전체** 다.

## 3. 배치 — IDS 와 IPS 는 자리가 다르다 {{13-3}}

| | **IPS** | **IDS** |
|---|---|---|
| 목적 | 실시간 **차단** | **탐지·경보** |
| 구성 | **인라인** (트래픽 경로 위) | 포트 미러링 (아웃오브밴드) |
| 위치 | 외부·내부 접점 | 내부망 모니터링에 적합 |
| 위험 | 내부망에 두면 오탐 시 정상 통신 장애, 장애 시 **SPOF** | 업무 흐름에 영향 없음 |

### NIDS 설치 위치

| 위치 | 목적 |
|---|---|
| 방화벽 **바깥** (인터넷 구간) | 시도되는 모든 공격 관측 (정찰·스캔 포함), 경보량 많음 |
| 방화벽 **안쪽** (내부망 진입점) | 방화벽을 **통과한** 실제 위협만 → 경보 신뢰도↑, 가장 일반적 |
| **DMZ** | 공개 서버(웹·메일·DNS) 대상 공격 탐지 |
| 내부 세그먼트 | 내부자 위협·**측면 이동** 탐지 |

### IDS 대응 행위 {{25-16}}

경보(메일·SMS·콘솔) · 로깅(포렌식 자료) · **세션 강제 종료(RST)** · 방화벽·라우터 연동 차단 · SIEM 상관분석

## 4. 허니팟

의도적으로 취약하게 꾸민 **미끼 시스템**이다. 공격자를 유인하고 수법·도구를 수집하며 실제 자산의 시간을 번다.

| | 저상호작용 | 고상호작용 |
|---|---|---|
| 방식 | 서비스 에뮬레이션 | 실제 OS |
| 특징 | 안전 | 정보 풍부하나 **장악 위험** |

허니넷 = 허니팟 여러 대로 만든 가짜 네트워크, 허니토큰 = 미끼 데이터·계정.

## 5. 관련 솔루션

| 솔루션 | 설명 |
|---|---|
| **NAC** | 접속 시 단말 인증 + 보안 상태 점검 |
| **UTM** | 방화벽 + IPS + 안티바이러스 + VPN + 웹필터 통합 (중소 규모, 성능 트레이드오프) |
| **NGFW** | 애플리케이션·사용자 인식 + IPS 내장 방화벽 |
| **SIEM** | 이기종 로그 수집·상관분석 |
| **SOAR** | 대응 자동화 |
| **EDR** | 엔드포인트 행위 탐지 |
