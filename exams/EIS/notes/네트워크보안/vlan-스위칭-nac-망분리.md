## VLAN (Virtual LAN) — 10-4, 27-12

하나의 물리 스위치를 **논리적으로 분할**해 별도 브로드캐스트 도메인으로.

| 목적 | 효과 |
|---|---|
| **보안** | VLAN 간 트래픽 격리 → 부서/구간 분리, 스니핑 범위 축소 |
| 브로드캐스트 도메인 **크기** 축소 | 불필요한 브로드캐스트·충돌 감소 |
| 네트워크 **성능** 향상 | 대역폭 효율, 장애 파급 범위 축소 |

- VLAN 간 통신은 **L3 장비(라우터/L3 스위치)** 경유 → 여기에 ACL 적용해 통제.
- 트렁크 포트는 **802.1Q** 태그로 여러 VLAN 전달. 공격: VLAN Hopping(스위치 스푸핑, 더블 태깅) → 미사용 포트 shutdown, DTP 비활성, 네이티브 VLAN 분리.

### VLAN 할당 방식 (24-5, 27-3, 28-3)

| 방식 | 기준 | 명령/특징 |
|---|---|---|
| **정적 VLAN** | 스위치 **포트** | 관리자가 포트마다 수동 지정. 가장 일반적, 안정적 |
| **동적 VLAN** | **MAC 주소**(또는 사용자·프로토콜) | VMPS/인증서버가 자동 할당. 이동성↑, 관리 서버 필요 |
| Cisco 확인 | — | `show vlan` |

## LAN 스위칭 방식 (24-3, 30-7)

| 방식 | 읽는 범위 | 지연 | 에러 검출 |
|---|---|---|---|
| **Cut-through** | 목적지 MAC(앞 6바이트)만 | 최소 | 없음 (에러 프레임도 전달) |
| **Fragment-Free** (Modified Cut-through) | 앞 **64바이트** | 중간 | 충돌(runt) 프레임 걸러냄 |
| **Store-and-Forward** | 프레임 **전체** 저장 후 FCS 검사 | 큼 | 완전 (CRC 오류 폐기) |

### 스위치 동작 원리 (20-12)

1. **Learning**: 수신 프레임의 출발지 MAC ↔ 포트를 MAC 테이블에 학습
2. **Flooding**: 목적지 MAC이 테이블에 없으면 수신 포트 제외 전 포트로 전송
3. **Forwarding**: 테이블에 있으면 해당 포트로만 전송
4. **Filtering**: 같은 포트로 나갈 프레임은 차단
5. **Aging**: 일정 시간 미갱신 항목 삭제

→ MAC 테이블이 가득 차면 Flooding으로 동작(= MAC Flooding/Switch Jamming 스니핑).

## NAC (Network Access Control) — 10-3, 19-2

네트워크 진입 시 **단말·사용자 인증 + 보안 상태 점검(무결성 점검)** → 비인가·취약 단말 격리/치료.
- 점검 항목: 백신 설치·패턴, OS 패치, 필수 SW, 비인가 SW, MAC 등록 여부.
- 구현: 802.1X(포트 인증), DHCP 방식, ARP 방식, 에이전트/에이전트리스.
- 오픈소스: **PacketFence**.

### NAC 물리적 구성 (17-12)

| 방식 | 배치 | 장단점 |
|---|---|---|
| **In-line** | 트래픽 경로에 직접 | 실시간 차단 강력, 그러나 장비 장애 시 **SPOF**·성능 병목 |
| **Out-of-band** | 스위치 미러링/일반 포트 | 구축 용이, 서비스 영향 적음, 차단은 스위치 연동(다소 지연) |

## 망분리 (12-11)

| 유형 | 방식 | 인터넷망 가상화 | 업무망 가상화 |
|---|---|---|---|
| 물리적 망분리 | PC 2대 또는 망전환 장치 | — | — |
| 논리적 망분리 | 가상화(SBC/CBC) | 인터넷 환경을 가상화 → 악성코드 감염돼도 **업무망 안전**, 자료 유출 통제 | 업무 데이터를 중앙 가상서버에 저장 → **단말에 데이터 미저장**(분실 대비), 중앙 관리·백업 용이 |

- 논리적 망분리는 구축비 저렴·사용자 편의↑ 이나, 가상화 취약점·자료전송 채널(망연계)이 새 위협.
