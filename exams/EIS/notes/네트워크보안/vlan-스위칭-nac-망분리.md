## 한 줄 정의

**망을 쪼개고(VLAN·망분리) → 접속자를 걸러내는(NAC)** 내부망 통제 기술이다. 스위치가 프레임을 어떻게 다루는지 알아야 VLAN 과 스니핑(MAC Flooding)이 이해된다. {{10-4}} {{27-12}} {{24-5}} {{12-11}} {{10-3}}

## 1. VLAN {{10-4}} {{27-12}}

물리 스위치 하나를 **논리적으로 나눠** 별도의 브로드캐스트 도메인으로 만든다.

| 목적 | 효과 |
|---|---|
| **보안** | VLAN 간 트래픽 격리 → 부서·구간 분리, 스니핑 범위 축소 |
| 브로드캐스트 도메인 **축소** | 불필요한 브로드캐스트·충돌 감소 |
| 성능 향상 | 대역폭 효율, 장애 파급 범위 축소 |

- VLAN 간 통신은 **L3 장비(라우터/L3 스위치)** 를 거치므로 여기에 **ACL** 을 걸어 통제한다
- 트렁크 포트는 **802.1Q** 태그로 여러 VLAN 을 전달한다

> [!함정] VLAN Hopping 공격과 대응
> 스위치 스푸핑 · **더블 태깅**으로 다른 VLAN 에 침투한다. → 미사용 포트 shutdown · **DTP 비활성** · 네이티브 VLAN 분리

### 할당 방식 {{24-5}} {{27-3}} {{28-3}}

| 방식 | 기준 | 특징 |
|---|---|---|
| **정적** | 스위치 **포트** | 관리자가 수동 지정, 가장 일반적·안정적 |
| **동적** | **MAC 주소**(또는 사용자·프로토콜) | VMPS/인증서버가 자동 할당, 이동성↑, 서버 필요 |

Cisco 확인 명령: `show vlan`

## 2. LAN 스위칭 방식 {{24-3}} {{30-7}}

| 방식 | 읽는 범위 | 지연 | 에러 검출 |
|---|---|---|---|
| **Cut-through** | 목적지 MAC(앞 6바이트)만 | 최소 | 없음 (에러 프레임도 전달) |
| **Fragment-Free** | 앞 **64바이트** | 중간 | 충돌(runt) 프레임 걸러냄 |
| **Store-and-Forward** | 프레임 **전체** 저장 후 FCS 검사 | 큼 | 완전 (CRC 오류 폐기) |

### 스위치 동작 원리 {{20-12}}

1. **Learning** — 수신 프레임의 출발지 MAC ↔ 포트를 MAC 테이블에 학습
2. **Flooding** — 목적지 MAC 이 테이블에 없으면 수신 포트 제외 **전 포트**로 전송
3. **Forwarding** — 있으면 해당 포트로만 전송
4. **Filtering** — 같은 포트로 나갈 프레임은 차단
5. **Aging** — 일정 시간 갱신 없는 항목 삭제

> [!시험] MAC 테이블이 가득 차면
> 스위치가 허브처럼 **Flooding** 으로 동작한다. 이를 노린 스니핑이 **MAC Flooding (Switch Jamming)** 이다.

## 3. NAC (Network Access Control) {{10-3}} {{19-2}}

네트워크 진입 시 **단말·사용자 인증 + 보안 상태 점검(무결성 점검)** 을 하고, 비인가·취약 단말을 **격리·치료**한다.

- 점검 항목: 백신 설치·패턴 · OS 패치 · 필수 SW · 비인가 SW · MAC 등록 여부
- 구현: 802.1X(포트 인증) · DHCP 방식 · ARP 방식 · 에이전트 / 에이전트리스
- 오픈소스: **PacketFence**

### 물리적 구성 {{17-12}}

| 방식 | 배치 | 장단점 |
|---|---|---|
| **In-line** | 트래픽 경로 위 | 실시간 차단이 강력하나 장애 시 **SPOF**·성능 병목 |
| **Out-of-band** | 스위치 미러링·일반 포트 | 구축 쉽고 서비스 영향 적음, 차단은 스위치 연동 (다소 지연) |

## 4. 망분리 {{12-11}}

| 유형 | 방식 |
|---|---|
| **물리적** | PC 2대 또는 망전환 장치 |
| **논리적** | 가상화 (SBC / CBC) |

논리적 망분리의 두 가지 가상화:

| | 효과 |
|---|---|
| **인터넷망 가상화** | 인터넷 환경을 가상화 → 악성코드에 감염돼도 **업무망은 안전**, 자료 유출 통제 |
| **업무망 가상화** | 업무 데이터를 중앙 가상서버에 저장 → **단말에 데이터 미저장**(분실 대비), 중앙 관리·백업 용이 |

논리적 망분리는 구축비가 저렴하고 편의성이 높지만, **가상화 취약점**과 **자료 전송 채널(망연계)** 이 새 위협이다.
