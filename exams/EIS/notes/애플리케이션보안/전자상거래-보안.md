## 한 줄 정의

전자상거래 보안은 **"돈이 오가는 구간의 신뢰"** 를 만드는 기술이다. 신용카드 결제의 **SET(이중서명) → SSL 기반 결제 → 3-D Secure**, 그리고 **OTP · 전자화폐 · 에스크로** 를 묻는다. 기출엔 거의 안 나오지만 필기 단골이다.

## 1. 전자지불 시스템 분류

| 유형 | 예 |
|---|---|
| 신용카드형 | SET · 3-D Secure · PG(전자결제대행) |
| 전자화폐형 | 선불 카드형(교통카드) · 네트워크형(전자지갑) |
| 전자수표형 | eCheck |
| 계좌이체형 | 실시간 계좌이체 · 펌뱅킹 |
| 소액결제 | 휴대폰 결제 · ARS |

## 2. SET (Secure Electronic Transaction)

Visa·MasterCard 가 만든 신용카드 전자결제 표준으로 **PKI + 이중서명** 기반이다.

참여자: 카드소지자 · 상점(Merchant) · **지불 게이트웨이(PG)** · 발급사(Issuer) · 매입사(Acquirer) · 인증기관(CA)

### 이중 서명 (Dual Signature)

> [!시험] 목적
> **상점은 지불정보(PI, 카드번호)를 못 보고, 은행은 주문정보(OI)를 못 보게** 하면서 **둘이 연결된 거래임은 증명**한다.

1. OI 해시 `H(OI)`, PI 해시 `H(PI)` 계산
2. 두 해시를 연결한 값의 해시(**POMD**) 계산
3. POMD 를 **카드소지자 개인키로 서명** = 이중서명
4. **상점**에 `OI + H(PI) + 이중서명` 전달 → OI 만 보고 검증
5. **PG(은행)**에 `PI + H(OI) + 이중서명` 전달 → PI 만 보고 검증

장점은 강력한 보안·부인방지, 단점은 **복잡·느림·인증서 배포 부담**이라 실패했고 SSL/3-D Secure 로 대체됐다.

## 3. SSL/TLS 결제와 3-D Secure

### SSL/TLS 기반 결제

- **구간 암호화만** 제공 → 상점 서버에 카드번호가 평문으로 보임 (SET 과의 차이)
- 실무: **PG 사가 카드정보를 대신 처리**(상점은 토큰만 보관) + **PCI-DSS** 준수

### 3-D Secure

결제 시 **발급사 인증 페이지**로 리디렉션해 추가 인증(비밀번호·OTP·앱 승인)을 한다.

- 3개 도메인: 발급사(Issuer) · 매입사(Acquirer) · 상호운용(카드사 네트워크)
- 2.0 은 리스크 기반 인증(디바이스·행동 분석)으로 마찰을 줄인다

## 4. OTP (일회용 비밀번호)

| 방식 | 설명 |
|---|---|
| **시간 동기 (TOTP)** | 시드 + 현재 시각 (30~60초), 시계 오차 허용창 |
| **이벤트 동기 (HOTP)** | 버튼 누른 횟수(카운터) 기반 |
| **질의응답** (Challenge-Response) | 서버 챌린지에 응답값 계산 — **동기화 불필요** |

OTP 는 토큰·카드·앱 형태이고, 금융권 이체는 공인인증서 + OTP 조합이다.

## 5. 전자화폐 요건

| 요건 | 의미 |
|---|---|
| **익명성** (불추적성) | 사용 내역으로 신원 추적 불가 (**은닉서명** 활용) |
| **오프라인성** | 결제 시 은행 온라인 연결 불필요 |
| **이중사용 방지** (Double Spending) | 같은 전자화폐의 재사용 탐지 |
| **양도성** | 제3자에게 이전 가능 |
| **분할성** | 액면을 나눠 사용 |

## 6. 에스크로와 관련 제도

**에스크로**: 구매자 대금을 **제3자(에스크로 사업자)가 보관**하다가, 구매자가 물품을 받아 확인한 뒤 판매자에게 지급한다. 비대면 거래 사기를 막으며, 전자상거래법상 일정 금액 이상 통신판매는 **에스크로 등 소비자보호 장치가 의무**다.

| 제도 | 내용 |
|---|---|
| **PCI-DSS** | 카드 데이터를 다루는 모든 주체의 보안 요구사항 (12개 항목) |
| **전자금융거래법** | 금융회사·전자금융업자 안전성 확보 · CISO · 사고 배상책임 |
| **전자서명법 / 본인확인기관** | 온라인 실명 확인 대체 수단 |
