## 한 줄 정의

실행 가능한 서버측 스크립트(`.php` `.jsp` `.asp`)를 올려 **웹셸**로 만드는 공격이다. 서버는 **확장자 · MIME · 매직바이트 · 크기 · 실행 권한**을 차례로 검사하는데, 공격자는 그 각각을 우회한다. 시험은 *"어떻게 우회하나"* 와 *"어떻게 막나"* 를 쌍으로 묻는다. {{5-6}} {{8-12}} {{13-11}} {{19-15}} {{23-13}} {{29-14}} {{32-13}}

> [!팁] 얻는 것
> 웹셸 → 원격 명령 실행 · 파일 조작 · DB 접근 · 권한 상승 · 추가 백도어

## 공격 성공 조건 — 3개 관문

1. 확장자 / MIME 검증 **통과**
2. 크기 제한(`LimitRequestBody`) **통과**
3. 업로드 경로에서 **스크립트가 실행**됨 (핸들러 매핑 · 웹루트 내)

## 검증 우회 기법

| 막는 검증 | 우회 |
|---|---|
| **확장자 블랙리스트** | 대소문자(`shell.pHp`) · 대체 확장자(`.php3` `.php5` `.pht` `.phtml` `.phar` / `.jspx` `.jspf` / `.asa` `.cer`) · 이중 확장자(`shell.php.jpg` — 서버가 앞을 읽으면 `shell.jpg.php`) |
| **끝문자 처리** | `shell.php.` (마지막 점) · `shell.php%20` (공백) · `shell.php::$DATA` (NTFS ADS) → OS 가 제거하고 저장 |
| **Content-Type (MIME)** | 프록시(Burp)로 `Content-Type: image/jpeg` 변조 |
| **매직바이트 / 시그니처** | 파일 앞에 `GIF89a;` · `\xFF\xD8\xFF` 를 붙이고 뒤에 `<?php ...?>` (**polyglot**) |
| **Null 바이트** | `shell.php%00.jpg` → 검증은 `.jpg`, 저장은 `.php` (PHP < 5.3.4 등 구형) |
| **경로 검증** | 파일명에 `../` → 웹루트 외·다른 경로에 저장 |
| **`.htaccess` 업로드** | 화이트리스트가 `.htaccess` 를 막지 않으면 → `AddType application/x-httpd-php .jpg` 업로드 후 `shell.jpg` 실행 |
| **이미지 리사이징** | GD 재저장으로 polyglot 이 깨지면 → EXIF `Comment` 에 페이로드를 넣고 LFI 와 결합 |
| **경쟁 조건** | 업로드 직후 검증·삭제 전 순간에 `shell.php` 를 반복 요청해 실행 |

### 실무형 지문 패턴 {{23-13}} {{29-14}}

프록시로 `test.php` → `test.php.jpeg` · `test.jpeg.php` · `test.php;.jpg` 등을 시도한다.

- 정규식이 `\.(jpg|jpeg|png|gif)$` 만 확인하고 `preg_match` 결과를 잘못 쓰면 우회된다
- 서버 설정(`AddHandler`, `<FilesMatch>`)이 `.php` 를 **부분 매칭**하면 `test.php.jpeg` 도 PHP 로 실행된다

## 대응

| 계층 | 조치 |
|---|---|
| **검증** | 확장자 **화이트리스트**(`.jpg` `.png` `.pdf` …) + MIME + 매직바이트 **다중 검증** |
| **저장** | **웹 루트 외부**에 저장, 다운로드는 별도 로직, 파일명 **난수화** |
| **실행 차단** | 업로드 디렉터리의 **스크립트 실행 권한·핸들러 제거** |
| **크기** | Apache `LimitRequestBody` · PHP `upload_max_filesize` · `post_max_size` |

> [!함정] 블랙리스트는 항상 뚫린다
> 우회 확장자가 끝없이 나오므로 **화이트리스트**가 원칙이다. 그래도 **실행 권한 제거**가 마지막 방어선이다.

### Apache — `.htaccess` 로 실행 차단

```apache
<FilesMatch "\.(ph|php[3457]?|phtml|sh|cgi|pl|jsp|asp)$">
    Require all denied            # 직접 URL 호출 차단
</FilesMatch>
AddType text/html .php .php3 .phtml    # 스크립트를 실행 불가한 MIME 으로 재지정
php_flag engine off                     # 해당 디렉터리 PHP 엔진 비활성
```

### IIS

- 업로드 폴더의 **'스크립트 및 실행 파일' 실행 권한 제거**
- 핸들러 매핑에서 해당 확장자 제거
