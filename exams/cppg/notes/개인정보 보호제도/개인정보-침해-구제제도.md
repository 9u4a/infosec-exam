> 2026-09-07 기준 · 개인정보보호법 제40조~제57조 (국가법령정보센터 원문 확인).

## 침해 신고

- 개인정보 침해를 당한 사람은 **개인정보침해 신고센터(한국인터넷진흥원, 국번없이 118)** 에 신고.
- 유출 신고 접수 전문기관도 **KISA**.

## 개인정보 분쟁조정위원회 (제40조)

- 개인정보에 관한 분쟁의 **조정**을 위해 설치. **위원장 1명 포함 30명 이내**(舊 20명). 위원 = **당연직위원 + 위촉위원**.
- **위원장**: 위원 중 **공무원이 아닌 사람**으로 보호위원회 위원장이 위촉.
- **임기**: 위원장·위촉위원 **2년**, **1차에 한하여 연임**.
- **조정부**: 분야별 **5명 이내** 위원(그중 1명은 변호사 자격). 조정부 의결 = 위원회 의결로 봄.
- **의결정족수**: 재적 과반수 출석 + 출석 과반수 찬성.
- 위원의 **제척·기피·회피** 규정, 신분보장.

## 분쟁조정 절차 (제43조~제47조)

| 단계 | 내용 |
|---|---|
| 신청 | 개인정보 관련 분쟁의 조정을 원하는 자 → 위원회. 상대방에게 신청 내용 통지. |
| **조정 참가 의무** | 개인정보처리자는 특별한 사유 없으면 응하여야 함. **불응 시 통지 받은 날부터 10일 이내** 사유 명시하여 불응 의사 통지. |
| 조정 전 합의 권고 | 위원회가 내용 제시하고 권고 가능. |
| **처리기간** | 신청 받은 날부터 **60일 이내** 심사·조정안 작성(부득이 시 의결로 연장·사유 통지). |
| **수락 간주** | 조정안 제시받은 당사자가 **제시받은 날부터 15일 이내** 수락 여부 미표시 → **수락한 것으로 본다**. |
| 조정서 | 위원장 + 각 당사자 기명날인·서명 → 정본 송달. |
| **효력** | 조정 성립 시 **재판상 화해와 동일한 효력**. |
| 조정 거부·중지 | 성질상 부적합·부정 목적 → 거부 / 한쪽 당사자가 소 제기 → 중지. |

## 집단분쟁조정 (제49조)

- **신청권자**: 국가·지자체, 개인정보 보호단체·기관, 정보주체, 개인정보처리자.
- **대상 요건** (시행령 제52조, 둘 다): ① 피해·권리침해 정보주체 수 **50명 이상** ② 중요 쟁점이 사실상·법률상 **공통**.
- 위원회 의결로 절차 개시 → **14일 이상** 개시 공고(홈페이지 또는 일반일간신문).
- 당사자 아닌 정보주체·처리자의 **추가 참가 신청** 가능.
- 처리자가 조정안 수락 시 조정에 참가하지 않은 피해자에 대한 **보상계획서** 작성 권고.

## 개인정보 단체소송 (제51조~제57조)

- 개인정보처리자가 **집단분쟁조정을 거부**하거나 **결과를 수락하지 않은 경우** → 법원에 **권리침해 행위의 금지·중지**를 구하는 소송(**손해배상 청구 불가**).
- **원고 자격**:
  - **소비자단체**(공정거래위원회 등록): 정관상 상시 정보주체 권익증진 목적 + **정회원 1천 명 이상** + 소비자기본법 등록 후 **3년 경과**
  - **비영리민간단체**: 동일 침해 입은 **100명 이상**의 정보주체로부터 소송 제기 요청 + 정관에 개인정보 보호 목적 명시 후 **최근 3년 이상 활동실적** + **상시 구성원 5천 명 이상** + **중앙행정기관 등록**
- **전속관할**: 피고 주된 사무소·영업소 소재지 지방법원 **본원 합의부**.
- **소송대리인 = 변호사 선임 의무**.
- 법원 결정으로 소송 허가(즉시항고 가능). 기각 확정 시 동일 사안 다른 단체 제소 불가(새 증거·원고 고의 예외).

## 함정 포인트

- 분쟁조정위원회 = **위원장 포함 30명 이내**(舊 20명), 임기 2년. 조정부 5명 이내.
- 처리기간 **60일**, 수락 간주 **15일**, 불응 통지 **10일**.
- 조정 성립 효력 = **재판상 화해**.
- 집단분쟁조정 대상 = **50명 이상 + 쟁점 공통**. 단체소송 비영리민간단체는 **100명 이상 요청**.
- **단체소송으로는 손해배상 청구 불가**. 손해배상은 개별 소송·법정 손해배상(300만원 이하).
- 공공기관도 분쟁조정에 **응하여야 한다**. 침해신고 대표번호 **118**.
