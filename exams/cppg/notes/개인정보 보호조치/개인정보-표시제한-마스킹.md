## 표시 제한(마스킹)이란

개인정보를 조회하는 **화면·출력물·인쇄물**에서 개인정보의 일부(또는 전부)를 
`홍**`, `010-****-1234`, `******-1******` 처럼 **가려서 표시**하는 것.
- 목적: 업무상 전체 값이 필요 없는 취급자·제3자에게 불필요하게 노출되는 것을 방지.

## 적용 대상·방법

- 조회 화면: 목록·상세에서 주민등록번호·연락처·계좌번호 등을 기본 마스킹, 
  전체 값이 필요한 업무만 **권한·사유 기록** 후 해제.
- 출력물·다운로드 파일: 용도에 필요한 항목만, 필요 시 마스킹된 형태로.
- 상담·콜센터: 상담원 화면에서 카드번호 전체 노출 금지(PCI-DSS와도 연결).

## 마스킹 vs 다른 기술

| 기술 | 특징 | 복원 |
|---|---|---|
| **마스킹(표시 제한)** | 화면·출력 시 일부를 가림. 원본 DB는 그대로 | 권한 있으면 원본 조회 |
| **암호화** | 저장·전송 시 알고리즘으로 변환 | 키로 복호화 |
| **가명처리** | 식별요소를 대체·삭제(추가정보 분리) | 추가정보로 재식별 |
| **익명처리** | 재식별 불가능하게 | 불가 |

## 출력·복사 시 보호조치

- 개인정보를 출력할 때 **용도를 특정**하고 **출력 항목을 최소화**.
- 개인정보가 포함된 출력물·복사물은 안전하게 관리, 불필요 시 **파기**.
- 출력·복사 **기록 관리**(누가, 언제, 무엇을).
- 복합기·팩스 수신함, 회수되지 않은 인쇄물 관리(Clean Desk).

## 함정 포인트

- 마스킹은 **표시(출력) 단계**의 보호. DB 저장값 자체를 바꾸지는 않는다(그건 암호화·가명처리).
- 전체 값 조회는 **권한 + 사유 기록** 후 예외적으로.
- 출력물도 개인정보 → 최소 항목·회수·파기 관리 대상.
