> 2026-09-07 기준 · EU GDPR (2018.5.25 시행) ↔ 한국 개인정보보호법.

## 한눈 대조

| 항목 | 한국 개인정보보호법 | EU GDPR |
|---|---|---|
| **적용 범위** | 국내에서 개인정보를 처리하는 모든 처리자 | EU 내 설립 처리자 + **역외적용**(EU 정보주체 대상 재화·서비스 제공 또는 행동 모니터링, 제3조) |
| **처리자 용어** | 개인정보처리자 / 개인정보취급자 / 수탁자 | Controller / Processor |
| **처리 근거** | 6가지 (동의·법령·공공기관 소관·계약·급박한 이익·정당한 이익) — 제15조① | 6가지 (동의·계약·법적 의무·중대한 이익·공익/공적 권한·정당한 이익) — 제6조 |
| **민감정보** | 사상·신념, 노조·정당, 정치견해, 건강, 성생활 + (시행령) 유전·범죄경력·생체·인종·민족 | 인종·민족, 정치견해, 종교·철학신념, 노조가입, 유전·생체, 건강, 성생활·성적지향 (제9조 특수범주) |
| **아동** | 만 14세 미만 — 법정대리인 동의 | 정보사회서비스 관련 만 16세 미만(회원국이 13세까지 하향 가능) |
| **정보주체 권리** | 열람·정정·삭제·처리정지·**전송요구(35의2)**·**자동화결정 거부·설명(37의2)** | 열람·정정·삭제(잊혀질 권리)·처리제한·**데이터 이동권(20조)**·반대권·**자동화 개별결정(22조)** |
| **침해 통지 (감독기구)** | 유출등 인지 후 **72시간 이내** (제34조) | **72시간 이내** (제33조) |
| **침해 통지 (정보주체)** | (요건 충족 시) 72시간 이내 | **높은 위험** 시 부당한 지체 없이 |
| **DPO / CPO** | CPO 지정 **의무**(모든 처리자), 강화 기준 시 독립성·자격 | DPO는 **일정 요건**(공공기관, 대규모 정기·체계적 모니터링, 대규모 특수범주)에서만 의무 |
| **영향평가** | **공공기관 의무**(5만/50만/100만), 민간 권장 (제33조) | **고위험 처리** 시 DPIA 의무 (제35조) |
| **처리활동 기록** | (안전조치·처리방침으로 갈음) | Records of Processing (원칙 250인 이상 등, 제30조) |
| **Privacy by Design** | 법 제3조(사생활 침해 최소화·익명/가명 우선) | 제25조 (Data Protection by Design and by Default) |
| **최고 과징금** | 전체 매출 **3%**(일반) / **10%**(반복·중대, 2026.9.11~) | 전 세계 매출 **4%** 또는 2천만 유로 (중대) / 2% 또는 1천만 유로 (일반) |
| **국외 이전** | 동의 / 조약 / 계약+공개 / 인증 / **적정성**(제28조의8) | 적정성 결정 / SCC(표준계약조항) / BCR / 인증 (제44~49조) |
| **적정성** | 보호위가 상대국 동등 수준 인정·고시 | EU 집행위 adequacy decision. **한국은 2021.12 취득** |
| **감독기구** | 개인정보 보호위원회 (국무총리 소속 중앙행정기관) | 회원국별 DPA + **EDPB**(유럽데이터보호이사회) |

## 공통점

- 처리 근거 6가지 구조, 정보주체 권리(열람·정정·삭제 등), 침해 통지 **72시간**, PbD, 정당한 이익 근거(공공기관 직무 수행에는 원용 불가).
- 국외 이전에 적정성·계약(SCC)·인증 등 다층 안전장치.

## 차이점 (자주 출제)

- **DPO**: GDPR은 조건부 의무, 한국 CPO는 전면 의무.
- **아동 기준**: 한국 14세, GDPR 16세(회원국 13세까지 조정 가능).
- **데이터 이동권 대상**: 한국·GDPR 모두 정보주체가 '제공한' 정보 위주, 처리자가 생성한 파생 정보(신용평가 결과 등)는 원칙 제외.
- **과징금 산정**: 한국 = 국내 전체 매출 기준, GDPR = 전 세계 매출 기준.
- 한국은 **EU 적정성 결정 보유국**(EU→한국 이전 자유화).

## 함정 포인트

- 침해 통지 **72시간**은 한국·GDPR **동일**.
- GDPR 최고 과징금 = 전 세계 매출 **4%**. 한국 = 전체 매출 **3%**(반복·중대 10%).
- 한국 아동 = **14세**, GDPR = **16세**.
- 정당한 이익은 **공공기관 직무 수행에 사용 불가** (양쪽 공통).
