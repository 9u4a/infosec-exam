## 기간·기한 (안전성 확보조치 기준·국가법령정보센터 확인)

| 값 | 무엇 |
|---|---|
| **72시간 이내** | 개인정보 유출등(분실·도난·유출) → 정보주체 통지 + (1천명 등) 보호위/KISA 신고 |
| **3일 이내** | 정보주체 이외로부터 수집한 개인정보 **수집 출처 등 통지**(요구 후 "즉시" = 정당한 사유 없으면 3일) |
| **5일 이내** | 개인정보가 불필요하게 된 날부터 파기("지체 없이" = 정당한 사유 없으면 5일) |
| **7일 이내** | 국외 이전 **중지 명령**에 대한 이의 제기 |
| **10일 이내** | 열람·정정·삭제·처리정지 요구 → 조치 또는 (미이행 시) 사유·이의제기방법 통지 / 분쟁조정 **불응 의사 통지** |
| **15일 이내** | 분쟁조정안 제시 후 수락 여부 미표시 → **수락 간주** |
| **30일 이내** | 자동화된 결정 **거부·설명 요구** 처리 / 영상정보 보관(산정 곤란 시) / 국외이전 중지명령 이의 결과 통보 |
| **60일 이내** | 분쟁조정·집단분쟁조정 처리(조정안 작성) / 공공기관 개인정보파일 **등록**(운용 시작 후) |
| **3개월 이내** | (5만명·100만명) 수집 출처 등 **최초 통지**(제공받은 날부터) |
| **6개월 이내 + 동종 재화** | 사전 동의 없이 광고성 정보 전송 가능(거래관계 예외) |
| **1년 이상 / 2년 이상** | 접속기록 보관 (일반 / 5만명 이상·민감·고유식별정보 처리 시스템·기간통신사업자) |
| **3년** | 접근권한 부여·변경·말소 기록 보관 |
| **반기 1회 이상** | 공공시스템 접근권한 부여·변경·말소 내역 점검 |
| **2년마다** | 광고성 정보 수신동의 여부 재확인(정보통신망법) |
| **3년마다 1회 이상** | 고유식별정보 안전조치 정기조사(보호위) |
| **3년마다 / 매년** | 개인정보 보호 기본계획 / 시행계획 |
| **1일 1회 이상 (또는 자동)** | 백신(보안 프로그램) 업데이트 |
| **월 1회 이상** | 접속기록 점검(고시 제2026-9호: 내부관리계획으로 자율 설정 — 통상 월 1회) |
| **연 1회 이상** | 내부관리계획 이행 점검(CPO), 이용·제공 내역 통지, 위험평가, 법규준수 검토, 취급자 교육 |
| **5년** | 국외 이전 인증 유효기간(범위) |
| 진료기록부 10년 / 처방전 2년 | 의료법 보존 |
| 전자상거래 계약·결제 5년 / 불만 3년 / 광고 6개월 | 전자상거래법 보존 |

## 인원·규모

| 값 | 무엇 |
|---|---|
| **만 14세 미만** | 아동 — 법정대리인 동의 (온·오프라인 동일) |
| **8세 이하** 아동 등 | 위치정보 — 보호의무자 동의로 갈음 (생명·신체 보호) |
| **50명 이상** | 집단분쟁조정 신청 대상(피해 정보주체 수) + 쟁점 공통 |
| **100명 이상** | 단체소송 — 비영리민간단체가 정보주체로부터 소송 제기 요청받아야 하는 수 |
| **5만 명 이상** | 접속기록 2년 / (민감·고유식별정보 수반) 영향평가 / 수집출처·이용내역 통지(민감·고유식별) |
| **50만 명 이상** | 영향평가 (다른 파일과 연계 결과) |
| **100만 명 이상** | 영향평가(단일 파일) / 인터넷망 차단조치 대상(전년도말 직전 3개월 일일평균 이용자) / 수집출처·이용내역 통지(개인정보) / 국내대리인 |
| **10만 명 이상** (대기업·중견·공공) 또는 **100만 명 이상** (중소·단체) | 재해·재난 대비(위기대응 매뉴얼·백업·복구) + 암호키 관리 절차 |
| **1천 명 이상** | 유출 신고 의무 (미만도 민감·고유식별·외부침입은 신고) / 단체소송 소비자단체 정회원 수 |
| **1천만 명 이상** | 징벌적 과징금(10%) 적용 요건 중 하나 (2026.9.11~) |
| 전체 매출 **1조원** 이상 또는 국내 정보주체 **일일평균 100만명** 이상 | 국내대리인 지정 대상 |
| 매출 100억 / 이용자 100만 | ISMS 인증 의무대상 (정보통신망법 제47조) |

## 함정 포인트

- 헷갈림: 접속기록 보관 **1·2년** vs 접근권한 기록 **3년** vs 광고 재확인 **2년마다** vs 고유식별정보 정기조사 **3년마다**.
- 열람·정정·삭제·처리정지 = **10일**, 수집출처 통지 = **3일**, 파기 = **5일**, 자동화결정 설명 = **30일**, 유출 통지·신고 = **72시간**, 분쟁조정 = **60일**, 조정안 수락간주 = **15일**, 국외이전 중지 이의 = **7일**, 파일 등록 = **60일**.
- 보호위 **9명·3년** vs 분쟁조정위 **30명·2년**.
- 과징금 **3%**(현행) / **10%**(2026.9.11~ 반복·중대).
- 수집 근거 = **7가지**(제15조①, 공중위생 7호 추가). 각각 구분 동의 = **7가지**.
