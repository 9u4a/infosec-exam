## 법 제2조 정의 용어

| 용어 | 정의 |
|---|---|
| **개인정보** | 살아 있는 개인에 관한 정보 — 가.직접 식별 / 나.결합 식별 / 다.가명정보 |
| **가명처리** | 추가정보 없이는 특정 개인을 알아볼 수 없도록 하는 처리 |
| **처리** | 수집·생성·연계·기록·저장·보유·가공·편집·검색·출력·정정·복구·이용·제공·공개·파기 등 |
| **정보주체** | 처리되는 정보로 알아볼 수 있는 사람으로서 그 정보의 주체가 되는 사람 |
| **개인정보파일** | 쉽게 검색할 수 있도록 일정한 규칙에 따라 체계적으로 배열·구성한 집합물 (수기 포함) |
| **개인정보처리자** | 업무 목적으로 개인정보파일을 운용하는 공공기관·법인·단체·개인 |
| **공공기관** | 국회·법원·헌재·중앙선관위, 중앙행정기관·소속기관, 지자체, 대통령령 지정 기관(학교·공사 등) |
| **고정형 영상정보처리기기** | 일정 공간에 설치되어 지속·주기적으로 촬영 (CCTV) |
| **이동형 영상정보처리기기** | 착용·휴대·이동 물체 부착·거치하여 촬영 (드론·바디캠) |
| **과학적 연구** | 기술개발·실증, 기초·응용 연구, 민간투자 연구 등 — **산업적 연구 포함** |

## 개인정보의 상태

| 용어 | 뜻 | 이 법 적용 |
|---|---|---|
| 개인정보 | 식별 가능 | 적용 |
| **가명정보** | 추가정보 있으면 재식별 | 적용 (특례 제28조의2~7) |
| **익명정보** | 시간·비용·기술상 재식별 불가 | **미적용** (제58조의2) |
| **개인영상정보** | 영상기기로 촬영된, 개인 식별 가능한 영상 | 적용 |
| **바이오정보(생체인식정보)** | 지문·홍채·얼굴·정맥·음성 등 — 식별 목적 처리 시 **민감정보** | 적용 |

## 동의

| 용어 | 뜻 |
|---|---|
| **필수 동의** | 재화·서비스 제공에 필수적인 항목 — 미동의 시 서비스 거부 가능 |
| **선택 동의** | 필수적이지 않은 항목(마케팅 등) — 미동의를 이유로 서비스 거부 **금지** |
| **별도 동의** | 민감정보·고유식별정보·제3자 제공·목적 외·국외 이전·마케팅 — 다른 동의와 구분 |
| **포괄 동의** | 목적을 특정하지 않은 일괄 동의 — **무효** |
| **동의 철회** | 언제든지 가능, 수집보다 쉽게 |

## 수집·이전

| 용어 | 뜻 |
|---|---|
| **직접수집 / 간접수집** | 정보주체에게서 직접 / 제3자·공개출처에서 (제20조 출처 고지) |
| **공개된 개인정보** | 정보주체가 공개한 정보 — 공개 목적·사회통념 범위 내 처리 가능 |
| **제3자 제공** | 제공받는 자의 목적을 위한 이전 — 원칙 별도 동의 |
| **처리 위탁** | 위탁자의 목적을 위해 대신 처리 — 동의 불요, 공개 |
| **영업양도** | 영업 이전에 수반된 이전 — 통지 |
| **국외 이전 / 재이전** | 국외로 / 이전받은 자가 제3국으로 |

## 데이터 활용·기술

| 용어 | 뜻 |
|---|---|
| **재식별** | 가명·익명정보에서 특정 개인을 다시 알아봄 — 가명정보 처리 시 금지 |
| **결합** | 서로 다른 처리자의 가명정보를 합침 — 결합전문기관 |
| **프로파일링** | 자동화된 처리로 개인의 특성·행동·선호를 평가·예측 |
| **행태정보** | 웹·앱 방문·검색·구매 이력 등 온라인 활동 정보 |
| **CI / DI** | 연계정보 / 중복가입확인정보 — 주민번호 대체 식별값 |
| **마스킹(표시 제한)** | 화면·출력물에서 개인정보 일부를 가림 (DB 원본은 유지) |

## 관리체계·위험

| 용어 | 뜻 |
|---|---|
| **DoA** (Degree of Assurance) | 조직이 수용하기로 한 목표 위험수준 |
| **SLE / ARO / ALE** | 1회 예상손실 / 연간 발생률 / 연간 예상손실(= SLE×ARO) |
| **잔여위험** | 통제 적용 후에도 남는 위험 (경영진 승인) |
| **3선 방어** | 1선 현업 / 2선 CPO·정보보호 / 3선 내부감사 |
