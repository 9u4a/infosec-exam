## 정책·감독

| 기관 | 역할 | 비고 |
|---|---|---|
| **개인정보 보호위원회** (PIPC) | 정책·기본계획, 법령·기준 제정, 시정조치·**과징금·과태료** 부과, 침해요인 평가, 국제협력, 의결례 공개 | 국무총리 소속 **중앙행정기관**, 위원 9명, 임기 3년 |
| **과학기술정보통신부** | ISMS-P 공동 정책기관, 정보보호 산업 | |
| **금융위원회** | 신용정보(개인신용정보) 감독, 마이데이터 | 신용정보법 |
| **방송통신위원회** | 위치정보, 광고성 정보 전송, 본인확인기관 지정 | 위치정보법·정보통신망법 |

## 지원·전문기관

| 기관 | 역할 |
|---|---|
| **한국인터넷진흥원 (KISA)** | **개인정보침해 신고센터 (국번없이 118)**, 침해 원인 분석·기술 지원, **유출 신고 접수(전문기관)**, ISMS-P 인증기관, 개인정보 포털(privacy.go.kr) 운영 |
| **개인정보 분쟁조정위원회** (KOPICO) | 분쟁의 조정 (신청 후 60일, 재판상 화해 효력), 집단분쟁조정. 위원장 포함 30명 이내, 임기 2년 |
| **금융보안원** | 금융 분야 ISMS-P 인증기관, 금융 마이데이터 지원 |
| **결합전문기관** | 서로 다른 개인정보처리자 간 **가명정보 결합** 수행 (개인정보보호법 제28조의3) — 보호위/관계 중앙행정기관장이 지정 |
| **데이터전문기관** | **신용정보** 가명·익명처리 적정성 평가, 결합 (신용정보법) — 결합전문기관과 근거 법이 다름 |
| **본인확인기관** | 주민번호 대체수단(**CI·DI**) 발급·검증 — 방통위 지정 (정보통신망법 제23조의3) |
| **개인정보 영향평가 기관** | 영향평가 수행 (보호위 지정) |

## 신고·상담 창구

| 창구 | 번호/경로 |
|---|---|
| 개인정보침해 신고·상담 | **118** (KISA, 국번 없음) |
| 개인정보 유출 신고 (사업자) | 개인정보 보호위원회 또는 KISA (privacy.go.kr) |
| 분쟁조정 신청 | 개인정보 분쟁조정위원회 (kopico.go.kr) |
| 개인정보 자가진단·처리방침 확인 | 개인정보 포털 (privacy.go.kr) |

## 함정 포인트

- 침해신고 대표번호 = **118**.
- 과징금·시정조치·과태료 부과 주체 = **개인정보 보호위원회**(형벌은 법원).
- 유출 신고 전문기관 = **KISA**.
- **결합전문기관**(개인정보보호법, 가명정보 결합) ≠ **데이터전문기관**(신용정보법).
- 위치정보 감독 = 방통위, 신용정보 감독 = 금융위.
