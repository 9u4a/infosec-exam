> ⚠ 의무대상 매출·이용자 수 기준은 개정으로 변동 — 최신 고시 확인.

## ISMS vs ISMS-P

| | ISMS (정보보호 관리체계) | ISMS-P (정보보호 및 개인정보보호 관리체계) |
|---|---|---|
| 범위 | 정보보호 중심 | 정보보호 + **개인정보 처리 단계별** 보호 |
| 마크 | ISMS | ISMS-P |
| 의무 여부 | 정보통신망법 제47조 요건이면 **ISMS 의무** | 의무는 ISMS. 개인정보까지 포함 인증을 원하면 ISMS-P 선택 |

## ISMS 인증 의무대상 (정보통신망법 제47조 제2항, 예시)

- **ISP**(정보통신망서비스 제공자)로 서울 및 모든 광역시에서 정보통신망 서비스 제공
- **IDC**(집적정보통신시설 사업자)
- 다음 중 하나에 해당하는 자:
  - 정보통신서비스 부문 **전년도 매출액 100억 원 이상**
  - 전년도 말 기준 직전 3개월간 **일일 평균 이용자 수 100만 명 이상**
  - **상급종합병원**, 재학생 **1만 명 이상 대학** 등(개정 반영)

## 인증 기관·심사 기관

| 역할 | 기관 |
|---|---|
| **정책기관** | 개인정보 보호위원회, 과학기술정보통신부 |
| **인증기관** | **한국인터넷진흥원(KISA)**, 금융보안원(금융분야) |
| **심사기관** | KISA가 지정한 기관들 |
| **인증위원회** | 심사 결과 심의·의결(35명 이내 위원 풀에서 구성) |

## 인증 절차

```
신청 → 계약 → 심사팀 구성 → 심사(문서·현장) → 결함 조치(보완조치)
→ 심사기관 심사보고서 → 인증위원회 심의·의결 → 인증서 발급
```

- 심사 종류: **최초심사 → 사후심사(매년 1회 이상) → 갱신심사(유효기간 만료 전)**
- **유효기간 3년**. 갱신하지 않으면 인증 효력 상실.
- 결함 발견 시 **보완조치 기간**(최대 100일 등, 고시) 내 조치.

## 함정 포인트

- ISMS-P 유효기간 **3년**, 사후심사 **매년**.
- ISMS 의무대상 판단 근거 = **정보통신망법 제47조**(매출 100억·이용자 100만 등).
- 인증기관 = **KISA**(금융은 금융보안원). 심사기관은 별도 지정.
- ISMS-P는 ISMS + **개인정보 요구사항**을 포함.
