> 2026-09 기준 · ISMS-P 인증기준(고시 별표). 항목 수는 개정으로 소폭 바뀔 수 있음.

## 3개 영역

| 영역 | 항목 수(대략) | 내용 |
|---|---|---|
| **1. 관리체계 수립 및 운영** | 16 | 기반 마련 · 위험 관리 · 운영 · 점검 및 개선 (PDCA) |
| **2. 보호대책 요구사항** | 64 | 정책·조직·자산, 인적보안, 외부자, 물리, 인증·권한, 접근통제, 암호화, 도입·개발, 시스템·서비스 운영, 사고 대응, 재해복구 |
| **3. 개인정보 처리단계별 요구사항** | 21 | 수집 · 보유·이용·제공 · 파기 · 정보주체 권리 보호 |

- **ISMS 인증**: 1영역(16) + 2영역(64) = **80개**
- **ISMS-P 인증**: 1 + 2 + 3영역 = **101개**(대략)

## 1영역 세부 (관리체계) — PDCA

| 분류 | 항목 예 |
|---|---|
| 1.1 관리체계 기반 마련 | 경영진 참여, CISO/CPO 지정, 조직 구성, 범위 설정, 자원 할당 |
| 1.2 위험 관리 | 정보자산 식별, 현황·흐름 분석, **위험 평가**, 보호대책 선정 |
| 1.3 관리체계 운영 | 보호대책 구현, 공유·교육, 운영현황 관리 |
| 1.4 관리체계 점검 및 개선 | 법적 요구사항 준수 검토, **관리체계 점검(내부감사)**, 개선 |

## 2영역 주요 분류 (일부)

2.1 정책·조직·자산 관리 / 2.2 인적 보안 / 2.3 외부자 보안 / 2.4 물리 보안 / 
2.5 인증 및 권한 관리 / 2.6 접근통제 / 2.7 암호화 적용 / 2.8 정보시스템 도입·개발 보안 / 
2.9 시스템·서비스 운영 관리 / 2.10 시스템·서비스 보안 관리 / 2.11 사고 예방 및 대응 / 2.12 재해복구

## 3영역 (개인정보 처리단계별)

| 단계 | 항목 예 |
|---|---|
| 3.1 수집 시 보호조치 | 수집·이용 동의, 최소수집, 민감·고유식별정보, 간접수집, 영상정보처리기기 |
| 3.2 보유·이용·제공 시 | 목적 내 이용, 제공 시 보호, 위탁, 영업양도, 국외이전 |
| 3.3 파기 시 | 보유기간·파기, 처리방침 공개 |
| 3.4 정보주체 권리 보호 | 권리 보장 절차, 개인정보 열람·정정·삭제 등 |

## 함정 포인트

- **ISMS = 80개(1+2영역), ISMS-P = 101개(1+2+3영역)** — 대표 숫자.
- 1영역은 **PDCA**(기반 마련 → 위험 관리 → 운영 → 점검·개선) 구조.
- 3영역은 개인정보 **생명주기**(수집→보유·이용·제공→파기→권리보호) 순서.
- 위험 평가·정보자산 식별은 **1.2(위험 관리)** 소속.
