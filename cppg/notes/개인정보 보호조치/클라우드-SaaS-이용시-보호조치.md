> 2026-09 기준 ·「개인정보의 안전성 확보조치 기준」 + 클라우드컴퓨팅법 + 보호위 클라우드 관련 안내.

## 클라우드 이용의 법적 성격

- 개인정보를 클라우드(IaaS/PaaS/SaaS)에 저장·처리하도록 맡기는 것 = **처리 위탁**(제26조).
  - 위탁계약서에 목적·범위, 재위탁 제한, 안전조치, 관리·감독, 손해배상 등 명시.
  - 위탁 내용·수탁자(클라우드 사업자)를 **홈페이지 공개**.
- 데이터가 **국외 리전**에 저장·처리되면 **국외 이전**(제28조의8)도 함께 검토 → 별도 동의/공개·계약/인증/적정성.

## 책임 공유 모델 (Shared Responsibility)

| 계층 | 클라우드 사업자(CSP) 책임 | 이용 기업(개인정보처리자) 책임 |
|---|---|---|
| 물리 시설·하드웨어·하이퍼바이저 | ○ | |
| 네트워크 인프라 | ○ | (보안그룹·방화벽 룰 설정) |
| 게스트 OS·미들웨어 패치 | (관리형 서비스는 CSP) | (IaaS는 이용 기업) |
| **애플리케이션·데이터·접근권한·암호화 키** | | **○ (개인정보처리자)** |
| 개인정보 처리의 적법성·동의·정보주체 권리 | | **○ (개인정보처리자)** |

- **"클라우드에 올렸으니 CSP가 책임진다"는 오해.** 데이터·접근통제·암호화·적법성은 이용 기업 책임.

## 실무 체크

- CSP의 **인증**(CSAP — 클라우드 보안인증, ISO 27017/27018, ISMS-P 등) 확인.
- **암호화**: 저장·전송 암호화, 키 관리(고객관리키 KMS, CSP와 키 분리).
- **접근통제**: IAM 최소권한, MFA, 관리 콘솔 접근 제한, 로그(CloudTrail 등) 보관.
- **설정 오류 방지**: 스토리지 버킷 공개 설정, 보안그룹 0.0.0.0/0 개방 점검.
- **위탁·국외이전 고지**를 처리방침에 반영.
- 계약 종료 시 데이터 **반환·파기 확인**(파기 증적).

## 함정 포인트

- 클라우드 이용 = **위탁**. 국외 리전이면 **국외이전**도 검토.
- 책임 공유 모델에서 **데이터·접근권한·암호화 키·적법성은 이용 기업 책임**.
- CSP 인증(CSAP 등)이 있어도 이용 기업의 안전조치 의무가 면제되지 않는다.
