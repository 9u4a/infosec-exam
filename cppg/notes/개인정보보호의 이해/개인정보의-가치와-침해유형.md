> 2026-09 기준. 개념 위주 — 침해가 "어느 단계"에서 일어나는지로 정리.

## 개인정보의 가치

- **경제적 가치**: 맞춤형 광고, 추천, 신용평가, 데이터 거래(가명정보 결합).
- **위험**: 한 번 유출되면 **회수 불가능**, 2차 피해(스팸·피싱·명의도용·보이스피싱) 지속.
- 개인정보 = **인격권**(자기정보결정권)이자 재산적 이익. 침해 시 정신적 손해 + 재산적 손해.

## 생명주기 단계별 침해 유형

| 단계 | 침해 유형 |
|---|---|
| **수집** | 과다수집, 동의 없는 수집, 기망에 의한 수집, 아동 정보 무단 수집 |
| **저장·관리** | 안전조치 미흡으로 인한 **유출·해킹**, 내부자 무단 조회·반출, 접근권한 남용 |
| **이용·제공** | 목적 외 이용, 동의 없는 제3자 제공, 위탁 시 재위탁·유출, 결합을 통한 재식별 |
| **파기** | 미파기·방치, 파기했다 주장하나 복구 가능, 분리보관 미흡 |

## 대표 침해 사례 유형 (시험 지문)

- **해킹·악성코드**로 대량 DB 유출 → 통지·신고 의무, 과징금.
- **내부 직원**이 고객 정보를 조회·유출·판매 → 접근통제·로그·최소권한 실패.
- **협력업체(수탁자)** 를 통한 유출 → 위탁자의 관리·감독 책임.
- **개발/테스트 서버**에 운영 데이터를 그대로 복제 → 가명·익명처리 없이 노출.
- **API·URL 파라미터**로 다른 사람 정보 조회 가능(취약한 접근제어).

## 신기술과 프라이버시 이슈

- **빅데이터·AI**: 프로파일링(자동화된 결정), 재식별 위험, 편향.
- **IoT·CCTV·드론**: 상시 수집, 정보주체가 인지하기 어려움 → 이동형 영상기기 규정.
- **위치정보·행태정보**: 온라인 맞춤형 광고 → 사전 고지·거부권.
- **다크패턴**: 동의를 유도하는 UI → 동의의 자유로운 의사 훼손.

## 함정 포인트

- 개인정보 유출의 "가장 많은 원인"을 묻는 문제 → 외부 해킹뿐 아니라 **내부자·수탁자·관리 소홀**이 큰 비중.
- 위탁 관계에서 수탁자가 유출해도 **1차 책임은 위탁자**(관리·감독 의무).
- 익명·가명처리를 했다고 해서 침해 위험이 0이 되는 것은 아니다(**재식별** 가능성 관리 필요).
