## 유효한 동의의 4조건 (시행령 제17조①)

1. 정보주체가 **자유로운 의사**에 따라 동의 여부를 결정할 수 있을 것
2. 동의를 받으려는 내용이 **구체적이고 명확**할 것
3. 그 내용을 **쉽게 읽고 이해**할 수 있는 문구를 사용할 것
4. 동의 여부를 **명확하게 표시**할 수 있는 방법을 정보주체에게 제공할 것

## 각각 구분하여 받아야 하는 동의 (제22조① — 7가지)

1. **수집·이용** (제15조①1호)
2. **제3자 제공** (제17조①1호)
3. **목적 외 이용·제공** (제18조②1호)
4. **제공받은 자의 목적 외 이용·제공** (제19조1호)
5. **민감정보** 처리 (제23조①1호)
6. **고유식별정보** 처리 (제24조①1호)
7. **재화·서비스 홍보·판매 권유** 목적 처리

## 서면 동의 시 명확히 표시할 "중요한 내용" (시행령 제17조③)

색깔·굵기·밑줄·따로 구분하기 등으로 표시:
1. 수집·이용 목적 중 **마케팅 연락** 사실
2. 처리 항목 중 **민감정보 / 여권번호·운전면허번호·외국인등록번호**
3. **보유·이용 기간**(제공 시 제공받는 자의 기간)
4. **개인정보를 제공받는 자 및 그 이용 목적**

## 동의 없이 처리하는 개인정보의 고지 (제22조③)

동의 없이 처리 가능한 개인정보는 그 **항목과 처리의 법적 근거**를 동의 처리 개인정보와 **구분하여 공개**하거나
서면·이메일·팩스·전화·문자로 고지. **동의 없이 처리할 수 있다는 입증책임은 처리자**.

## 선택 동의 거부 시 불이익 금지 (제22조⑤)

**선택 동의 사항 / 목적 외 이용·제공 동의(3호) / 마케팅 동의(7호)** 를 하지 않았다는 이유로 재화·서비스 제공 거부 금지.

## 동의 방법 5가지 (시행령 제17조②)

1. 서면 직접 발급·우편·팩스 → 서명·날인 동의서 회수
2. 전화로 동의 내용 알리고 의사표시 확인
3. 전화 + 인터넷주소 확인 + 다시 전화 확인
4. 홈페이지에 동의 내용 게재 → 정보주체가 표시
5. 이메일 발송 → 동의 의사 적힌 이메일 회신

- **무효 온라인 동의**: 이미 체크된 상태(default) / "링크 확인하였으며 동의합니다" 문구에만 체크.

## 만 14세 미만 아동 (제22조의2)

- 처리 시 **법정대리인의 동의** + **동의 여부 확인**.
- 확인 방법(시행령 제17조의2): ① 인터넷 표시 + 법정대리인 **휴대폰 문자** 알림 ② 법정대리인 **카드정보** 제공 ③ 법정대리인 **휴대폰 본인인증**.
- 동의를 위한 최소 정보 = **법정대리인의 성명·연락처** → 아동에게서 직접 수집 가능.
- 아동 고지 = **이해하기 쉬운 양식·명확·알기 쉬운 언어**.
- 법정대리인 동의 확인 방법을 **처리방침에 포함·공개**.

## 함정 포인트

- 각각 구분 동의 = **7가지** (수집·제공·목적외·제공받은자 목적외·민감·고유식별·마케팅).
- 마케팅 동의는 **선택**. 미동의를 이유로 서비스 거부 금지.
- 아동 기준 = **만 14세 미만**, 온·오프라인 동일.
- '포괄 동의'(목적 미특정 일괄 동의)·기본 체크 동의는 **무효**.
