> 2026-09-07 기준 · 개인정보보호법 제35조~제39조의2 (국가법령정보센터 원문 확인). **기한 숫자가 시험 단골.**

## 정보주체의 권리 (법 제4조 — 7가지)

1. 처리에 관한 **정보를 제공받을 권리**
2. 동의 여부·범위를 **선택하고 결정할 권리**
3. 처리 여부 확인 + **열람(사본 발급 포함)** 요구
4. **전송을 요구**할 권리
5. 처리 정지·**정정·삭제·파기** 요구
6. 피해를 **신속·공정하게 구제**받을 권리
7. 완전히 자동화된 결정에 대해 **거부·설명 등을 요구**할 권리

## 대응 기한

| 요구 | 처리자 조치 | 기한 |
|---|---|---|
| **열람** (제35조) | 열람하게 함 | 요구받은 날부터 **10일 이내** (연기 가능, 사유 통지 / 소멸 시 지체 없이) |
| **정정·삭제** (제36조) | 조사 후 조치 → 결과 통지 | **10일 이내** (미이행 시 사실·이유·이의제기방법 통지) |
| **처리정지** (제37조) | 지체 없이 전부/일부 정지 또는 거절 통지 | **10일 이내** |
| **자동화된 결정 거부·설명** (제37조의2) | 자동화 결정 미적용 or 인적 개입 재처리·설명 | **30일 이내** |

- 거절·연기·미이행 시에도 **사유와 이의제기 방법**을 통지.
- 대리인 = **법정대리인 / 위임받은 자** (제38조, 시행령 제45조).
- 요구 방법·절차 마련·공개, **수집 방법보다 어렵지 않게**. 실비 범위 수수료·우송료(사본 우송 시) 청구 가능.

## 열람 요구 항목 (시행령 제41조①)

① 개인정보의 **항목·내용** ② **수집·이용 목적** ③ **보유·이용 기간** ④ **제3자 제공 현황** ⑤ 처리에 **동의한 사실·내용**

### 열람 제한·거절 사유 (제35조④)
1. 법률상 열람 금지·제한
2. 다른 사람의 **생명·신체 위해** 우려 또는 **재산·이익 부당 침해** 우려
3. 공공기관 업무에 **중대한 지장**(조세 부과·징수·환급 / 성적평가·입학자 선발 / 시험·자격심사 / 보상금·급부금 산정 진행 중 평가 / 감사·조사 진행 중)

## 정정·삭제 특칙 (제36조)

- **다른 법령에서 수집 대상으로 명시**되어 있으면 **삭제 요구 불가**(정정만).
- 삭제 시 **복구·재생되지 않도록** 조치.
- 삭제 원칙 = 파일에서 완전 삭제. 다른 법령상 보존 등 정당한 사유 시 **해당 정보만 식별 불가 조치로 갈음** 가능.

## 처리정지 거절 사유 (제37조②) — 4가지

1. 법률에 특별한 규정 또는 법령상 의무 준수를 위해 불가피
2. 다른 사람의 생명·신체 위해 우려 또는 재산·이익 부당 침해 우려
3. **공공기관**이 처리하지 않으면 다른 법률상 소관 업무 수행 불가
4. 계약 이행이 곤란한 경우로서 정보주체가 계약 해지 의사를 명확히 밝히지 않은 경우

## 손해배상 (제39조·제39조의2)

- 일반: 처리자가 **고의·과실 없음을 입증하지 못하면** 책임(입증책임 전환).
- **징벌적**: 고의·중과실로 분실·도난·유출·위조·변조·훼손 + 손해 발생 → **손해액의 5배** 이내(고의·중과실 없음 증명 시 제외).
- **법정**: 고의·과실로 분실·도난·유출·위조·변조·훼손 → 실제 손해 입증 없이 **300만 원 이하** 상당 금액.

## 함정 포인트

- 핵심 기한 = **10일**. 자동화된 결정 거부·설명 = **30일**.
- 열람 요구는 **본인 개인정보에 대해서만**.
- 삭제 요구가 **항상** 관철되지는 않는다(법령상 수집 근거 있으면 정정만).
- 처리정지 거절 사유 = **4가지** (매출 감소 등은 아님).
- 징벌적 손배 = **5배**, 법정 손배 = **300만 원**.
